# LIMITATIONS_OMEGA.md —— 关于"遮挡区 Ω"的如实说明

> **本文件是本包最重要的一份诚实声明。**
> 结论先说：**我们没有可信的遮挡区掩码**。论文因此删除了所有"遮挡区内"的分区指标，
> 只保留与掩码无关的结论。任何人若引用本包的区域数字，必须先读这一页。

---

## 1. 问题是什么

论文的前提是：相机侧遮挡物（拍摄者本人/手持物）在画面里造成一块区域 Ω，其中
① 反射被削弱、② 输入比目标更暗。对监督与评测来说，都需要**知道 Ω 在哪**。

**我们试了四类自动判据，全部失败。**

---

## 2. 四类自动判据的失败记录

### 2.1 `omega_of`（训练期用的判据）：在测试面板上退化

| 池 | Ω 面积中位 |
|---|---|
| 训练池 82 对（`real_pairs_1026`） | 15.3% |
| 训练池 126 对 | 20.8% |
| **测试面板 15 场景** | **35.4%** ⚠️ |

同一判据在户外场景上面积翻倍，会吞进阴影、树荫、窗框。
**结论：该判据只能在训练池上用于监督，不能用于测试面板的区域指标。**

### 2.2 v13 判据（`r=R/T` 闸门 + Otsu）：绕着暗影圈

人工目检确认：它圈的是**画面里偏暗的地方**，不是遮挡物剪影。
换言之它测的是"反射弱"，而不是"反射被挡住"——两者语义几乎相反。

### 2.3 阈值扫描：4 个拍摄域 × 5 档面积预算，**无一格圈对**

把 `I/T` 的阈值按面积预算（3%/6%/10%/15%/25%）扫一遍，四个域（1026-apr / 1020-apr / 1020-may / 1020-jun）
逐格目检，**没有任何一档圈出"人眼认定的遮挡区"**。
跨域最优阈值相差 **0.36**（apr 0.583 / may 0.751 / jun 0.943）⇒ 固定阈值不可能跨域通用。

复现：`code/train/../` 见 `viz_threshold_sweep.py`（本次未随包，脚本在工作树 `scripts/`）。

### 2.4 单帧直接学习：IoU 上界 0.494（域内）/ 0.14（跨域）

用一个小的分割网络直接回归 Ω：域内最好 IoU **0.494**，跨域 **0.09–0.14**（随机基线约 0.143），
容量从 0.2 M 加到 5 M 无改善。
**⇒ 单帧定位 Ω 不可行，这本身就是论文的一条结论。**

## 3. 连"标注掩码"也不是真值

训练期那套掩码是 **`omega_of` 提议 + 用户逐对肉眼确认**的产物。既然 2.1–2.4 表明提议只部分正确：

| 论文原本想写的 | 实际只能这样写 |
|---|---|
| "真掩码不优于随机盘 ⇒ 位置无关" | "**在我们的标注掩码下**，随机盘与标注掩码无显著差异；原因可能是位置无关，**也可能是标注不准**" |
| "洞内 −1.0 灰阶 / 洞外 +10.7" | **删除**（该组数是在退化的面板掩码上算的） |
| "遮挡区内拿方法对比" | **不做**（论文明确写：this panel cannot be scored inside the occlusion region） |

实测四种区域的对照（82 对池，3 种子）：

| 区域 | PSNR | 种子 sd |
|---|---|---|
| 标注掩码 | 19.41 | **0.54** |
| 随机盘·每步重画 | 19.90 | 0.16 |
| 随机盘·每对固定 | **20.25** | 0.29 |
| 整图 | 20.05 | —（单种子） |
| 无区域项 | 17.76 | 0.16 |

**标注掩码既不最好，种子方差又最大（是随机盘的 3.4 倍）。** 这与"标注有噪声"一致。

## 4. 与 `rdnet-clean-20261029` 分支的接口风险

合作者分支把模型输出从 `[R̂, T̂]`（R 非负）改成 `[N, T]`，其中

```
T = sigmoid(logit(I) + 4q)
N = I − T          ← 有符号显示域残差，不是非负反射辐亮度
```

**这直接影响本包的损失**：论文里的区域项是

```
L_Ω = Σ_Ω |T̂ − T| / Σ_Ω |R̂|
```

分母 `Σ|R̂|` 在新表示下变成 `Σ|N|`。而实测 Ω 内 `I/T ≈ 0.87 < 1`，即 `N = I − T < 0`
——分母会变号，且在某些样本上趋零。**该损失在新表示下需要重新定义**（例如用 `Σ|N| + ε` 并保证正定，
或改用局部照度估计作分母）。这一点尚未解决。

此外：该分支去掉 Mona adapter、解冻 FocalNet 末层、损失只监督显示域 T、数据源换成 KITTI/DriveAct/A2D2 + HF 合成。
**因此本包的数字与该分支不可直接对比**，必须同数据、同评测脚本重训一次。

## 6. 引用本包时必须遵守的三条

1. **不要**引用任何"遮挡区内 PSNR / 区域增益"的数字——它们在我们的面板上不可靠，论文里已删除。
2. "区域项有价值（3–4 dB）"这条**成立**，因为它是**有无**区域项的对照，与掩码位置无关。
3. "区域画在哪不重要"这条**只能写成"无显著差异"**，且必须附上"掩码本身未经人工验证"的限定。
