## 2. 与 `tintedglass-synth` 主分支的关系

本包**只读快照**，不参与训练流程。主分支的 `scripts/`、`RDNet/` 仍是工作副本；
`code/` 是把其中"复现论文所需"的部分抽出来、去掉一次性脚本后的干净版本（清单见 `MANIFEST.txt`）。

**与合作者 `rdnet-clean-20261029` 分支的关系**：
该分支改动了模型输出语义（`N = I − T` 有符号残差，而非非负反射 `R`）、可训练参数（解冻 FocalNet 末层、去掉 Mona adapter）、
损失（只监督显示域 `T`）与数据（KITTI/DriveAct/A2D2 + HF 来源 + 成像合成）。
**因此本包的数字不能与该分支的新架构直接对比**；两者需要一次同数据、同评测脚本的受控重训才能并列。
详见 `LIMITATIONS_OMEGA.md` §4。

## 4. 主张边界（写进论文的诚实声明，也适用于复现）

1. 本文**不主张**在公开基准上刷新 SOTA；主张是"该数据协议下，监督的可辨识性受限"。
2. **+2.22 dB 是域迁移 + 光度的结果**，不是"遮挡区监督有效"的证据；恰恰相反，我们的对照显示
   区域画在哪里**不显著**（标注掩码 19.41、随机盘 19.90、固定盘 20.25、全图 20.05）。
3. **负结果全部保留**：L^shift（+0.06 dB）、纯真实占比（−1.2 dB）、解析尺度不变损失（无增益，种子差 2.7 dB）。
4. Ω 掩码**未经人工标注验证**，因此所有分区数字**从论文中删除**（见 `LIMITATIONS_OMEGA.md`）。
