## Reading order

1. `results_summary_2026-11.md` — what the project concluded.
2. `experiment_ledger.md` — why (chronological, with retractions).
3. `nov02_report_v3.md` + `lightrr_judge.md` — the two strongest independent checks.
4. `prereg/*` — to verify that rules preceded results.
5. `icme2027_rules.md`, `qc_runbook_v1.2.md`, `collection_sop_v1.1.md` — reproduction and future-capture logistics.

## Conventions

- Numbers have a **panel and protocol**: 15-scene hand-masked panel (`1019`) vs November batch (`nov02`, 5 scene clusters). Never compare across panels without saying so.
- The authoritative metric tables are generated by the scripts in `code/eval/`; screen-printed values can differ slightly from saved-uint8 tables.
- Anything called *prediction*, *pseudo-label* or *auxiliary* is not ground truth.
- Retractions are marked with a sentinel in the ledger; retracted values must not be cited.
