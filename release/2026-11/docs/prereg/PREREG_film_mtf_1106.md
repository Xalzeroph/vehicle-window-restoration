# 预登记 · 贴膜玻璃膜传递函数 K(f) 互谱标定（2026-11-06 exp-dev，纯 CPU）

> 先写死判据，再跑。物理模型：`I = K*T + R`（K=对所有透射光同一线性算子/膜 MTF，R 不穿膜）。

## 数据与预处理（写死）
- **清洗配对**：`/tmp/ri_dev/clean_all_manifest.json`（shift≤2px、|g−1|≤0.15；无 resid 过滤）。
  四池分别：apr=`real_pairs_1026`（可用 73 对，<80 已注明）、may=`real_pairs_1020`（82）、jun=`real_pairs_1027jun_aligned`、nov=`real_pairs_nov02`；
  jun/nov 各取前 **min(120, n)** 对（rng=20261106 抽样；每池 ≥80 除 apr 外）。
- 逐通道鲁棒中位比 `g`（`build_devset_v2_1104.robust_gain`，keep_frac=0.7、3 轮）；**光度归一 `I' = I/g`**。
- **256×256 中心裁剪**（避开边界）、**Hann 窗**（2D 外积）、逐通道**去均值**。
- FFT：`F_I`, `F_T`；**互谱估计** `K̂(ω) = Σ_n F_I·conj(F_T) / Σ_n |F_T|²`（逐 bin 累加复数；**不用谱比**）。
- 径向：`r = sqrt(fx²+fy²)/(N/2)`，即轴向 Nyquist=1，角上 ~1.41；**主曲线只用 r∈[0,1]**（角点不报）。
- 逐 RGB 通道分别估计。

## 输出（全部落 /tmp/ri_dev/film_mtf_1106.{md,json}）
1. **径向 MTF** `|K̂|(r)`：四池 × 三通道曲线（r bins=64）；
2. **相位** `arg K̂`：分池/通道报 r∈(0.1,0.5) 的中位相位（对称 PSF 应≈0）；
3. **关键频率**：`f50`、`f10`（|K| 首次降到 0.5/0.1 的 r；未穿过则记 `≥1`）；同时报拟合模的解析 f50/f10；
4. **反射能量占比**：5 个频带（r: 0–0.1/0.1–0.3/0.3–0.55/0.55–0.8/0.8–1.0）的 `Σ|F_I−F_T|²/Σ|F_T|²`（通道平均）；
5. **参数化拟合**：`K(r)=1/(1+(r/f_c)^α)` 非线性最小二乘（逐池/通道），报 f_c、α、RMSE；并报高斯核 `exp(-(r/f_c)²)` 对照；
6. **图**：四池 × 三通道 |K|(r) → `/tmp/ri_dev/film_mtf_1106.png`；
7. **Wiener 反卷积诊断**：用 train/odd 划分（奇数对估计、偶数对测试，避免自证）：`T̂ = conj(Km)/(|Km|² + S_RR/S_TT) · F_{I'}`，
   Km=拟合径向模（各向同性 2D），S_RR/S_TT=训练对逐 bin 噪声比；报 `PSNR(T̂,T) − PSNR(I',T)`（逐池/全体，dB）。

## 判据（写死）
- **主判据 C**：高频端 `r>0.7` 的通道平均 `|K̂| < 0.1`？
  - **是 → 先验 C 成立**（"高频里 T 的贡献近零，补高频=补反射"）；否 → 先验 C 不成立，需重想方向；
  - 分池/分通道同时报（任一池/通道不满足要注明）。
- **副判据（同批膜）**：四池 `f50` 的极差/均值 **< 30%** ⇒ 视为同一批/同一型号；
- **一致性（染色）**：同池三通道 `f50` 的极差/均值 < 30% ⇒ 通道间无明显差异；否则报三通道差异作为染色证据；
- **Wiener 诊断**：`ΔPSNR = PSNR(T̂,T) − PSNR(I',T)`；**> 0.1 dB 记"K 可用"**（0.1–0.3 dB 也算信号），≤0 记"K 不足以提升重建"。

## 已知边界（开跑前写下）
- 互谱法假设 R 与 T 独立；同一场景相邻帧的照明/阴影变化可能与 T 内容相关 → 低频 K̂ 可能被污染；
- 中心裁剪 256² 只覆盖画面中心，K 若有空间变化（膜不均匀）本测量只给区域平均；
- `I' = I/g` 只做全局逐通道增益归一，不校正空间照度不均；
- 像素域中 R 与 T 的"独立"是近似，反射层本身来自真实场景，可能与 T 场景有弱相关（如窗外车流与车内无关，一般可接受）；
- 本测量是线性系统近似，不排除膜的非线性（散射饱和）成分。
