## 0. 结论先行（TL;DR）

1. **SOTA 已全线易主为"生成式/扩散"**：GenSIRR Nature 27.30+、WindowSeat ~27.4，把判别式锚点（DAI 27.05 / DSIT 26.77 / RDNet ~25.9）甩开 0.3~1.5 dB。论文相关工作与对比若只列 RDNet/DAI 一代会显得过时。
2. **2026 三个新工作恰好从三个角度解释"判别式为什么触顶"**：语义骨干与复原模型之间的 gap（GFRRN）；预训练编码器潜空间**不具备反射叠加的线性结构**（GenSIRR re-VAE、PRISM LCC，两篇不约而同指向"把物理结构写回特征空间"）。
3. **数据问题的解法已分层**：结构化采集（DAI 旋转介质，与 6 月四步法同思路）→ 合成/真实标签统一（GFRRN unified label，移植到 DSIT +0.17 / DSRNet +0.45）→ 物理渲染合成（WindowSeat Blender PBR，对强反射显著更鲁棒）。
4. **生成式成本已收敛到可落地**：WindowSeat LoRA+量化、单消费卡一天；GenSIRR DEBS 额外开销仅 ~1.25×；DAI 一步扩散 ~1s。→ ideas.md 里"扩散 teacher + 轻量在线"的架构假设（G 条）2026 下半年已具备实现条件，且新增了 **DEBS（免训练）** 和 **PBR 合成** 两个低成本入口。

## 2. 单篇要点

### 2.1 GenSIRR（Rectifying Latent Space for Generative SIRR）【全文】

**谱系**：郭晓杰组下一代 —— 作者 Li MJ / Hu J / Wang HN / Hu QM / Guo XJ，正是 YTMT→DSRNet→DSIT→RDNet→DIRS 原班人马。6.8 演进图需更新：判别式巅峰 RDNet/DIRS 之后，**该组转向了生成式**（与 6.8 分析"组内已开始试探扩散（TADiSR）"的判断吻合）。

**核心观察（表 1 证据链）**：编辑型 LDM（FLUX.1-Kontext）的 VAE 潜空间中，混合图的编码 `z_I ≠ (1−α)z_B + αz_R`。只加重建 loss 微调 VAE 对最终 SIRR 几乎无用（Real20 25.71→25.79）；**显式用等变 loss 拉近线性结构后暴涨到 27.27**。即：瓶颈不在重建质量，在潜空间几何。

**三组件**：
1. **re-VAE**：反射等变 VAE（LoRA rank-8，PD-12M 合成数据 3.84M 对），L_recon + L_equiv 强制潜空间线性；
2. **LTE**：可学习任务特定文本嵌入，绕开"用自然语言描述歧义混合图"的不可行（随机初始化或 RDNet prompt 生成器都不收敛，须从固定提示初始化）；
3. **DEBS**：测试时免训练技巧 —— k 个噪声种子并行跑 1 步，用单目深度估计做无参考质量筛选（反射是"幽灵物体"扰动深度，深度最连贯者胜），只走胜者全程，开销 ~1.25×（k=4）。

**性能与代价**：Real20 27.58/0.881、SIR2 28.08/0.937、Nature 27.34/0.840（DEBS 后）；人工成功率远超判别式（RDNet 类 30~41% vs 其 78.5~96.6%）。**代价**：256px 单张 2.58s @ A800（判别式 <100ms 的 ~26 倍）；DiT 需全量微调（中间层内在秩 >512，LoRA 不够）；多步生成的幻觉风险仍存在。

**车窗视角**：① DEBS 的深度一致性可借为**无参考质量筛选/车窗评测工具**；② re-VAE 需重训编码器 + 合成数据管线，属高成本路线；③ 强透射衰减（黑膜）下生成式"无中生有"风险最大，若当 teacher 必须配保真度/一致性约束。

### 2.2 GFRRN（Gap-Free Reflection Removal Network）【全文】

**谱系**：判别式双流+特征交互的最新接力（IBCLN → YTMT/DSRNet → DSIT → RDNet 同谱系，论文内与 RDNet/DSIT 直接横比）。明确指认两个此前被忽视的 gap：

1. **语义 gap**：冻结的预训练语义骨干（VGG/Swin）不参与训练，其特征与去除模型"各说各话" → **Mona-tuning**：在预训练骨干中插入少量可学习 PEFT 层参与联合训练（消融：去掉掉 0.63 dB，w/o Mona 26.70 vs 27.33）。论文承认 RDNet 也注意到类似问题（即 TAPG 用可训练 ConvNext 替代冻结 Swin-L 的动机同源）。
2. **数据 gap**：合成数据反射标签是 R，真实数据通常取 I−T，两者不一致、互相打架 → **label generator 统一标签**。关键卖点：**该技巧是数据级的通用解法**，作者把它移植到 DSIT（+0.17）和 DSRNet（+0.45）均有效。

**结构件**：解码器 G-AFLB（高斯掩码自适应频率学习块，+0.25 vs AFLB）；DAA（Dynamic Agent Attention，跨窗/窗内两级显著性建模，+0.42 vs W-MSA）。

**性能**：Real20 / Object200 / Postcard199 / Wild55 / Nature20 五集平均 27.33/0.929，均值超次优 0.7 dB。

**车窗视角**：与 FullTriAxisNet 血缘最近（判别式单帧），是**判别式新顶 baseline**；label generator 可直接移植到"合成对 + 真实四步法"混合训练；速度仍是实时部署/蒸馏基线首选。

### 2.3 WindowSeat（Reflection Removal via Efficient Adaptation of Diffusion Transformers）【全文】

**定位**：不造任务专用架构，把 12.5B / 20B 基础扩散 Transformer 通过 **LoRA + 量化 + 输入/输出模式复用**改造成 SIRR 工具；论文报告单消费卡约一天（5k 步级）。

**数据贡献（可能是最有外溢价值的部分）**：系统分析现有数据源（屏幕空间仿真、小规模集、伪标签）局限后，构建 **Blender PBR 光路渲染管线**（Principled BSDF 玻璃）。消融（Table 6）：alpha-blend 数据训出的模型在玻璃 IoR 升高（反射增强）的测试集上明显退化，PBR 数据显著提升强反射鲁棒性；PBR+alpha 混合综合最优（Nature 27.25），纯 PBR 零样本倾向更好。

**输入模式**：12.5B 消融最优 = FLOW 预测 + 第二路高斯噪声 token 集注入，Nature 27.43 / Real 26.19 / Objects 28.46 / Postcard 28.58 / Wild 28.98。

**车窗视角**：① PBR 管线可参数化"贴膜玻璃"光学属性（IoR/膜吸收/反射强度），**是目前唯一给出"可控物理合成同时覆盖反射+低光透射退化"路径的候选**；② LoRA 单卡成本意味着"自采真实车窗数据 + 大底座微调"可承受；③ 底座 20B 部署重，做 teacher 后蒸馏是自然的下一步；④ 论文未承诺开源（项目页为 HF Space demo），复现依赖后续发布，先订阅关注。

### 2.4 PRISM（Latent Composition Consistency for SIRR）【核验】

与 GenSIRR **同病不同方**：不修改 VAE，而是论证 FLUX VAE 潜空间对图像层天然低相干（T/R 余弦 ~0.07 vs 像素空间 ~0.74），故 `z_I ≈ z_T + z_R` 近似成立 → flow matching 学速度场 `v* = z_T − z_I ≈ −z_R`，一次前向即分解。防坍缩手段：LCC（batch 内循环互换反射 latent 做循环一致性）+ LCS（patch 级对比）+"透射层像素监督、反射层零监督"。

**风险提示**：反射层无像素监督导致亮度偏置（论文自承需后校准）；仍受单帧歧义限制；**尚无会议收录，投稿状态未知** —— 引用须标 arXiv。

**车窗视角**：方法学上给出"潜空间分解"的低成本替代实现；但 re-VAE 与 LCC 都建立在 latent 加法性上，而黑膜低光下混合过程叠加噪声与 CRF 非线性，加法性前提存疑 —— 值得做一个小实验验证前提（成本低），验证结果本身可以写进论文 motivation。

### 2.5 EvReflection（Event-Driven Micro-Dynamics for RR）【核验】—— 记录在案的排除项

事件相机捕捉手抖等微运动引起的反射/透射差分运动，MDD 解耦 + PAR 修正，配 EVR² 首个真实事件基准。自报 SOTA（合成/真实各超次优 >1.6 / >1.2 dB）。

**排除理由**（供 related work 与审稿回应存档）：课题约束为单帧静态输入、无车载事件相机硬件（CLAUDE.md 记录）；事件方案依赖微运动与硬件同步，与"单帧车窗图像增强"的产品/装置约束不符。只作"旁路信号还能怎么做"的背景一句话引用。

| 2026 论文指认的 gap | GenSIRR | PRISM | GFRRN | WindowSeat | 车窗课题对应点 |
|---|---|---|---|---|---|
| 语义/特征空间无物理结构 | re-VAE 强制线性叠加 | 寻找 latent 低相干性 | Mona 调语义骨干 | DiT 自带强世界先验 | 黑膜 = 空间变化 α + 色偏 Ψ + 非线性 Φ —— 呼应 DIRS LORS 的"物理写回"，现有公开方法无一建模 |

## 4. 车窗课题落地评估

> **算力约束（2026-09 确认）：本机仅 8–16 GB 显存消费卡**，无大模型训练条件。落地原则：扩散类方法一律走「官方权重推理 / HF Space 在线 demo」，训练预算只投判别式或云租卡（如 WindowSeat 单卡一天方案租一张 24GB 云卡即可）。

### 4.2 对 ideas.md / Phase 计划的增量建议

- **对比叙事重定位**：通用 SIRR 基准（Nature/Real20）已被扩散方法占据（27.3~27.4 且还在涨），判别式拼不过 —— FullTriAxisNet 的论文故事必须主打"**通用 SIRR 不做的**：低光+强反射+黑膜物理"，用车窗自有评测集说话（延续 5.25 综述 §4 challenge 论述），公开基准只作参考坐标。
- **扩散接入（ideas G）**：2026 有两个低成本入口 —— (a) DEBS 式深度引导免训选路（只需单目深度网络，可先在 RDNet/FullTriAxisNet 输出上做无参考筛选，试错成本最低）；(b) WindowSeat 式 LoRA 单卡微调大底座（等开源）。
- **数据（ideas J）**：① 6 月四步法升级为"同一透射场景多反射配置"，解锁 DAI RIF 一致性正则 + GFRRN unified label 两类收益；② 引入合成时用统一反射标签；③ 跟踪 WindowSeat PBR 是否开源（唯一同时覆盖反射+低光两个退化的合成线索）。
- **评测**：黑膜下 PSNR 意义有限（透射本身欠曝），引入 GenSIRR 式人工成功率 + 深度一致性作为无参考指标。

### 4.3 论文叙事分层建议（供更新 survey_car_window 5.x）

1. **判别式双流线**：YTMT → DSIT → RDNet → GFRRN（血缘叙事，含 PEFT/标签统一技巧）；
2. **生成式/扩散线**：L-DiffER → DAI（单步、数据） → GenSIRR（潜空间整流） / WindowSeat（LoRA+PBR）；
3. **数据与评测线**：RRW → DRR(DAI) → GFRRN 标签统一 → WindowSeat PBR → NTIRE 2026 挑战赛（另：LoViF 2026 雨滴+反射统一去除挑战与雨天车窗相关，可留意）；
4. **旁路传感（说明为何排除）**：闪光对/偏振/多视角/事件（EvReflection 一句话收尾）。
