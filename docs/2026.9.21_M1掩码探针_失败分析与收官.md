# 2026.9.21 M1 掩码门控探针：失败分析与收官

> **结论先行**：预登记判据下 **封线**——**单帧人影（Ω）定位在本设定下不可行**：
> 直连上界 **0.494** ≤ 封线线 0.65、跨域 **0.09–0.14** ≈ 平凡解 0.143；
> 容量（0.2M→5M）与数据（真阳 vs +合成）均无增益。
> 与 S2 合成统一叙事：**"人影洞既定位不了、又修不掉"**（任务级障碍，两个负结果互证）。

## 1. 目标与预登记门（Opus 钉死，`待做清单` §3.2）

**科学问题**：人影定位（掩码）能否跨场景迁移？——S2 已证"训练域可学"（①④ 16/16），
M1 把"定位"显式化，分离"定位"与"修复"。
**架构**：`T̂ = I − m̂ ⊙ D`（冻结官方 RDNet 266.4M，只训掩码头，bias=−4 零初始化）。
**判决门**：跨域场景级 IoU ≥0.50 且 ≥3/5 场景 → 可迁移；[0.30,0.50) 部分；<0.30 判死。
**容量阶梯诊断（预登记）**：域内留出 ≥0.60=高 / ≤0.35=低；**训练场景 <0.80 = 实现/标签 bug，停判读**。
**性能副判**：先跑 oracle 臂——若它 ≤1/11 则性能侧解读作废。
基线（实测）：may 全 1 平凡解 IoU=0.143、随机同面积=0.079。

## 3. 结果

**主判（场景级 IoU）**

| 档 | may（跨域） | apr 留出（域内） |
|---|---|---|
| A: w32 / w96 / w192 | 0.134 / 0.115 / 0.142 | 0.411 / 0.408 / 0.397 |
| B: w32 / w96 / w192 | 0.114 / 0.096 / 0.092 | 0.394 / 0.414 / 0.371 |

**诊断链**：
1. 训练集 IoU 中位 **0.537** → 触发预登记检查点（<0.80 停判读）；
2. **非退化解**：预测占比≈真值占比（0.15→0.15、0.29→0.30）、prob p95≈1.0——**面积对、形状/位置错**；
3. 口径对照：按训练口径（裁块）in-sample 0.676 vs 全图 0.537（修完口径仅 ~0.68）；
4. **直连 U-Net 终值 0.494**（全程 0.40–0.51 震荡无趋势）→ **封线线命中**；
5. "抄上一帧"朴素基线 **0.67–0.83**——反超全部训练模型（域内最佳 0.41）；
6. 附带：B 组合成洞洞内外灰度差仅 1–9/255（不可见）= 不可学样本（"加数据无增益"的真相）。

## 4. 失败分析（Opus 收官判读）

**一句话根因**：Ω 是**反事实标签**（"无人在场时反射本有的样子"）——单帧 I 只剩"暗人形块"弱证据，
与"真暗物体/阴影"在单帧中不可分 → 模型只能学到**面积先验**（占比对、形状位置错）。

**分层归因**：

| 层 | 判定 | 证据 |
|---|---|---|
| **任务本质** | **不可救（结构性）** | 直连 0.494（换方法无用）+ 容量三档无用 + 加数据无用 → 瓶颈=**单帧可辨识性** |
| 数据（合成练习册） | 废料（可修不必修） | 洞 1–9/255 不可见；标签本身干净（自洽 0.865、相邻帧 0.66–0.83） |
| 实现（口径/特征） | 没做对、但已排除为根因 | 口径修完 ~0.68；"冻结特征不足"被直连实验证伪 |
| 方法（从零学无先验） | 可修但属新线 | 见"出路" |

**三条可复现锚点**（论文用）：**0.494**（单帧上界）、**0.143**（瞎猜）、**0.67–0.83**（抄上一帧——
唯一明显更强信号）。

## 5. 结论与下一步

1. **封线成立**：措辞带限定——"**在本数据（223 真阳帧、单设备）与本标签口径下**，单帧人影定位实测
   上界 ≈0.5、不随容量与迭代增长；跨场景退化至平凡解。据此判定本设定下不可行"（不写"物理不可能"）；
2. **出路（记 future work，本轮不做）**：**时序（优先）**——抄上一帧 0.67–0.83 是实测最强信号，
   人影在视频中近乎静止而单帧证据不足；成本 ≥2–3 GPU·h，超出本轮掩码线封顶（~1 GPU·h），不颠覆封线。
   人形先验（下游模型零训练抓 25% 人影）→ 次选，记 limitations；
3. **底线缺口（确认必做）**：Ω 上补 3–5 个公开方法（ERRNet/DSRNet/IBCLN 等）→ "**全员 0/N**"对照表
   （推理 only，2–4 GPU·h；纪律：一次测完、全部如实报告、判据①–⑤ + may 口径、jun 不动）；
4. S3（jun）仍未消耗。

## 6. 论文口径（统一叙事）

**"人影洞既定位不了（M1：单帧 0.494、跨域≈瞎猜），又修不掉（S2：Ω 上 0/40；给真值掩码，官方残差
亦 0/16）"**——S2 证"训练域可学（16/16）、零泛化"，M1 把根因钉死为"Ω 单帧不可辨识"；
两负结果互证为**任务级障碍**（三个可复现锚点），支撑诊断型贡献（问题定义成立、现有范式失效）。
**限定必须写明**：单设备、223 真阳帧、本标签口径（omega_of 定式）。
