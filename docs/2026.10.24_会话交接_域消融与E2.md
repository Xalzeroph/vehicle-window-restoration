## 2. 五组实验的结果

### 2.1 损失消融（8 臂 14 次，15 场景）

| 臂 | 动的哪项 | PSNR |
|---|---|---|
| C0 基线（关梯度/拉普拉斯） | — | 20.035（3 种子） |
| **C3** | **去掉 Ω 加权项** | **17.128（−2.91，0/15）** |
| C4 | 加梯度/拉普拉斯，`w_s` 已修 | 19.831（−0.20，0/15） |
| C0′ | 同样两项，`w_s` 未修 | 20.158（+0.135） |
| C1 | `lam_r=0` | 20.231 |
| C2 | `lam_recons=0` | 20.155 |
| D16 | 只用 16 对 | 19.318（−0.72） |
| L | 16 对 + 旧保真 | 19.614 |

**结论**：Ω 项是承重墙；梯度/拉普拉斯保真是真负结果；**「修 `w_s` bug」反而更差 0.34 dB**（漏乘恰好加强了 opensrc 那批更可信的结构监督）；全帧 > 手挑少帧。

### 2.2 级联 NAFNet（4 臂）

| 臂 | PSNR | HF-PSNR | 梯度余弦 | 洞区 |
|---|---|---|---|---|
| 官方 base | 20.05 | 33.87 | 0.611 | 19.25 |
| **naf_l1** | **20.43（+0.37 显著）** | 33.63（−0.25） | 0.606（−0.006） | **17.81（−1.44）** |
| +L_HF | 20.23 | 33.60 | 0.605 | 17.33 |
| +L_gc | 19.82 | 33.56 | 0.608 | 16.87 |

**结论**：PSNR 涨但 HF/结构/洞区同时变差；我新增的两个损失（高频监督、梯度余弦）**都有害** → **细节缺失是"信息缺失"，不是"监督缺失"**。

### 2.4 apr 为什么同为室外却最差（零 GPU）

| 臂 | raw | 去掉色调后 | 增益 |
|---|---|---|---|
| **R-apr** | 20.236 | 21.746 | **+1.510（68%）** |
| R-jun | 19.927 | 21.150 | +1.223 |
| R-may | 22.471 | 22.854 | **+0.383** |
| R-in19 | 26.272 | 26.572 | **+0.300** |

**本质是纯加性偏亮**：apr 输出的最优集级仿射 `a≈0.98（≈1）、b≈−12`。把输出统一减亮 11 灰阶 → **+1.270 dB（占亏空 57%）**，且 may（+0.013）/ in19（+0.183）几乎无增益 → 交叉验证成立。

**物理原因**：apr 的 GT 亮度 128.2 vs 1019 的 100.5（差 28 灰阶）；apr 的 I→T 只暗 **3.2%**，1019 需要 **14.1%** —— apr 的反射**只加结构、不加净亮度**。

**已否证的假设**：反射强度（apr 最接近 1019 却最差）、暗化比例（Spearman 仅 −0.31，`R-may14` 是反例）。

### 2.5 E2 暗化剂量（3 臂）

| 训练暗化比例 | k 中位 | PSNR | 相对 apr 原样 |
|---|---|---|---|
| 3.2%（原样，3 种子） | 0 | 20.158 | — |
| 8.3% | +7.8 灰阶 | 21.115 | +0.957 |
| 11.3% | +11.7 | 20.989 | +0.831 |
| **14.3%** | +15.7 | **21.513** | **+1.355** |

**结论**：补暗化有效，14.3% 最好（+1.36），**打满零 GPU 分析预测的上界 +1.27** → 机制链闭合。但**未追上 may（22.46）**，差 0.94 dB → 暗化解释大部分而非全部。

## 6. 环境坑（都踩过）

1. **传脚本**：`base64` 超 Windows 命令行长度上限会**静默失败** → 超 300 行一律用 `scp`。
2. **相对路径失效**：`finetune_rdnet_s2.py` 第 34 行 `os.chdir(PROJ/RDNet)` → 一切路径传绝对。
3. **`pkill -f xxx` 会杀自己的 shell** → 用 `pkill -f '[x]xx'` 括号技巧。
4. **OOM 竞态**：`nvidia-smi` 检查与真分配之间别人可能抢走 ≥7 GB。**每任务前重新选卡 + 启动后 OOM 换卡重试**；并发数 = 空卡数（一卡一进程）。
5. **必须显式设** `TORCH_HOME=/home/zmy/data/cache/torch` `HF_HOME=/home/zmy/data/cache/huggingface`，否则 pyiqa 联网下载崩。
6. **PowerShell 生成 JSON 带 BOM** → Python 读用 `encoding="utf-8-sig"`。
7. **`while read` 遇无结尾换行的文件会丢最后一行**。
8. **Python 输出重定向到文件是块缓冲** → 加 `-u` 或 `flush=True`。
9. **中文路径在 git 里被 quote** → `git -c core.quotepath=false` 才看得见。
10. 共享机守则：他人 <3 卡用 4 卡、≥3 卡用 2 卡；**GPU6/7 保留给 Isaac Sim**。
