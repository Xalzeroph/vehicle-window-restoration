## 1. 动机

**不是"贴膜很暗"，而是"任何隔着玻璃的相机"**——车检、安防、隔窗拍摄。这类场景的成像是两个场景之和
（透射 + 反射），而野外没有逐像素真值。

更关键的是：**领域的裁判本身失真**。SIRR 通用做法是用 VOC2012（15,287 张）在线合成
（读 RDNet 源码 `data/dataset_sir.py`：反射先高斯模糊，`a∈[0.8,1]·T + b∈[0.4,1]·R`，70% 用非线性
叠加 `T+R−T·R`），**配方里没有"透射被衰减"这一项**。我们实测：在该合成域上微调，域内 **+3.4~+7.2 dB**、
实拍 **−0.4~−3.9 dB**（9/9 格全负）。"练得越好、实拍越差"本身就是可发表的事实。

## 2. 问题陈述（一句话）

> **在单帧、无偏振、反射强度未知（真实中常在 0.13–0.21，局部峰值可达 2.59）的条件下，
> 如何保证去反射算子对真实分布"严格不劣于输入"？**
> 现有 SIRR 做不到：增益匹配后无优势（6 月 −0.26 dB n.s. / 4 月 −1.78 dB），
> **近零反射帧大亏 −3.9~−7.9 dB、纹理砍 43%**（改动>25 的像素仅 1.3%）。

## 3. 第一性原理：三条缺口 + 因果排序

### 3.1 三条"原理性"缺口（非"没训过"）

| # | 缺口 | 证据 |
|---|---|---|
| **①** | **模型类无乘性自由度**：`a·T+b·R` 的 a∈[0.8,1] 是**混合权重**（衰减 ≤2 dB）不是透射衰减；输出参数化 `T̂=I−R̂` 也乘不出 τ → "因膜而暗"**根本不可表达**（空间非均匀 τ(x) 更表示不了） | 配方源码 + 实拍 τ 实测 |
| **②** | **无恒等分支**：R=0 时仍被强制减掉一个 R̂ → 这是"改动 1.3% 像素却砍 43% 梯度"的来源，是**归纳偏置**不是数据问题 | 5 月负对照 |
| **③** | **单帧歧义只靠先验**：域移时先验会自信地做错（`y=τT+R` 有**尺度规范自由度**，网络靠 a、b 先验定标；测试 τ 出界即标定错——**高 PSNR 是拟合了 a 先验，不是解了题**） | 实拍三种失败签名 |

### 3.2 因果排序（本文件最重要的结论）

| 排序 | 因素 | 量级 | 退化性质 |
|---|---|---|---|
| **①** | **R 主导反射** | 干扰比信号高 **+8.3 dB**（r_obs 峰值 2.59） | **辨识性硬退化**（信号与干扰同空间，单帧不可靠分离） |
| ② | RDNet 先验错配 | 4~8 dB（零反射 −3.9~−7.9） | 归纳偏置 |
| ③ | τ（0.6–1.0） | **−3.5 dB（τ=0.67）/ −4.4（τ=0.6）** | 香农式**软**退化（容量随 log SNR 连续降） |

**4 月的 −1.78 dB 是 ① 的直接证据**（反射又强又结构化，超出训练分布 → 既没去掉反射、又搞坏画面）；
**5 月的二分是 ② 的直接证据**（有反射帧 +0.3~2.0 dB，近零反射帧 −3.9~−7.9 dB）。
**headline 是 ①（R 主导），不是 τ、也不是噪底。**

### 3.3 τ 只在特定耦合下才有害（界定其贡献上限）

τ 单独看是**纯增益**：噪声可忽略时 τ=0.67 与 τ=0.05 只是**同一可逆问题的量级差**
（oracle 除以 τ 即复原，8bit 仅多损 0.58 bit）。性质改变来自**耦合**：
`y = τT + R + n`，**n 不随 τ 缩放** → 对比度/噪声比按 τ 掉。
故 τ 的贡献上限 ≈ 3.5 dB，**排在 R 与先验错配之后**。

## 4. τ vs α：区别与红线（防止复活已归档的 α 线）

**在方程 `I = (·)·T + R` 里 τ 与 α 是同一个槽位**，区别在三处：

| | 旧 α（已归档） | 新 τ |
|---|---|---|
| 量级 | 扫到 **0.05**，**实拍从未观测到** | **0.6–1.0**，CWD 实测 τ≈0.67（投影膜）/ 0.99（车窗玻璃） |
| 角色 | **空间变化的场，去估计它** → 病态逆问题 → α 头卡 0.7 平台 | 近常量，**不估计它** |
| 机制 | 比值 R/(αT) 上升 | 噪声耦合 + 模型类缺项 + 尺度规范歧义 |

> **红线**：τ 线**不得做逐像素 τ 估计**（那是 α 老路，失败原因不变）；
> 主张必须落在"噪声耦合 / 模型类缺项 / 尺度规范"这三条新东西上。

**另需注意**：车窗本体的 τ≈0.99（实测）→ **对"车窗"而言 τ 这条线几乎不存在**；
τ∈[0.6,1] 属**投影膜**档。若论文要覆盖车窗场景，τ 只能是**防守项**（界定边界），不能当主 claim。

## 5. 与项目早期结论的调和

早期结论"**乘性增强对检测零增益（Δ 不变）**"与新命题**不冲突**，是"此乘性非彼乘性"：
旧结论的乘性发生在**采集之后、无噪合成域**（精确可逆、检测器取相对特征）；
新命题的 τ 发生在**采集之前**，其后接固定噪声底 + 真实 R + ISP/γ/量化 + 空间非均匀 τ(x)，
可逆性被 n 与 R 打破。**旧数据既不反驳也不支持新命题。**

## 6. 实验设计（零训练优先）

| 实验 | 内容 | 若命题为真应看到 | 目的 |
|---|---|---|---|
| **E3（优先）** | 三套实拍配对按**局部 r_obs 分箱**，量 oracle 校正后的判据 | 单调降、r_obs≈1 处斜率陡、2.59 近不可恢复 | 直接量 **①R 主导** 的剂量-反应 |
| **E2** | T 取 CWD、R 取实拍/OpenRR，合成 `τT+R`，τ∈{1…0.05} × {**无噪, 实噪声底**}，oracle `(I−R)/τ` 复原 | **无噪臂全 τ 无损**（复现旧结论）+ 含噪臂按 20logτ 掉、τ<噪声底处崩 → 定出 SNR=1/SIR=1 两拐点 | **界定 τ 的贡献上限**（证明它不是主角） |
| **E1** | CWD 三档（无玻璃 τ≈0.99 / 投影膜 τ≈0.67）同场景，按各自 τ 对齐亮度后比下游差 | 投影膜仍输、差距集中暗部、随照度下降放大 | 同场景下 τ 对下游的实际影响 |

## 8. 风险与退路

- **若 E2/E3 显示 R 主导成立**：主线 = "**R 主导是辨识性硬退化 + 现有方法缺恒等分支（不伤害约束）**"，
  τ 降为界定边界的防守项
- **若被否**：退到两条已验证核心——**R 主导（峰值 2.59）** 与 **RDNet 先验错配（零反射 −3.9~−7.9 dB）**，
  故事仍立
- **最可能的审稿攻击**：① 3.5 dB 可能淹没在评测噪声（需功效分析）② 与旧结论表面矛盾（须讲清采集前/后）
  ③ CWD 是投影膜+单相机+小样本 ④ "已知 τ 时分解平凡"（须强调 τ 未知且空间非均匀）⑤ 单检测器=cherry-pick
- **多设备非硬门槛**：领域（RRW/SIR²/OpenRR）不以设备多样性见长；且我们的主结论是**同设备配对比较**
  （ISP/色调在 I 与 GT 中共模抵消）。多设备仅对"现象普遍性外推"类主张必需 → 优先级：**不同膜 > 不同手机**
