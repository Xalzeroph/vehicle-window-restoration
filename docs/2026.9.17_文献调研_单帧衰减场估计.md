# 2026.9.17 文献调研：单帧乘性衰减场（透光率 α）估计——族谱、消歧手段与新颖性判断

> 缘起：S2 出口轮把瓶颈定位到 **α̃ 的跨域校准**（α̃ 换真值 +4.3 dB，见 `2026.9.17_S2物理出口轮_实验记录.md`），
> 且 α 头线早有 0.7 可辨识性平台。本轮调研两个问题：① 别的领域怎么解"单帧乘性场与内容不可分"；
> ② "α（深色贴膜的衰减场）"这一支在文献里是否已被占位（关乎论文新颖性）。
> 方法：4 路并行检索 + 逐条网络核实；关键条目（PSTM）由主对话独立复核。

## 1. 族谱总表（同构问题：从单帧 I 里分离乘性场）

| 领域 | 方程 | 乘性场 | 消歧手段 |
|---|---|---|---|
| Retinex / 低光增强 | I = R·L | 照度 L(x) | 低频平滑先验 → 保边精修 → 学习式 |
| 去雾 / 水下 | I = J·t + A(1−t) | 透射率 t(x) | 暗通道等强先验 / 降维+锚点 / 多假设融合 |
| 阴影去除 | I = s(x)·T | 阴影场 | 硬边界 + matte 低参数化 + mask 监督 |
| 镜头遮挡（雨滴/污渍/划痕） | I = α·D + (1−α)·I₀ | 遮挡透射率 | mask 先验 / 注意力隐式 / 多帧 |
| 本征分解 | I = R·S | shading | 先验或合成 GT（bas-relief 歧义同族） |
| 透明层 matting | I = 前景·α + 背景·(1−α) | 透明度场 | 低参数化解耦 + 折射流 + 合成 GT |
| 平场/暗角校正 | I = flat(x)·T | 平场增益 | 梯度对称性单图估计；显微界主流需多图（BaSiC） |
| 本课题 | I = α·T + R | 透光率 α（硬边界、离散档、α≪1） | 本项目在探索：域适配分离器 + 档位头 |

## 2. 分领域要点（引用均已核实）

### 2.1 Retinex / 本征分解（照明场估计的传统）
- Jobson et al., *Properties and Performance of a Center/Surround Retinex*, IEEE TIP 1997（DOI 10.1109/83.557356）——
  照度=高斯低通 的最原始平滑先验；**各向同性平滑与硬边界天然冲突（生晕）**，我们的 α 必须换保边/分段先验。
- Guo et al., *LIME*, IEEE TIP 2017（DOI 10.1109/TIP.2016.2639450）——**锚点定标**（逐像素 max(R,G,B) 作初值）+ 保边精修的两段式。
- Wei et al., *RetinexNet*, BMVC 2018（arXiv:1808.04560）——**成对曝光弱监督**（反射一致 + 照度 TV），无需 GT 分解。
- Cai et al., *Retinexformer*, ICCV 2023——把照度当**条件（key）**而非隐变量。
- Barrow & Tenenbaum 1978（intrinsic images 起点）与 Belhumeur et al., *The Bas-Relief Ambiguity*, IJCV 1999——
  **"单帧乘性不可分"的理论源头**；绝对档位不可辨识、必须引入先验或锚点。
- Garces et al., *A Survey on Intrinsic Images*, IJCV 2022（arXiv:2112.03842）；IIW 数据集（Bell et al., ACM TOG 2014，DOI 10.1145/2601097.2601206）——
  **用"相对序"（人类成对判断）替代绝对值监督**。
- Xu et al., *Structure Extraction from Texture via Relative Total Variation (RTV)*, ACM TOG 2012（DOI 10.1145/2366145.2366158）——
  奖励块状平滑、惩罚纹理、保硬边：**与"分段常数 α + 2–4.5px 硬边"形状完全匹配的正则**。
- Bousseau et al., *User-assisted intrinsic images*, SIGGRAPH Asia 2009（DOI 10.1145/1661412.1618476）——
  少量稀疏锚点即可钉死绝对标度。

### 2.2 去雾 / 水下（工程上最成熟的"透射率"领域）
- He et al., *Single Image Haze Removal Using Dark Channel Prior*, CVPR 2009 / TPAMI 2011——**强内容先验做锚点**（"局部必有一通道近零"）；
  其先验失效区（天空/白物）与我们高 α 平台同构。
- Cai et al., *DehazeNet*, TIP 2016（arXiv:1601.07661）；Qin et al., *FFA-Net*, AAAI 2020——学习式回归 t；FFA-Net 明言
  **"先验式分步估计 t 不准会直接损害结果"，故直接回归干净图**。
- Li et al., *AOD-Net*, ICCV 2017——把 t 与大气光**合并成单一 K(x) 直接出图，规避分开估计的误差累积**。
- Tan, *Visibility in Bad Weather from a Single Image*, CVPR 2008——**只求任务可见度、不求物理正确**（后被批评非真实辐照度）。
- He et al., *Guided Image Filtering*, ECCV 2010——t 的精化算子；深度不连续处留 halo，**精度-伪影的显式权衡**。
- Ancuti & Ancuti, *Single Image Dehazing by Multi-Scale Fusion*, TIP 2013——**绕开 t：多假设融合**。
- Akkaynak & Treibitz, *Sea-thru*, CVPR 2019——**逐像素衰减须"外锚"（距离）才能与内容解耦，单帧纯内解不可行**。
- Berman et al., TPAMI 2021——**高维衰减场降为"离散参数 + 自动选型"以提升可辨识性**。

### 2.3 阴影 / 遮挡 / 透明层（硬边界 + 分段结构的先例）
- Chuang et al., *Shadow Matting and Compositing*, SIGGRAPH 2003——阴影密度 matte β 的 per-pixel 求解（我们的 α 同构）。
- Le et al., *SID*, ICCV 2019——**阴影 = 低维光照参数 × matte**，mask 监督；评估按阴影区口径。
- Guo et al., *ShadowFormer*, AAAI 2023——跨阴影/非阴影全局注意力；**明确边界处伪影问题**。
- Qian et al., *Attentive GAN for Raindrop Removal*, CVPR 2018——注意力隐式定位遮挡；**PSNR/SSIM 奖励平滑，不宜作 α 精度唯一口径**。
- Eigen et al., *Restoring an Image through a Window Covered with Dirt or Rain*, ICCV 2013——**网络会走捷径直接回归干净图、不估 α**（与我们观察到的"估计器被绕过"同构）。
- Chen et al., *TOM-Net*, IJCV 2019——透明体 α 不唯一 → 改预测 attenuation mask + 折射流 + 合成 GT。
- Xu et al., *Deep Image Matting*, CVPR 2017——**trimap 的 unknown 带 = 我们的边界带**；compositional loss + SAD/Grad/Conn 口径可借。
- Liu et al., *Learning to See Through Obstructions*, CVPR 2020——**单帧不成立，多帧视差是标准解药**。

### 2.4 本课题近邻：反射去除 / 隔玻璃成像 / 单帧平场
- Zhao et al., *Reversible Decoupling Network for Single Image Reflection Removal (RDNet)*, CVPR 2025（arXiv:2410.08063）——我们沿用的分离主干。
- Levin & Weiss, TPAMI 2007（稀疏先验+人工标注）；Zhang et al., CVPR 2018（感知损失 + Real20 基准 + 用户研究）。
- **近邻（已核；按"设定不同 + 无开源"处理）**：Wang, Lu & Tian, *Polarization State Tracing for Reflection Removal and
  Color-Consistent Reconstruction*, **CVPR 2026, pp. 5680–5689**——把玻璃内多次反射 + 波长选择性吸收
  （Stokes–Muller/Beer–Lambert）统一建模，GlassPol 真实数据集，PSNR 领先最多 3 dB。
  **两点事实核查（2026-09-17）**：① 论文 PDF 与补充材料经全文提取**均无任何链接**，全网无 GitHub/HF 仓库 →
  **无公开代码与数据，无法复现、无法同条件对比**；② 其设定为**有色玻璃的光谱选择性吸收**（空间近似均匀的
  平板吸收 β_λ，痛点是色偏+鬼影），**不是深色贴膜的空间性强衰减**（α≪1、硬边界、离散档位、痛点是内容损失）。
  → 本项目口径：**不追其数据、不作为竞争对照**；related work 中如需引用仅用于划界。
- Lei et al., CVPR 2020（偏振数据集）；Li et al., TIP 2019（光场 EPI 多帧路线）——均未处理透光率衰减。
- Ma et al., *See Through the Windshield from Surveillance Camera*, ACM MM 2019——透车窗监控增强 GAN，
  **把衰减并入异构退化隐式处理、无显式 α**（工业实践把贴膜当通用低光的代表）。
- Zheng et al., *Single-Image Vignetting Correction*, TPAMI 2009——单图估乘性渐晕场（梯度对称性）；
  Peng et al., *BaSiC*, Nature Communications 2017（DOI 10.1038/ncomms14836）——显微平场校正标准工具，**需多图（≥5）**。

## 3. 消歧手段清单（跨领域归纳，按可得性排序）

| 手段 | 代表 | 对我们的可用性 |
|---|---|---|
| ① 结构先验：块状平滑 + 保硬边 | RTV（TOG 2012）、matting trimap | **现成可用**（α 的形状完全匹配） |
| ② 相对序/档位监督（不求绝对值） | IIW/WHDR、LOE | **现成可用**（α 离散档位天然适合序回归——档位头已在做） |
| ③ 锚点/参考区 | DCP、LIME、Bousseau | 部分在用（区域池化、裸区保护）；可显式化 |
| ④ 配对/多档弱监督 | RetinexNet、KinD | **我们独有且未用尽**：同场景 5 档合成 → 可做"跨档一致性"损失 |
| ⑤ 多假设融合（不硬选一个 α） | Ancuti 多尺度融合、Berman 参数库选型 | 可作为出口失败后的替代出口形态 |
| ⑥ 直接映射（绕开显式 α） | AOD-Net、FFA-Net、Eigen 2013 | 教科书承认的主流；但会丢掉"可解释 α"这条卖点 |
| ⑦ 多帧/偏振外锚 | Sea-thru、Liu 2020、PSTM | 单帧设定的升级路线（limitation & future work） |

## 4. 新颖性判断（关于 α 这一支是否已被占位）

**结论：未被占位，但已有近邻，必须主动划界。**

- 已被做的：着色玻璃的**光谱吸收**已由偏振路线物理建模（PSTM, CVPR 2026）——但（a）设定是**有色玻璃**
  （空间近似均匀、痛点在色偏/鬼影），**不是黑色贴膜的深衰减**（空间场、α 低至 0.2–0.3、痛点在内容损失）；
  （b）**无公开代码与数据，无法对比**。平场/DCP 一支同样估乘性场——但场是平滑/深度相关的，且（显微）多为多图；
  透窗监控（ACM MM 2019）与工业界的车窗膜增强——把衰减当通用低光，无显式 α。
- 未被做的：**"单帧 RGB + 硬边界 + 离散档位 + 深衰减（α 低至 0.2–0.3）"的透射恢复与 α 可辨识性研究**。
- 口径（2026-09-17 用户裁定）：PSTM **不作为竞争对照**、不追其数据；related work 引用仅用于**划界**
  （设定不同：有色玻璃光谱吸收 vs 黑色贴膜空间衰减；输入不同：4 偏振 vs 单 RGB）；若论文写作需要，
  limitation 可简述"偏振路线需专用硬件"。

## 5. Related work 段落草稿（可直接改写）

> **单帧乘性衰减场估计**。从单帧图像中分离乘性的照明/衰减场是长期的不适定问题，其理论根源可追溯至
> 本征图像分解（Barrow & Tenenbaum, 1978）与 bas-relief 歧义（Belhumeur et al., 1999）：乘性场与内容可成对
> 缩放而保持观测不变。各领域以不同先验消歧——Retinex 系假定照度低频平滑（Jobson et al., 1997；LIME, 2017），
> 去雾以暗通道作内容锚点（He et al., 2009），阴影/遮挡以硬边界与低参数化 matte 建模（Chuang et al., 2003；
> SID, 2019），水下则以距离外锚或参数库降维（Sea-thru, 2019; Berman et al., 2021）。当透射率无法可靠估计时，
> 工程主流转向直接映射或多假设融合（AOD-Net, 2017；FFA-Net, 2020；Ancuti & Ancuti, 2013）。
>
> **隔玻璃成像与透射恢复**。单帧反射去除假定 I=T+R 两层叠加（Zhang et al., 2018；RDNet, 2025），
> 未建模玻璃的乘性衰减；有色玻璃的光谱选择性吸收近期被偏振成像建模（Wang et al., CVPR 2026），但其面向
> 色偏与鬼影、且依赖偏振输入，与本文关注的**空间性强衰减**（黑色贴膜，α≪1）设定不同。透窗监控
> （Ma et al., 2019）将衰减并入隐式退化。**本工作关注单帧普通影像下、深色贴膜的强衰减
> （α≪1、硬边界、离散档位）对透射恢复的影响**，并研究其 α 的可辨识性边界——这一设定尚无工作占位。
