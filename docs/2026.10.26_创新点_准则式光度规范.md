# 2026.10.26 创新点登记：准则式光度规范（Criterion-based Photometric Gauge）

> **登记原因**：用户判断这是"实打实的又一个新创新点"，要求记档。
> **本文的写法是"能过审的版本"**——不是"我们首创"，而是"我们搬了一条已被验证的策略，
> 但补上了低光领域没有的三样东西，并明确否掉了一处看似可搬其实不可搬的细节"。
>
> **一句话**：**当参考图的全局光度水平由采集过程决定（而非由输入决定）时，该分量不可由输入辨识；
> 逐像素监督会把模型拉向域平均亮度。低光增强用"准则约束"取代"参考图亮度"来回避它；
> 我们把同一策略用于 SIRR 的净衰减比 ρ，并补上形式化、可干预验收与物理取值来源。**

## 1. 创新点陈述

### 一段版（投稿用）

> 配对式图像复原的监督信号隐含一个假设：参考图的光度水平是输入的函数。
> 当该假设被采集过程破坏时（曝光设置不同、遮挡改变了照明），全局光度分量**不可由输入辨识**，
> 逐像素监督的最优解退化为**域平均亮度**——表现为"欠校正 + 平滑"。
> 低光增强回避此问题的方式是**放弃参考图亮度、改用可测准则**。
> 我们将该策略迁移到单图像反射去除，但做了三处必要的改写：
> （i）准则的取值不是常数，而是**部署相关的物理量** ρ（可由车膜 VLT 或一次性标定给出）；
> （ii）给出 ρ 不可辨识性的形式化与**光度误差分解**；
> （iii）给出**干预式验收**（固定输入、扰动条件、要求输出跟随），并实测现有条件化方法不通过。

### 三句版（幻灯片用）

1. **问题是"参考图的光度水平不可辨识"，不是"网络不够强"。**
2. **解法是"别让它猜，给它一个可测的准则"，这一招低光验证过。**
3. **我们的增量是：准则的取值来自物理（ρ），并给出证明与验收——低光那边都没有。**

## 2. 支撑证据（今天新测，oracle 口径，非可部署方法）

在 `real_pair_1019_testsplit12`（12 场景）上：

| 条件 | PSNR | 说明 |
|---|---|---|
| 原图不动 | 18.384 | 地板 |
| **原图 + 每图最优 affine（2 参数）** | **20.341** | 对应 `2026.10.08` C1 的口径 |
| **原图 + 每图最优 4×4 平滑亮度场（17 参数）** | **23.993** | **零学习，仅供诊断** |
| R-apr / R-jun / R-apr16 | 20.11 / 19.85 / 19.50 | **低于 17 参数基线** |
| R-may / R-mayjun | 22.54 / 23.22 | 略高于 affine，低于 17 参数场 |
| **R-in19（在测试地点上训过）** | **26.40** | 唯一显著高于所有光度基线 |

**两条读数**：

1. **一个不学习的 17 参数光度基线（看着答案调），打赢了大多数训练臂。**
   → 说明这些臂**连光度都没对齐**，不是"去反射不够好"。
2. **唯一大幅超过光度基线的是 in-domain 臂（+6.06 dB）。**
   → 说明**去反射确实有真信号**，任务本身不假；假的是"跨域臂已经学到了它"这个判断。

**注意**：17 参数基线是 **oracle**（用 GT 拟合），**不可部署、不能当竞品**，只能当**诊断尺子**。

## 3. 必须自己否掉的一处错误搬运（重要，写进论文反而是加分项）

低光的曝光损失是**分块**算的（每块都要落在区间内），因为全局一个数会把图压平。

**但这条不能直接搬到 ρ 上。** 理由：

| | 低光的准则 | 我们的 ρ |
|---|---|---|
| 形态 | **软区间**（E ∈ [0.4, 0.6]） | **精确比值**（μ(T̂) = ρ_tgt·μ(I)） |
| 物理含义 | "没有哪块该全黑/全白" | 全局净衰减，**空间上本来就该不均匀** |

**若照抄成"分块 ρ"，等于强制每块的衰减比相同**——而反射是空间变化的，
这会**制造一个物理上错误的约束**，并且与 Ω 的免伤目标直接冲突。

> **正确写法**：低光的**策略**可搬（准则取代参考），低光的**实现细节**不可搬（分块）。
> 我们的 ρ 准则保持**全局**；"压平"风险由 Ω 免伤项与结构项承担，不由分块 ρ 承担。

**这一条主动写进论文，等于替审稿人先否掉一个他会问的问题。**

## 4. 可证伪的实验（先预登记，再跑）

| 编号 | 实验 | 判据 | 不过怎么办 |
|---|---|---|---|
| **G-1** | 训练去掉全局亮度项（损失里不管 μ），部署用标定补 | **结构指标（HF / 洞区 / 结构相似）变好**，PSNR 可略降 | 判断不成立，退回纯分析 |
| **G-2** | ρ 准则（全局）ON vs OFF | **`S/μ(I) ≥ 0.5`**（干预式：扰动 ρ_tgt，输出跟随） | 条件通路无效，与今天 `killtest_rcm` 的结论合并 |
| **G-3** | 诊断尺子常态化 | 每个臂都对着 **affine(2p) / field(17p)** 两个光度基线报相对值 | 必须做，否则跨域臂的无能会被误读成"方法差一点" |

**G-3 零成本，且立刻改变所有历史结论的读法**——建议先做。
