# 2026.9.21 S2v2 修正版（保真项）负结果与归因 —— "加纪律"反而更糊更软

> **结论先行**：修正版（加全图梯度/Laplacian 保真项）**无增益且训练域更糊**（同 6k 对照：
> 细节保留 0.832 → 0.73、去除力度 162901 +2.4 → +9.5）；dev 判决与 v1 同级（仍 ③④ 双破门）。
> **"损失缺高频保真项"的归因假设被自证伪**——机制 = **对冲收缩**（见 §5）。
> PEFT 配方**冻结**，等用户新拍多场景配对数据后再开正式轮。

## 1. 背景与假设

S2 v1（见 `docs/2026.9.21_S2训练_结果与归因.md`）在 dev 上退化为"全图低通"。当轮归因假设：
**"损失缺全图高频保真项"**，修法 = 加梯度/Laplacian 保真 + 合成 s≡1。本档检验该假设。

## 2. 执行（2026-09-21，六卡）

```
卡1/2/3: finetune_rdnet_s2.py --arm main --seed 101/202/303 --iters 6000
         （新增 λg=5·‖∇T̂−∇T‖₁ + λl=2·‖ΔT̂−ΔT‖₁ 全图保真，四列同加；--s-jitter 0）
卡4:     s2_watch_card.sh（评测卡升级：自动输出 ①–④ 判决 + ⑤ 细节保留率 + 透射区 |P−I|）
补测:    v1 的 ckpt_6000 复评（控制"6k vs 10k"进度混杂，Opus 要求）
```

## 3. 结果（三臂同条件对照）

**⑤ 细节保留率（P/T Laplacian 能量比；线 ≥0.90）**

| | v1@6k | v1@10k | **v2@6k（加保真）** |
|---|---|---|---|
| apr（训练域） | **0.832** | 0.795 | **0.73 / 0.73 / 0.74**（3 seed） |
| may（dev） | 0.495 | 0.520 | 0.49 / 0.50 / 0.51 |

**去除力度（反射区亮度回归比，越小=越狠）**

| 场景 | v1@6k | v1@10k | v2@6k |
|---|---|---|---|
| may 162203 | 0.864 | 0.820 | **0.952** |
| may 162901 | +2.402 | −0.405 | **+9.513** |
| may 164653 | 1.037 | 0.972 | 1.121 |

**透射区 |P−I|（线 ≤3）**：apr 8.99 → 8.48 → 10.4~10.8；may 14.2 → 13.2 → 13.7~16.2。

**判决**：v2 在 may ①/③/④ 与 v1 同级（0–1/11，双破门）→ **FAIL**；apr 仍 ①④ 16/16（④中位 0.222）。
**用户目检**（对比图 `fig/s2v2_{may,apr}_vs_old_0921.jpg`）："感觉更糊了，反射区的去除也没有之前下手狠"
——**两条均被数值确证**。

**解耦结论**：
- may 上的差异 ≈ **进度效应**（v1@6k 0.495 ≈ v2@6k 0.49–0.51；去除力度随训练增强 v1@6k→v1@10k）；
- **apr 上同条件（皆 6k）的差异 = 保真项的真负作用**（0.832 → 0.73，去除 2.4 → 9.5）。

## 4. 已知实现瑕疵（记录待修，非主因）

`grad_fidelity` / `lap_fidelity` **未乘样本权重 w_s**——opensrc 臂（T 更陡、像素项半权）被相对放大。
修法：两项乘 `w_s`（与其它项一致）。

## 5. 归因（Opus 判读）：对冲收缩

**机制**：由一致性约束 `I = T̂ + R̂`，`∇T̂ ≈ ∇T` 等价于对 `∇R̂ ≈ ∇R` 的密集监督——而反射梯度是
**最难辨识**的量。L1 族下"错填"的期望损失 ≥ "不填"，故最优对冲 = **压自身高频 + 缩修正幅度**。
加"保真" = 加"对冲压力"，**越约越保守**（与直觉相反，但自洽）。

**硬证据**：末迭代 log `L_grad ≈ 0.09` → 每列梯度残差 ≈ 0.019，与 `|∇T| ≈ 0.027` **同量级、
全程无下降**——保真项**从未被满足**，是全程活跃的收缩压力（"训练 log 降到小值"是绝对尺度的错觉）。

**推论**：问题从"损失缺项"转向 **"数据可辨识性"**——16 对单机位数据中，反射/透射分解缺乏
足以约束的解空间信息，模型只能对冲。**调损失调不出来**，须扩监督域覆盖（多场景配对数据）。

> **补充（2026-09-21 晚，交叉引用）**：该收缩发生在**输入信息充足处**——may 输入保留了真值 89% 的结构
> 对比度，仍被微调输出压到 0.53（官方原生对照 0.68）；即破坏既非信息缺失驱动、也非定位失败所致
> （M1：Ω 本身不可辨识）——是模型在不确定下选择收缩。核验见
> `docs/2026.9.21_S2训练_结果与归因.md` §3c。

## 6. 结论与下一步

1. **PEFT 配方冻结**（不再试更大 λ——剂量方向预示更糊；不建议换"结构相似"式约束——同 L1 对冲逻辑）；
2. **等用户新拍"人走入→走出"多场景配对数据**（1–2 天），到位后开正式轮（判据集 ①–⑤）；
3. 备份路线：若无法多拍 → 结构路线（检测头 + 仅在掩影域修复）；
4. S3（jun）保持未消耗。

- 本档可作 **"目标冲突下保真约束的非预期退化"** 独立记录；**限定**：16 对单机位、Mona-PEFT、
