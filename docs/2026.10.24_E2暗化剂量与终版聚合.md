# 2026.10.24 E2 暗化剂量 + 域消融终版聚合（10 臂全部 3 种子）

> 本轮做两件事：**(a)** 把域消融的 8 个臂从 1 种子补到 3 种子（16 次训练）并重出权威表；
> **(b)** 做 E2「apr 补暗化」三档剂量（8.3% / 11.3% / 14.3%）。
> 统一配置：RDNet+Mona（主干冻结，可训练 65.95 M）、6000 iter / bs 6 / lr 1e-4、
> `--lam-grad 5 --lam-lap 2 --legacy-fidelity`、采样比 30:40:30、种子 101（E2）/ 101·202·303（域消融）。
> 主表 = **12 场景**测试子集（1019 冻结划分，sha256 `3c416c46…`）；15 场景作为辅表。
> 判据 = **Bonferroni 调整后 CI 排除 0**（8 条对照，α_adj = 0.00625）。
> ⚠️ 本文第 1–2 节的数字**取代** `2026.10.23_域消融v1_结果与归因.md` 的单种子表。

## 0. 六句话结论

1. **方向全部守住，幅度普遍缩水**：8 条预登记对照的判定与 10.23 完全一致
   （① ✅ / ② 无可检出 / ③④❌ / ⑤❌ / ⑥✅ / ⑦ 未过校正 / ⑧✅），但补种子后典型收缩 0.3–0.4 dB。
   **最佳臂 23.242 → 22.832**（`R-mayjun`，3 种子），不要再用 23.24 这个数。
2. **域效应仍是最大的单项**：`may − apr` = **+2.003**（12/12 场景，校正后 CI [+1.141, +2.865]）；
   域内上界 `in19 − apr` = **+6.216**（12/12）。
3. **apr 是负资产这条没变**：`aprmay − may` = **−0.959**（1/11），全三域 **−0.443**（仅负方向，未过校正）。
4. **E2 三档暗化全部显著优于 apr 原样**（12/12 场景，校正后 CI 均排除 0）：
   **+1.059 / +0.853 / +1.418 dB**（8.3% / 11.3% / 14.3%）。
5. **14.3% 档打穿了零 GPU 预测的上界**：实测 **+1.418** vs 事后色调上界 **+1.325**（≈108%）。
   说明"训练时补暗化"比"事后做仿射"能吃到更多 —— 机制链闭合，且不是同一个操作。
6. **但"剂量越大越好"不成立，不能写进论文**：11.3% 反而比 8.3% 低 0.206 dB；
   `dark14` 与 `may`（22.206）仍差 0.585 dB，而这 0.585 在**校正后不显著**。
   诚实的说法是"补暗化能拿回 ~1.0–1.4 dB，14.3% 档已接近 may 的水平"，**不是**"存在最优点"。

## 3. E2：apr 补暗化（三档剂量）

### 3.1 剂量定义（可复算）

对 apr 的每一对，把 `T` 整体平移 k，使该对的暗化比例达到目标：

```
k = target_pct · mean_luma(I) − (mean_luma(I) − mean_luma(T))
T' = clip(T − k, 0, 255)          # I 不动
```

| 训练集 | target | 实得暗化（逐对中位） | k 中位 | k<0 的对数 |
|---|---|---|---|---|
| apr 原样（R-apr） | — | **2.05%** | 0 | — |
| `real_pairs_1020_apr_dark08` | 8% | **8.31%** | +7.85 | 16 / 126 |
| `real_pairs_1020_apr_dark11` | 11% | **11.32%** | +11.73 | 8 / 126 |
| `real_pairs_1020_apr_dark14` | 14% | **14.35%** | +15.70 | 0 / 126 |
| （1019 需要） | — | **14.1%** | — | — |

> `k<0` 表示该对原本暗化已超过目标、被"反向提亮"——这是把剂量设成目标值而非增量后的必然结果，
> 不是 bug。14% 档 k 全为正。
> 注：10.23 文档里 apr 的"3.2%"是**按域均值算**（(132.5−128.2)/132.5），
> 这里的 2.05% 是**逐对中位数**，两个口径都对，不要混用。

训练侧只改 `--omega-domains` 对应的数据目录，其余参数与 12 个域消融臂完全一致
（见 `runs/dom_v1/E2-dark14_s101/manifest.json`：6000 iter / bs 6 / lr 1e-4 / lam_grad 5 / lam_lap 2 /
legacy_fidelity / n_omega 126 对 6 场景 / 可训练 65.95 M / wall 3.22 h）。

### 3.3 与零 GPU 预测对账

| 来源 | 预测 / 实测 | 与 dark14 实测 +1.418 比 |
|---|---|---|
| 逐图仿射（用 GT 的色调上界） | +1.510 | 94% |
| 集级仿射（真正可部署，a≈0.98、b≈−12） | +1.325 | **107%** |
| 训练期补 11 灰阶暗化 | +1.270 | 112% |

→ **训练时补暗化比"事后统一减亮"多拿 0.15 dB**。两者不是同一个操作：事后仿射只是把输出整体挪回去，
而训练期补暗化改的是"模型该输出多亮"的学习目标，因此能超过事后上界。
**机制链闭合**：apr 亏空的主因是纯加性偏亮（10.23 已确立），补上亮度即可回收大头。

### 3.4 三条不能说的话

1. **不能说"14.3% 最优"**。三档里 11.3% 比 8.3% 低 0.206，这个回落**没过校正**（区间含 0），
   所以既不能断言非单调、也不能断言单调。只能说 **dark14 单独显著高于 apr**，
   且 dark14 与 dark08/dark11 的差距（+0.36 / +0.57）**刚刚过校正线**，很脆弱。
2. **不能说"补暗化解决了 apr 问题"**。`may − dark14` = +0.585，在 α_adj 下**不显著** ——
   但这不等于"打平"：区间上限 1.238，**只说明本测试集（n=12）分辨不出这点差距**，不能说两者一样好。
3. **不能说剂量-反应成立**。E2 三个臂**各只有 1 个种子**，而同一配置的种子 std 是 0.578 dB。
   三档之间 0.2–0.6 dB 的差异**小于种子噪声**，属于"没测出来"，不是"测出来很小"。

### 3.5 补种子能买到什么（这条决定了待办 #3 要不要做）

用 `R-apr` 的种子 std 0.578 dB 当噪声估计（假设各臂同方差）：

| 设计 | 两臂均值比较的 SE | MDE（95%） | 能分辨的最小剂量差 |
|---|---|---|---|
| 1 vs 1 种子 | — （无种子级误差棒） | — | 只有场景级配对 CI，**会高估置信度** |
| 3 vs 3 种子 | 0.472 | **1.31 dB** | 只够分辨 ~1.3 dB 以上 |
| 6 vs 6 种子 | 0.334 | 0.86 dB | 仍分不出 0.2–0.6 |
| 12 vs 12 种子 | 0.236 | 0.52 dB | 勉强 |

**结论**：把 E2 三档补到 3 种子（6 次训练 ≈ 20 GPU·h），买到的是
**每个剂量自身的误差棒**（`dark14 − apr` 的种子级 95% CI 约 **[+0.11, +2.73]**，仍排除 0 但很勉强），
**买不到剂量排序** —— 0.2–0.6 dB 的剂量差在这个设计下永远分不出来。
所以待办 #3 本轮**没做**，理由见 §5。

### 4.2 `dom_R-aprmay_s303`（15 场景）只剩 3 个 `t_hat.png` → **污染了辅表**

- 现象：目录里有 3 个场景的 `t_hat.png` 就中断了，**没有 `arm_info.json`**。
- 为什么危险：`table_final_1019.py` 是**直接读预测 PNG**，不校验 `arm_info.json`。
  于是这 3 个场景被当成"一个只有 3 个场景的种子"混进辅表，
  `agg_dom_v1.py` 对该种子求均值 → `R-aprmay` 的 15 场景 PSNR 被静默改写：
  **21.221（std 0.641）→ 补跑后 21.259（std 0.122）**。std 差了 5 倍是最明显的信号。
- 修法：对 `R-aprmay_s303` 重跑 15 场景推理 → `[done] PSNR=21.322` → 重算表 → 重新聚合。
- **建议固化成一条检查**（还没写进 `agg_dom_v1.py`）：
  每个种子的行数必须等于场景数（15 场景 = 15 行 / 12 场景 = 12 行），
  不等就 `raise`。本轮已手工用 awk 校验，两侧均 `none`：

```bash
awk -F, 'NR>1 {c[$3]++} END {bad=0; for (k in c) if (c[k] < 15) {printf "%-32s %d\n", k, c[k]; bad=1}; if (!bad) print "none"}' \
    eval/table_final_1019_dom_v1.csv
```
