# 2026.10.08 P0 判决：UniSER（CVPR 2026）的 mask/strength 是"用户给定"还是"模型自动判断"

> 一轮 = 一个可独立回答的科学问题（research-loop P0）。
> 本轮全部由主 agent（flash）执行，用户显式指定不开子代理。

## 1. 目标与预登记判决门（先写后跑）

**一句话目标**：判决 UniSER 的空间 mask 与移除强度（strength）是**外部用户输入**，还是**模型自动判断**——以确定我们"自动 no-harm 门控"的差异化是否仍然成立。

**预登记判决门**（事后不改口）：

| 情形 | 判定 | 后续动作 |
|---|---|---|
| mask/strength 是**用户提供**的控制信号 | **① 成立** | 我们的自动门控独有，门控线保留为主线 |
| mask/strength 由**模型自己预测** | ② 成立 | 门控线让位（已被占），转"人影洞 + 跨域协议" |

**成本**：0 GPU（读文）。

| # | 原文（摘） | 位置 | 含义 |
|---|---|---|---|
| E1 | "Developed fine-grained **user controls** for SER tasks, including spatial masks and strength levels" | 贡献列表 #3 | 控制信号是**用户控制**，被算作贡献本身 |

## 4. 判决：**① 成立 —— mask 与 strength 全部是用户给定的控制信号**

UniSER 的"免伤"（mask 内无效果则保持原样）是**执行指令**，不是**自主判断**。模型不做"该不该动手"的决策，它只回答"在指定区域里按指定强度动手"。

> 人话：Adobe 做的是一个**极其听话的工人**——你圈哪里他改哪里、你说多大力就多大力；你不圈的地方他绝不碰。但"该圈哪里"这件事，仍然要人来定。

## 5. 反向发现（对我们反而有利）

E4 那条行为——"**mask 内无效果 → 保持原样**"——正是我们用 E4 的 oracle 门控量出来的 **+2.02 dB headroom** 的行为化表述。

- 我们测：完美"选不选"值 **+2.02 dB（块级）**，且 **36% 的块本该不动**；
- 他们做：把"不该动就不动"直接写成训练目标。

**结论：我们的诊断被一篇 CVPR 2026 用工程方式实现了**——说明这条路线有效、且已被顶会认可。差别只在**谁来给 mask**。

## 6. 可借用的零标注配方（本轮最实用的产出）

他们的强度训练法（Eq.1）：

```
α ~ Uniform[0,1]                     每样本采样一个标量强度
I_target = α·M_blur·I_gt + (1 − α·M_blur)·I_input
```

即：**用软掩码当连续强度条件，用"输入与真值按 α 线性插值"当监督**，模型就学会 α=1 全去、α=0 不动、中间部分去。

- 对我们：**我们有真 GT（黑布档）**，同样可以零标注地训出"连续力度图"；
- 迁移方式：把"用户给的 mask"换成"我们的门控头输出"，训练时用随机软强度图 → 学"力度 → 动作幅度"的连续映射；
- 成本：可直接挂在 RDNet + Mona 上，无需新数据。

## 7. 划界（必须写进论文，否则会被质疑）

| 维度 | UniSER（CVPR 2026） | 我们 |
|---|---|---|
| 控制信号 | **用户提供** mask + strength | **自动判断**该不该动手（无 mask 输入） |
| "免伤"含义 | 听 mask 的话（mask 外/无效果区不动） | **对任意输入不劣于输入**（自证式判据） |
| 通解路线 | 3.8M 配对 + DiT 微调 + 通用 prompt + 辅助遮挡任务 | 域不变判据 + 跨域留一协议 + 人影洞反事实退化 |
| 任务族 | 四类软效果统一（lens flare / shadow / haze / **reflection**） | 深色贴膜车窗（反射 + 暗区透射） |
| GT 来源 | 公开数据集整合 + 自建渲染管线 | **自有黑布档真 GT**（四步/协议 v2） |
| 算力 | 巨大（作者自陈 limitation） | 10GB 卡 PEFT 级 |

**已被占坑、不得再声称新颖的两条**：
1. "反射 + 阴影 + 光晕统一处理"（半透明遮挡家族）——已被 UniSER 占；
2. "可控力度/区域编辑"本身——已被 UniSER（mask+strength）与 LUCID（CFG）占。

**我们仍然独有的三条**：
1. **自动**（无 mask）判断该不该动手，且判据是"不劣于输入"；
2. **人影洞（Ω）**这一反事实退化——四类软效果里没有它，它更接近"遮挡 + 低光"；
3. **跨域留一（LODO）协议** + 可解释失败诊断（剂量-反应 / 门控 headroom / 注入触发）——UniSER 的泛化是 in-the-wild 定性 + 标准 benchmark，无留一域。
