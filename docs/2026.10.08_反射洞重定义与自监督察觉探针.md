# 2026.10.08 "反射洞"重定义 + 自监督模型察觉能力探针

> 触发：用户指出"**反射洞是具体物体遮挡造成的**（身体部位 / 树叶 / 三脚架），所以有语义与结构；模型可以用语义知道这里是洞、要填起来；透射层物体也有语义，可用高层语义反过来做细节修补"。
> 本文记录三件事：① 协议 `Ω` 与用户所说"洞"**不是一回事**；② 在用户指认的洞区里的个案数字；③ 自监督模型（DINOv2）能否察觉洞。

---

## 1. 定义澄清：协议 `Ω` ≠ 反射洞

`scripts/eval_protocol.py::compute_mask` 的定义：

```python
D = |I − T·g|            # 增益对齐后的逐像素偏差（g = robust_gain）
M = D > max(3σ̂, 8)      # Ω = 偏差显著大的像素
```

→ **`Ω` 是"残差阈值掩膜"**：把"反射强的亮区"和"反射被挡的暗区"**混在一起**，呈散斑状，覆盖 **34–44%**（连通域数千个）。

**后果**：
- M1 的"单帧定位上界 IoU **0.494**"考的正是这个掩膜 → **它并没有否定"洞能被定位"**，只否定了"能回归一个残差阈值掩膜"；
- 我之前两次试图自动构造"洞"掩膜（局部中值法 1.5% 细条 / 闭运算法 42.6% 过检，与用户指认 IoU 仅 0.17）**均未对上**，说明自动定义不可靠。

**用户给出的正确定义**：洞 = **贴近玻璃的前景物把反射挡掉**留下的区域；遮挡物属于一个**开放家族**（手/头肩/树叶/三脚架腿…）。其共性是**物理角色 + 结构**（该处反射被压、边界为物体轮廓），不是语义类别。

## 2. 个案数字（用户指认洞区：apr 172719 的 B4–C4「手拿手机」+ C4–D4「人头肩」）

区内（480×152 px）对齐口径：

| | 区内亮度 | 区内细节（Laplacian var） | 区内 ΔPSNR（vs 输入） |
|---|---|---|---|
| 真值 GT | 89.1 | **332.1** | — |
| 输入 I | 86.0（−3.0） | 206.8（**63%**） | — |
| **官方 RDNet** | **46.9（−42.1）** | **56.2（17%）** | **−3.17 dB** |
| lovo_k2 臂 | 91.3（+2.3） | 138.5（42%） | **+5.65 dB** |
| s2main10k 臂 | 91.0（+1.9） | 121.0（36%） | **+2.99 dB** |

**读法**：
1. **官方在该区把它当"反射"去减**：亮度砍 42、细节只剩真值 17%、对齐后仍比输入差 3.17 dB → **"模型不知道这是洞"被证实**；
2. **微调臂在域内做对了操作**（把亮度拉回真值、区内 +5.65 / +2.99 dB）——**"填起来"是学得会的**，且已部分学会；
3. 但**细节只到真值 42% / 36%** → **结构没补出来**——正是"用语义补细节"（机制 B）的空间。

## 3. 自监督模型能否察觉？（DINOv2-base @518 patch 特征）

| 核对区（用户指认） | 无监督聚类最佳 IoU | **种子相似度最佳 IoU** | 暗度基线 IoU |
|---|---|---|---|
| apr 宽松 x≥.25,y≥.75 | 0.347 | **0.611** | 0.589 |
| apr 紧 x≥.50,y≥.75 | 0.246 | **0.502** | 0.436 |
| may 宽松 | 0.171 | **0.388** | 0.155 |
| may 紧 | 0.194 | **0.333** | **0.010** |

**定性（见 `fig/dino_hole.png`）**：
- may 帧里，**地上的纸箱被 DINOv2 干净地聚成一个独立类**（连通、边界贴合）→ **物体级感知确实存在**；
- apr 帧里出现若干**紧凑的物体状聚类**（其中中央底部那块很可能就是"手+手机"）；
- 种子相似度图能在洞区点亮成片。

**判读**：
1. **"有所察觉"成立**——尤其在 **may 上：暗度基线彻底失效（0.010）而 DINOv2 相似度仍有 0.333** → **语义特征在平凡线索失效处仍然可用**；
2. 但**纯无监督聚类只有 0.17–0.35**，够不上"直接拿来做掩膜"；
3. **诚实的保留**：核对区是用户的**粗框**（四分之一条带），对粗框算 IoU 偏宽松；且"最佳种子"是在框内扫出来的（用了弱监督）→ 这是**乐观上界**，不是无监督结果。
