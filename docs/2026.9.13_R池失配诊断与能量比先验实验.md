# 2026.9.13 R 池失配诊断与 RDNet 能量比先验实验

> 起因：用户对 v2 合成数据的三条观察——
> ① α<0.5 时人眼已分辨不出透射层 T；② RRW 提取的 R 层"轮廓能认出但色彩完全畸变"，而实拍反射强区要么炫光白、要么膜黑，不会这样；③ 本轮实验说明 RDNet 去反射高度依赖"反射/透射能量比"先验。

## 1. 色彩畸变根因：`frame − GT` 把"场景负残影"混进了 R 【事实】

**机制**：RRW 的 GT 图与视频帧走过不同的采集/处理链（曝光、色调曲线、色处理均不同）。
直接相减 `R = frame − GT` 时，残差 = 真实反射 −（GT 与帧的失配项）；失配项在空间上就是**场景本身**（逐通道、非线性），因此 R 层里出现"场景轮廓残迹 + 颜色错乱"。

**证据 1 —— 残差与场景 GT 的相关**（38 个入池场景，raw 残差灰度 vs 本场景 GT 灰度，256×144 口径）：

| 统计 | 数值 |
|---|---|
| corr(R_raw, 本场景 GT) | 范围 −0.05 ~ −0.82，均值 ≈ −0.39，中位 ≈ −0.40 |
| corr(R_raw, 其他场景 GT)（对照） | ≈ 0（±0.1~0.37 随机） |
| 强残影例 | camera_objects5 = −0.823、indoor_object2 = −0.596、outdoor_trees1 = −0.587 |

**证据 2 —— 对齐后残影消失**（选代表场景，单帧）：

| 场景 | GT→frame 逐通道仿射 (s) | 残差 corr：对齐前 → 对齐后 |
|---|---|---|
| camera_objects5 | 0.68 / 0.54 / 0.52 | −0.688 → **+0.026** |
| camera_objects2 | 0.91 / 0.91 / 0.90 | −0.311 → **−0.009** |
| outdoor_trees1 | 0.76 / 0.79 / 0.69 | −0.480 → **−0.007** |
| indoor_object2 | 0.77 / 0.78 / 0.74 | −0.678 → **−0.015** |

**证据 3 —— 失配形态**：逐通道**只对增益**（无截距）拟合消不掉 corr（−0.59 → −0.60），**加截距**后全部归零；且斜率 0.52–0.91 配正截距。
→【推断】失配主要是"对比度/色调曲线差 + 色偏"型（手机 ISP 味），不是单纯曝光差；增益-only 的 s≈0.83–1.12 说明**平均亮度关系接近 1:1**，偏差集中在曲线形状与色处理上。

**副作用**：带截距的对齐会把反射自身的直流分量吸进截距（camera_objects5 的 R̄ 9.6 → 2.3 就是直流被吸走的结果），正式修复需用**低分位包络**拟合（见 §5）而不是裸仿射。

## 2. 色度统计：合成 R 比实拍反射"花"得多 【事实】

| 指标 | 实拍 R̂（3 视频 15 帧） | 新池 pool（缩放后） | E1 旧池 |
|---|---|---|---|
| chroma 中位 / p90（max−min 通道差） | **2.0 / 7.0** | 6.0 / 41.0 | 11.0 / 53.0 |
| chroma 随亮度的分布 | 平坦（2.7 → 9.0，无 >160 亮度像素） | **随亮度单调升**（5.8 → 51.2，192–224 档最艳） | — |

- 实拍：越亮越白（强反射去饱和）→ 对应"炫光白 / 膜黑"的用户观察。
- 合成：越亮越彩 → 用户感知的"色彩畸变"。缩放按 ρ 线性放大色度（raw 均值 6.2 → 缩放后 14.9）。
- 修复失配后色度回落（gain-only 对齐已让部分场景 4.5→1.8、8.0→2.3）；v3 完成后复测，若仍偏离再考虑色度压缩策略。

## 3. RDNet 能量比先验：受控实验

### 3.1 固定 ᾱ=1、只缩放 R 强度（新做的受控扫描，产物 `probe_rscale_0913/`）

| k（R 强度） | 输入真比 r_obs（中位） | 输出 R̂/T̂（中位） | 去除比例（1 − R̂̄/(k·R̄)） |
|---|---|---|---|
| 0.5× | 0.141 | 0.189 | **−29%**（输出的反射比真实还多） |
| 1× | 0.247 | 0.163 | +32% |
| 2× | 0.404 | 0.106 | +74% |

输入能量比涨 2.9×，输出比反而**降** 1.7×、去除比例从负到 74%——RDNet 的 R:T 分配**不跟踪**输入能量比。

### 3.2 α 扫描（v2 首跑，`eval_v2_alignment.py`）+ 旧池对照

| ᾱ | 真比 r_obs（≈25.4/(ᾱ·T̄)） | 新池 R̂/T̂ 中位 | 新池去除比例 | 旧池 R̂/T̂ | 旧池去除比例 |
|---|---|---|---|---|---|
| 1.0 | 0.29 | 0.163 | 36% | 0.07 | 57% |
| 0.6 | 0.48 | 0.265 | 34% | 0.19 | 29% |
| 0.3 | 0.95 | 0.380 | 47% | 0.48 | 11% |
| 0.15 | 1.9 | 0.301 | 67% | 0.78 | 18% |
| 0.1 | 2.9 | 0.257 | 74% | 0.94 | 23% |
| 0.05 | 5.7 | 0.226 | 81% | 0.91 | 39% |

真比跨 20×，新池输出比只在 0.16–0.38 徘徊（旧池会爬到 0.9，说明不是死板上限，但仍远滞后于输入）。
注：绝对量 R̂̄ 会随输入整体变暗而缩小，"去除比例"混入了尺度效应；较干净的不变量是输出 R̂/T̂ 的窄带。

### 3.3 判定 【事实+推断】

**RDNet 的 R:T 分配锚定在其训练分布里的"反射该占多少"（≈0.1–0.4），基本不随输入真实能量比变化**——受控扫描里甚至反向。用户判断成立；更准确的表述是"与输入能量比脱钩/锚定先验"，不是简单的"依赖"。可进论文：失败模式 = **先验失配**，不是容量不足。
注意：当前池混有 §1 的失配残影，上述数值待 v3 池重建后复核。

## 4. α<0.5 人眼不可分辨 T 【用户观察 + 推断】

- 与信息量分析一致：ᾱ=0.3 时 T̄≈27 gray、ᾱ=0.05 时 ≈4.4 gray，再叠强 R 覆盖；oracle-α 上限在 ᾱ=0.05 也只有 ~20dB（50% 像素 α<0.05）。
- 当前合成还多叠了一层 §1 的失配残影（暗化 + 色偏），**名义 ᾱ 的有效外观比修复后更暗更花**——人眼阈值可能被高估。
- 基准含义：ᾱ≥0.3 是主战场（人眼也可见）；ᾱ<0.15 作为"不可恢复带/动机曲线"展示。修复后需重做一次人眼可见性检查，以修复版为准。

## 8. 【修正】根因重判：逐帧相机 AE/AWB 响应，不是"采集链失配" 【事实+推断】

### 8.1 三个新事实

**（a）42/42 场景全部存在与 GT 一致的干净帧。** 逐场景 min_frames mean|frame−GT| ∈ [0.66, 2.54] 灰阶
（argmin 帧的均值差 ≈ +0.5）。与 RRW 采集协议吻合（CVPR 2024 *Revisiting SIRR in the Wild*, Zhu et al.：
GT 用黑绒布挡反射侧拍摄，视频模式下中途撤布，三脚架对齐）——视频开头就是"绒布未撤"的干净态。
→ `R = frame − GT` **本身就是该视频的真实反射效应**（旧池 raw 与按干净帧重算的真值相关性 **0.977**、
目检几乎重合），提取环节**没有**采集链失配。

**（b）负相关/"鬼影"来自逐帧逐通道的相机响应（AE 压曝光 + AWB 对反射光反应）。**
机理：反射光进入后整幅变亮 → AE 降曝光、AWB 压偏色 → frame ≈ s_c·GT + R_optical，
负相关 = (s−1)·GT 项（乘性、随 GT 增大而为负）。
用低分位包络斜率稳健估计 s_c（分箱取 q15 包络点、对 GT∈[30,230] 段拟合直线）：

| 帧 | s=(R,G,B) | 备注 |
|---|---|---|
| f000/f010（干净帧） | (1.014, 1.001, 0.980) | ≈1，自洽 |
| f031 | (0.956, 0.941, **0.844**) | B 通道跌最大 |
| f103 / f134 / f196 | (0.943–0.973, 0.91–0.94, **0.73–0.84**) | AWB 压蓝 |

【推断】B 通道增益跌 0.16–0.27 → 反射光偏蓝（窗外/亮室光）触发 AWB 压蓝 + AE 压曝光；
这正是 R 层 corr(R,GT)≈−0.4~−0.8 的主导项（乘性 → 与 GT 线性相关 → 消掉它即大幅回落）。

**（c）色彩的另一半是真实反射内容，不是伪影。** 放大目检 f031−GT：除弥散亮层外可见**实体倒影**
（玻璃杯/壶轮廓等）；真值差分层 f31−f0 的 chroma 中位/p90 = **12.4/27.9**。RRW 反射的是
相机侧房间（有色物体）→ 内容本身有色；与我们实拍（RDNet R̂ chroma 2/7，白眩光/黑膜）是
**内容差异**。ρ 缩放再线性放大之。

### 8.2 对修复方案的影响：全包络过削，改为"只扣乘性响应"

对照（indoor_object2，pool 口径）：

| 方案 | corr(R,GT) | chroma 中位/p90 | 与真值差分层 corr |
|---|---|---|---|
| 旧池（frame−GT） | −0.590 | 11.0/28.0 | **0.977** |
| 全包络（原 v3 方案，§5） | −0.365 | 5.0/18.0 | 0.896 |
| **斜率式（R = frame − s_c·GT）** | −0.414 | 8.6/21.6 | 0.954 |

- 全包络把反射直流与部分本体一起削掉（对真值保真度下降、色度腰斩）→ **弃用**（§5-1 作废）。
- 斜率式只扣"相机响应"分量（benchmark 辐射模型 I=αT+R 不含相机响应，扣掉更符合模型），
  保留反射直流、内容与色度主体 → 采用。
- 残余 corr ≈ −0.41【推断】= 局部化的处理响应（非全局增益）尚未扣净，待后续观察。

### 8.3 修订后的 v3 步骤（实施中）

1. `build_rrw_pool.py` 增 `--tone-correct {none,slope,env}`（默认 none，保留旧行为）：
   逐帧逐通道估计 s_c（低分位包络斜率，q15、24 箱、拟合段 GT∈[30,230]）→ `R = frame − s_c·GT` 截 0；
   **活跃帧选择仍按原始 (frame−GT) 均值口径**（保持与 v2 池同一选择规则）。
2. 重建池 → `r_rrw_strong_v3/`，`eval_pool_quality.py` 对比旧池/实拍：corr、色度（期望向实拍靠）、强度分布。
3. 目检：R 层是否还有"场景轮廓鬼影 + 互补色"观感（用户判定）。
4. 通过后重建测试集 + 复跑 RDNet 六档（对比 v2 首跑结论是否稳健）。

## 9. 【二次修正 / 撤回】v3 修正作废；R 中的"T 成分"是采集本征的亮度相关增益 【事实+推断】

> 起因：用户观察——"R = I−T 的残差里有很多成分还是 T"。本节对该观察做了完整核验，
> 结论：**现象成立且为采集本征性质**；且 §8 采纳的 v3 斜率修正**在这条判据下有害，撤回**。

### 9.1 现象量化（2026-09-13 深夜）

- 旧池 corr(R_gray, 本场景 GT) 均值 −0.375（最差 camera_objects5 −0.82）；v3 池 −0.169。
- **截 0 不是主因**：未截断的逐帧中值差分 corr ≈ 截断版（camera_objects5 −0.821 vs −0.825），
  负值像素占 11.5%~57%。
- 差分的亮度轮廓（逐 GT 分箱的 Δ̄ = median_t(frame)−GT，暗→亮 8 箱）：

| 场景 | 暗→亮 Δ̄ 轮廓 | 亮区符号 |
|---|---|---|
| camera_objects5 | +44.8 +33.7 +33.3 +21.0 +11.6 +5.6 +0.6 +3.7 | ≈0 |
| indoor_object2 | +18.4 +18.5 +15.5 +5.4 −0.3 −1.7 −3.4 −9.5 | 负 |
| outdoor_trees1 | +34.5 +17.9 +5.9 −1.3 −4.1 −5.5 −4.8 −4.5 | 负 |
| camera_objects8 | +24.4 +22.5 +18.5 +14.7 +0.3 −5.7 −13.1 −24.8 | 负 |

【事实】**反射效应（frame−GT）在暗区最强、亮区趋零甚至为负**，即 R 被一个随亮度单调下降的
增益调制。逐帧形状稳定（同场景各活跃帧归一化轮廓 corr 0.6~1.0，但幅值 14~72 波动），
指向"随像素自身亮度变化的响应增益（手机局部色调映射/响应曲线斜率）"而非反射内容随机分布。
亮区为负说明该增益还能压到 0 以下（局部响应），线性"反射只加光"模型在亮区不成立。

### 9.2 判据与撤回依据：无反射像素上 R 必须 ≈ 0

构造"无反射像素"掩码 = 整个视频（含干净帧）像素值时域 std 最低 20%——这些像素从未出现
反射，任何提取法的 R 在该掩码上应 ≈0。实测平均 |R|（灰度）：

| 场景 | none(旧池) | **斜率(v3)** | 仿射包络 | mask-LS 仿射 |
|---|---|---|---|---|
| camera_objects5 | 3.2 | **33.8** | 7.2 | 2.9 |
| indoor_object2 | 3.1 | 9.3 | 6.8 | 2.3 |
| indoor_object3 | 1.8 | 4.8 | 8.8 | 1.7 |
| speaker | 0.9 | **14.8** | 7.8 | 1.8 |
| outdoor_trees1 | 0.8 | 1.0 | 12.1 | 2.0 |
| camera_objects8 | 5.0 | **21.2** | 10.7 | 4.5 |
| indoor_arts1 | 3.3 | **35.4** | 9.2 | 2.7 |

**v3 斜率修正在无反射像素上注入最多 35 灰阶假信号**（缺截距项：真响应含大正截距
c≈+5~+38，纯斜率 s·GT 在强响应帧严重失真）→ **v3 池 (r_rrw_strong_v3) 与 v3 测试集
(synth_rrw_v3_0913) 作废，2026-09-13 已从项目目录删除**（连同两张 v2-vs-v3 对比图）。
仿射包络同样不可靠（q05 线被暗反射内容污染）。
mask-LS 仿射物理上安全（MAE 1.7~4.5）但 corr 改善有限（−0.82→−0.74、−0.59→−0.47…），
且掩码 GT 覆盖窄（如 camera_objects5 仅 129~167）→ 斜率外推不可靠，优点不足以采纳。

### 9.3 结论与对基准的影响

1. **R 中的"T 成分"是 RRW 采集本征性质**（亮度相关增益调制 + 亮区局部响应），
   不是提取 bug，全局逐帧响应修正无法消除（practically：修正只会引入新伪影）。
2. **基准有效性不受影响**：R_x 与无关场景 T_y 合成，R 与其自身源场景 GT_x 的相关
   不构成对基准 T 的泄漏，合成图 I=αT_y+R_x 物理/数值上仍成立；论文中按"数据性质"记录即可。
3. **v2 池（--tone-correct none，即 frame−GT）保持为基准 R 源**；v3 的实验价值 = 把
   "响应可被全局扣掉"这一假设证伪（判据：无反射像素一致性）。
4. 人眼可见性（§4）与能量比先验（§3）不受本节影响。
