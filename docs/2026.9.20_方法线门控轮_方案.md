## 1. 主张与已核事实

**主张**：(A) 门控 = **单侧伤害风险预警**（非"预测该不该动"）：`O = I + w·(后端−I)`，w∈[0,1]。
不动手恒安全（w=0 ≡ 恒等）；假拒绝只损失收益，假接受触发伤害门。论文重心 = **协议 + 失败模式分类学**，
不赌"我们的 critic 赢"。

## 4. B1 门（critic 可分性）与信号锚点

锚点：8 个手搓信号 harm AUC pooled 最高 0.625、within-month 跨月翻转 → 现成信号≈随机（kill 结论不依赖标签口径）。

- **主指标 = 场景内 AUC（macro）**（base-scene 内中心化 + 块加权 pooled-within，另报逐场景宏平均）；11 簇 bootstrap；
  **pooled 降为描述量**，引用时必须并列"**场景身份捷径**"基线（dev 实测 in-sample **0.824**、LOO 仅 0.18 = 纯记忆）；
  **判决禁用 pooled 单独**
- **线性探针 kill test**（冻结 ConvNeXt-T + 线性头，块级，留一场景 CV，1 卡 0.5h，**macro 口径**）：
  **≥0.65 → GO**；**<0.60 → KILL**（回退手搓+保守阈值，"headroom 不可学"入负结果）；0.60–0.65 → 限 1 卡 2h 单次试训
- **终门（macro）**：**≥0.70 且 11 簇 bootstrap 下界 ≥0.65**；apr/may 各 ≥0.63；**最差月止损线 0.58**
- **risk–coverage 工作点**：保留，按簇级重采样评估（c=40% 处 acted 块伤害率 ≤0.5× 基线；c10 ≥0.30）

## 5. critic 设计摘要（预登记锚，来源：Opus 设计判读 2026-09-20）

- 输入 `[I, P, P−I, R̂loc]` 四通道；**timm ConvNeXt-T 冻结** + FPN-lite 头（stride4 单通道图）+ 全局支路标量 g，
  `w = σ(map + g)`；空间 w 平滑（guided filter），`w=0` 用 `where` 硬置恒等（不留残差）
- **监督**：效用 `u = ΔPSNR + λ(−ΔLPIPS)`（相对固定后端）→ 损失 = Huber + 成对排序 + 辅助 BCE(harm)；
  **决策级损失**：`O=I+w(P−I)` 可微反传真实效用，**假接受伤害权重 ×3–5（非对称）**
- **阈值**：conformal risk control 于 dev 校准（目标 bad-action ≤10%）；**一月校准、另一月验证**
- **跨月**：留一月验证（LOMO）+ Group-DRO/VREx + 光度/JPEG 增强；特征用相对量（|P−I| 按 I 局部对比度归一）；
  喂后端状态（cls_model 6 维 code）
- **禁止**：pooled AUC 单引、RDNet 式全局 prompt 注入（αTAP 老路，已归档）、oracle-w 五分类作主监督
