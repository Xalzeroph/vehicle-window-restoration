# 2026.10.26 预登记：$\Omega$ 掩码 vs 同面积随机掩码（机制判决实验）

> **目的**：判定"$\Omega$ 加权项承重（去掉 −2.91 dB）"到底来自**反射洞的物理结构**，
> 还是来自"**任意一块同面积区域的正则**"。
>
> **这是 $\Omega$ 损失能否作为"方法创新"写进论文的唯一判决实验。**
> 判据写死在本文件，跑完只许照此判。

---

## 1. 设置

两个臂**除掩码来源外完全相同**（沿用 `runs/abl_v1/C0_s101` 的确切配置）：

| 项 | 值 |
|---|---|
| 脚本 | `scripts/finetune_rdnet_s2.py`（本次新增 `--omega-mode`） |
| 数据 | `data/train_sets/real_pairs_1020_apr`（126 对 / 6 场景），`--omega-domains apr` |
| 迭代 / batch / lr | **6000 / 6 / 1e-4**，seed **101** |
| 损失权重 | `lam_r 1.5, lam_recons 0.2, lam_excl 0.1, lam_om 3.0, lam_hinge 1.0, lam_dists 0.2, lam_grad 5.0, lam_lap 2.0` |
| `legacy_fidelity` | **False**（与 C0 一致） |
| **臂 real** | `--omega-mode real`（真实 $\Omega$ 掩码） |
| **臂 random** | `--omega-mode random`（同面积随机圆盘，圆心限制在框内以保证面积相等） |

**输出**：`runs/abl_om1026/{real,random}_s101/`

## 3. 判据（写死，跑完照此判）

| 编号 | 判据 | 含义 |
|---|---|---|
| **G1（机制成立）** | `PSNR(real) − PSNR(random) ≥ +1.0 dB` | **洞的结构真的携带信息** → $\Omega$ 损失可作为方法创新，claim 强 |
| **G2（机制不成立）** | `\|Δ\| < 1.0 dB` | 收益来自"**任意同面积区域的免伤正则**" → claim 必须弱化为"廉价正则"，不能说"洞的物理" |
| **G3（反向）** | `PSNR(real) − PSNR(random) ≤ −1.0 dB` | 反常，需查随机掩码是否意外成了更强正则（如位置更居中） |
| **G4（可复现性）** | `PSNR(real)` 落在 **20.035 ± 0.30** | 复现 `C0_s101`；若偏离，说明本次环境/数据池与 10.21 不同，G1/G2 需降级为**只比两臂相对差** |

**主报**：$\Delta$ 及其 95% CI（场景级配对，$n=15$ 或 12 按届时口径）。

**次要指标**（不改判，但一并报）：$\Omega$ 区 PSNR、去反射率、HF-PSNR、梯度余弦。

---

## 4. 已知局限（必须在论文里写）

| 局限 | 影响 |
|---|---|
| **单种子** | 检测下限约 1.3 dB（种子级），故 G1 的 1.0 dB 门槛偏松；若 $\Delta$ 落在 0.5–1.5 之间，**不能下结论**，需补种子 |
| 随机圆盘 vs 真实 $\Omega$ 形状不同 | 圆盘更"方整"，可能反而更易优化；这是保守方向（对 G1 不利），可接受 |
| 只测 PSNR 主判 | 若两臂 PSNR 打平但 $\Omega$ 区误差显著不同，应报出来并说明"总体打平、局部有差" |
| 数据池 `real_pairs_1020_apr` 与 10.21 是否同版 | 若不同版，G4 会失败，此时只比相对差 |

## 6. 复跑

```bash
# real 臂
CUDA_VISIBLE_DEVICES=2 python3 -u scripts/finetune_rdnet_s2.py \
  --arm main --iters 6000 --batch 6 --lr 1e-4 --seed 101 --mona both \
  --lam-r 1.5 --lam-recons 0.2 --lam-excl 0.1 --lam-om 3.0 --lam-hinge 1.0 \
  --lam-dists 0.2 --lam-grad 5.0 --lam-lap 2.0 --s-jitter 0.0 \
  --omega-dir <P>/data/train_sets/real_pairs_1020_apr --omega-domains apr \
  --assert-under <P>/data/train_sets/real_pairs_1020_apr \
  --out <P>/runs/abl_om1026/real_s101 --gpu 0 \
  --manifest <P>/runs/abl_om1026/real_s101/manifest.json --omega-mode real
# random 臂：同上，--omega-mode random
```
