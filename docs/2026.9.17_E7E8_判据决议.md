# 2026.9.17 E7/E8 与判据决议（含一次判断纠错）

> 本文件的**结论均出自 Opus 评审**（2026-09-17 两轮），flash 仅负责执行与核对数字。
> 起因：用户指出"PSNR 已不足以说明反射去掉，应以感知为主"；flash 提出"改用残留比为主判据
> + PSNR 可能冤枉了门控"，用户要求 Opus 评审。**评审判定 flash 的核心判断有误**，本文如实记录。

## 1. E7：oracle 天花板与判据相关性

逐块（128²，3,223 块，三套实拍配对合并），候选 w∈{0,.25,.5,.75,1}，`输出(w)=(1−w)·输入+w·RDNet`：

| 量 | 值 |
|---|---|
| **约束 oracle**（在 ΔLPIPS≤0 的 w 中取最大 ΔPSNR） | **均值 +1.99 dB / 中位 +0.32 dB** |
| 对照：纯 RDNet（w=1） | 均值 +0.36 dB，ΔPSNR≥0 60%，ΔLPIPS≤0 20% |
| headroom | **+1.63 dB** |
| corr(ΔPSNR, ΔLPIPS) | **−0.232** |

**关键含义**：存在**同时占优**的逐块解（+1.99 dB 且不伤 LPIPS）→ 判据应写成「**约束非劣**」，
不是加权折衷。当前手搓信号拿不到它（E5/E6：LPIPS 达标最高 37%）→ **"知道该动多少手"这件事值 1.6 dB**。

## 2. E8：判据相关性实验（对 flash 假设的判决）

同一批候选（3,223 块 × 5 个 w = 16,115 样本）并算三个量：

| 相关 | 值 | 含义 |
|---|---|---|
| corr(ΔL1残留, ΔPSNR) | **−0.884** | **残留比 ≈ PSNR（同一根轴）** |
| corr(ΔPSNR, ΔLPIPS) | −0.273 | |
| corr(ΔL1残留, ΔLPIPS) | +0.238 | 符号翻号，但幅度同级 |

## 3. 判据决议（Opus 评审结论）

1. **残留比不是新判据轴**：逐块分母 `mean|输入−GT|` 固定 → 排序 ≡ L1 排序，与 PSNR 秩相关 >0.9（实测 −0.884）。
   其失效模式：需 GT+掩膜（无配对实拍不可用）、**强反射块分母大 → "免单"**、只量幅度不量结构。
   → **降级为强反射块的辅助诊断量，不作主判据**。
2. **"PSNR 冤枉门控"不成立**：E5/E6 中 PSNR 是**宽松方**（63–81%），LPIPS 是**严苛方**（16–37%）；
   以 LPIPS 为主只会更难看。E4 更硬：PSNR 判 RDNet 赢时，LPIPS 与肉眼一致判输 → 冲突是真的
   （"去反射像素增益 ↔ 糊化/幻觉"的权衡），不是度量缺陷。
3. **"LPIPS 低估结构化剪影"无据**（未验证）：只有弱版本成立（整图距离**稀释**小面积剪影）；
   E4 中 LPIPS 恰恰抓住了肉眼可见的残留。**不得当论据使用**。
4. **像素域与感知近乎正交**（E8 实测）：无论 PSNR（|r|=0.27）还是 L1（|r|=0.24），与 LPIPS 的关系都只有
   0.25 量级（R²≈6%）→ **优化像素域指标推不动感知**。这才是"必须以感知为主判据"的**正确理由**。

### 可辩护的判据体系（双轨主判据 + 人评直证）

| 地位 | 内容 |
|---|---|
| **主 (i)** | **反射区受限结构残差**：掩膜内 SSIM / 梯度残差，**按局部 GT 对比度归一**（不用输入误差归一 → 废掉"分母免单"）+ 反射存在性分数 |
| **主 (ii)** | 整图 LPIPS + **反射区裁剪 LPIPS**（避免稀释） |
| **人评（必做）** | **20 人 × 30 图 2AFC**（≈600 判定，足以分辨 60%/50% 胜率）——"人影去没去掉"只能由它直证 |
| 辅 | PSNR/SSIM：仅作 `ΔPSNR≥0` 不劣约束与跨论文可比 |

统计口径：逐图配对差报**中位 + bootstrap CI + 符号检验**（不报均值）。

## 4. 对后续轮次的影响

1. **门控/估计器的目标不变、判据换新**：目标仍是收回 E7 的 +1.63 dB headroom，但验收按新判据
2. **数据规模仍是硬约束**：24 场景（=24 簇）→ 块级达标率的场景级 CI ≈ ±10%，预登记门不可分辨；
   最小可行 = 合成对（已知 α、R）训练 + 24 实拍留一场景终检 + 按场景报 CI
3. **不得再用"残留比"当卖点**；不得再用"PSNR 冤案"叙事
