## 2. FoCo 的"联合"到底怎么做的（从正文抠出的可实现细节）

**总目标（式 2）**：
```
argmin_θ  d(G(I), Î)                ← L_C：像素/视觉损失
        + d(F^f(G(I)), F^f(Î))      ← FoFA：特征层
        + d(F^t(G(I)), F^t(Î))      ← GaTA：任务层
```

### 2.1 FoFA（Foundation Feature-space Alignment，特征层）

1. 取多个基础模型 `F_{i,j}`（第 i 个模型、第 j 层，论文用 **CLIP / SAM / ResNet**）；
2. 每个空间用**卷积投影器 `P_{i,j}`** 映射到统一特征空间，再归一化：
   `F̂^f_{i,j}(x) = Norm(P_{i,j}(F^f_{i,j}(x)))`
3. **交叉注意力融合进判别器**：在图像特征 `f_j^D`（判别器第 j 层）与语义特征 `f_j^F`（统一空间）之间做通道/空间双注意力：
   `A^s = Softmax(P^{s,k}(f_j^F)·P^{s,q}(f_j^D)/√(H·W))`，`A^c = Softmax(P^{c,k}(f_j^F)×P^{c,q}(f_j^D)/√C)`
   `f_j^O = A^c × A^s + f_j^D`
4. **判别器损失 = 对抗 + 特征匹配**（关键：把判别器自己的特征图与基础模型特征对齐）：
   `L_D = −E_{x~p_high}[log D(x) + ‖D^f(x) − F̂^f_m(x)‖] − E_{x~p_low}[log(1−D(G(x))) + ‖D^f(G(x)) − F̂^f_m(G(x))‖]`
   `L_G = −E[log D(G(x))]`

> 一句话：**不是把 CLIP/SAM 的特征直接拼给生成器，而是让判别器"长出"基础模型的语义特征**（特征匹配项），再用它去评判增强结果。

### 2.2 GaTA（Gap-driven Task-based Alignment，任务层）

1. **强模型（CLIP）= 伪标签提供者**：对增强结果做 **T 次增广**，每次取预测，**多数投票**得伪标签：
   `Ŷ^l = argmax_c Σ_{t=1}^T 𝟙[argmax_{c'} p(Y^l_t = c') = c]`
2. **弱模型（ResNet）= 退化检测器**：对同一增强输出取 logits `Y^s = F^s(G(x))`
3. **损失**：`L_GaTA = L_h(Y^s, Ŷ^l)`（弱模型预测要向强模型投票伪标签靠拢）
4. 两个模型**全程冻结**；论文实验用**分类任务**实现 GaTA（消融：去 CLIP/SAM → 模糊扭曲；去 ResNet → 光照跑偏）

> 一句话：**用"强弱差距"当监督信号去训练增强器**——让弱模型在增强结果上的判断追上强模型的投票结论。

## 3. 我们照它做的探针（两轮）

### 3.1 第一轮：ADE-150 空间（强 CLIP 零样本投票 vs 弱 SegFormer-B0）

| 门 | 结果 | 判定 |
|---|---|---|
| G1 gap(GT)−gap(I) ≥ +0.05 | **−0.07 / −0.10** | FAIL |
| G2 gap(I)_apr − gap(I)_may ≥ +0.05 | +0.12 / +0.19 | PASS |
| G3 ρ(gap, α\*) ≤ −0.4 | −0.512 / −0.388 | PASS / FAIL |

**但随后查出 G3 是域级假象**：gap 在 apr 只取 {0,1}、**may 恒为 0**；域内相关 **apr −0.050 / +0.462（符号相反）**；仅用域标签预测 α\* 就有 ρ=+0.394/+0.489。
→ 说明我的操作化有缺陷（ADE 空间里两个模型都近乎乱猜）。

### 3.2 第二轮：ImageNet-1000 空间（忠实复现：CLIP 零样本(1000 可读类名, T=8 投票) vs ResNet18 a1_in1k）

| 量 | lovo_k2 | s2main10k |
|---|---|---|
| gap(GT) / gap(I) | 0.30 / 0.17 | 0.27 / 0.20 |
| **G1 gap(GT)−gap(I) ≥ +0.05** | **+0.13 PASS** | **+0.07 PASS** |
| **G2 gap(I)_apr − gap(I)_may ≥ +0.05** | **−0.22 FAIL**（方向反） | +0.11 PASS |
| ResNet 稳定率 GT / I | 0.53 / 0.48 | 0.53 / 0.42 |

**域内相关（决定它能否当逐图信号）**：

| 信号 | lovo_k2 apr / may | s2main10k apr / may | 一致性 |
|---|---|---|---|
| ρ(gap_I, α\*) | +0.138 / −0.402 | −0.112 / −0.279 | ❌ 符号翻转 |
| ρ(ResNet 稳定率, α\*) | −0.568 / −0.244 | −0.541 / +0.341 | ❌ 符号翻转 |
| ρ(ResNet 置信, α\*) | −0.591 / −0.363 | −0.197 / −0.130 | ⚠️ 四格同负但量级 0.13–0.59，弱 |

### 判决

- **A 探针 FAIL**（预登记要求两域同号且 |ρ|≥0.4；实际符号翻转）；
- **但 FoCo 的前提在我们数据上成立（G1 两臂 PASS）**：干净图（GT）确实让"强弱模型"更一致；
- **它不构成域判别 / 信任信号**——G2 方向在两臂间矛盾，域内相关不稳定。

## 4. 这次真正的收获：FoCo 的正确用法是**训练期监督**，不是测试期信任估计

FoCo 的两个模块都是拿基础模型去**训练增强器**（自监督、不需要配对 GT）。而我们"跨域没有 GT"正是它的用武之地。

| 我们原本的用法（FAIL） | FoCo 的用法（未试） |
|---|---|
| 用强弱差距**判断该不该动手**（测试期门控） | 用强弱差距**当损失训练修复模型**（训练期监督） |
| 需要"域判别"，单帧无观测 | 不需要域判别；弱模型追强模型伪标签即可 |
| 探针已判死 | **尚无证据，值得一试** |

**候选下一步（B'）**：在 S2 微调里加 FoCo 式监督——
- `L = L_rec + λ_FoFA·d(F^f(输出), F^f(GT)) 或 判别器特征匹配 + λ_GaTA·L_h(ResNet18(输出), CLIP 投票伪标签)`
- 预登记判据建议：**may 上对齐后 PSNR 相对无监督基线提升 ≥ +0.5 dB，且 apr 不掉 >0.3 dB**；同时报 harm-rate。
- 成本：训练级（6–12 GPU·h）；**先跑 1 个种子的最小版（~2 GPU·h）**看方向。
- 风险：FoCo 的自监督是**无配对**场景；我们有配对 GT，`L_rec` 可能已经占了大部分信息量，边际收益存疑 → 所以先小规模验方向。
