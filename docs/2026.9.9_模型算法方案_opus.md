# 贴膜透射 α-条件化分离：模型算法方案（2026.9.9）

> 角色：SIRR+图像复原设计评审 ｜ 日期：2026.9.9 ｜ 输入：ideas.md A–K、9.9 规划(E1–E4)、9.3 调研、郭组演进分析、9.8 轻量研讨、RDNet 代码实读。
> 结论先行：**形态 = 单模型 α 条件化分离（方案 2）；主方案 A（空间 α 头 + stem 级空间调制 + α 感知训练，从官方权重微调）；方案 B（零结构改动的训练技巧包）是必跑对照与兜底，架构 claim 由门槛消融裁决；方案 C（显式两段）不主推只作讨论位。第一优先的"两周实验"仍按 9.9 文档 E1→E2→E3 走，本方案喂给 E4。**

## 0. 问题再述（一段）

深色贴膜玻璃单帧透射复原：I = α_c(x)·T + R + n，α_c 为空间变化、逐通道、均值 0.05–0.3 的乘性衰减，R 不经过膜、占据主要亮度预算；目标是单帧恢复与 T 池曝光语义一致的全亮度 T（去膜+去反射一体，非"提亮"）。已判死：全局乘性提亮（相对对比不变，信息增益为零）、RemoVal 数值协议、实拍域微调（无数据）、循环/扩散/蒸馏宏大叙事。**本方案的信息学支点一句话：逐像素、逐通道的 α 反演恢复的是"被膜压掉的相对对比"，这与 L 级的全局提亮有本质区别——只有当增益场未知且空间变化时，恢复才携带新信息；α 场的不可观测歧义（α·T 乘积）由训练分布先验消解，这也决定了评测必须分层。** 数字主战场 = 合成贴膜退化域（唯一像素级 GT），实拍只做定性。

## 2. 方法形态裁定（问题 1 的结论）

**裁定：方案 2——α 条件化分离：一个网络、α 为带监督的辅助头（训练期 GT α map 监督，推理期自估）、α̂ 以空间调制方式喂回自身主干。不做显式两段。** 理由（每条带为什么）：

1. **α 与 T 只在乘积中出现，α 的"位置+强度"是模型唯一能拿到衰减布局的通道**——而衰减布局决定哪里要放大、放大多倍、哪些像素其实纯属 R（不该放大）。这个信息必须在特征流内可用，而不是只在 loss 里被隐式统计：loss 重加权只能平衡梯度量级，无法在强 R 淹没处告诉网络"这是被压暗的 T 边缘"。这是"进网络"与"不进网络"的本质差别。
2. **联合单模型是"合成→实拍"泛化上最稳的形态**：训练期 α 监督来自合成器（零成本、像素级、逐通道），推理期唯一输入仍是 I——训练/推理计算图完全一致（都从 I 自估 α̂），无两段式的训练-推理错配；显式两段（方案 3）的 α 估计误差无法被下游校正、要训两套协议、推理仍须合一，只在联合训练不稳时作 fallback。
3. **为什么不走完全隐式（现状 RDNet 的全局 prompt 已是雏形）**：隐式 α 无法监督、无法可视化、α̂ 无独立指标——论文将失去"α 感知"的可证伪证据链（α 头 MAE + ᾱ 分档曲线）。加上 6 维全局标量在空间变化 α 前结构性不足（E1 zero-shot 预期崩塌即此因）。
4. **单模型仍要刻意保留一个"α 不注入"的孪生配置（=方案 B）**：它既是消融对照，也是架构 claim 的撤回点——见 §6 G3。

## 3. 候选方案 A / B / C

**方案 A（推荐，主 claim 载体）：αTAP-RDNet——空间 TAPG + stem 空间调制**
- 改动点（对齐代码）：① `classifier.py` 的 `PretrainedConvNext` 冻结全局 head（6 维）改为**解冻 convnext_small 特征 + 轻量空间 head**（在 (B,768,h/32,w/32) 特征上 1×1 conv→64→ReLU→1×1 conv→3，sigmoid 出 α̂_c∈[0,1]，上采样到输入分辨率；~0.5M 参数）。② `RDnet_.py` 只动 `forward`（约 L168–192 区域）：`x_stem` 前乘空间调制 `x ← x_stem ⊙ (1 + λ·Conv3x3(α̂))`（逐通道逐像素 scale，λ 可学初始化 0.1 保证不破坏预训练行为）；原 6 维 prompt MLP 保留，输入改为 α̂ 的全局统计（GAP+LogSum）派生，保持列结构零改动。③ 可选进阶行：各 Level 输入 FiLM（α̂ 逐尺度池化后通道仿射），~100 行，不动 ReverseFunction（α̂ 对输入确定性，可逆重计算安全）。④ 损失见 §4。
- 训练：官方 rdnet ckpt 初始化（含全部可逆列），**两段式：先解冻 columns+新 α 头+prompt（冻结 FocalNet），跑通出数；有余力再解冻 backbone 精修**。315M 中 ~80% 参数在冻结骨干时不动 → 12GB 可行性大幅改善。
- 代价：代码改动 ≤1.5 周；训练 4–8 GPU·日（4 卡×2 天量级）出第一版全 ᾱ 档数字。预期：ᾱ≥0.3 档与 B 拉不开，ᾱ≤0.15 档领先 B 0.3–0.8dB（待验，这就是 claim 所在）。

**方案 B（兜底 + 必跑对照）：零结构改动训练技巧包**
- 内容：RDNet 原架构（甚至可冻结 FocalNet）+ 同合成数据 + ① α 感知逐像素重加权像素损失（权重见 §4）；② 独立小 α 头（仅训练、输出用于 loss 加权与 α MAE 报告、不注入网络）；③ 物理一致性 loss；④ RefMix(低档位)。
- 定位：回答"重加权+同域重训是否已够"。若 A−B < 0.3dB（ᾱ≤0.2 均值），**架构 claim 撤回，论文方法 = B + 失效分析 + 基准**（9.9 E4 决策门的执行者）。参数量 0 增量。
- 观点（问题 2 的直接回答）：**不期望纯重加权在 ᾱ<0.2 稳定拿到 >0.5dB**——重加权系数 ∝1/α，暗像素处把噪声与 R 残差的梯度同时放大，不截断必炸、截断后增益有限；它解决"梯度被淹没"却解决不了"强 R 区 T 可分性弱"，后者需要条件线索。但这条是**经验判断不是定理**，所以 B 必须与 A 同协议同跑，用数字裁决，不要预判到省略 B。

**方案 C（讨论位，不主推）：显式两段（α 估计器 → (I, α̂) 拼输入分离）**
- 何时启用：仅当 A 的联合训练出现不稳/不收敛才 fallback。否则只写进 related/讨论。理由见 §2.2。

## 4. 损失与监督（问题 3 的结论）

总损失（A 配置）：
`L = L_T + w_R·L_R + w_α·L_α + w_c·L_cyc [+ L_smooth]`，各部件判断：

1. **L_T（主力，必贡献）**：像素 L1（或 Charbonnier）+ 梯度 L1 + MS-SSIM，**逐像素权重 w_c(x) = clamp((0.15/α_c(x))^0.5, 1, 8)**（α 用 GT——加权是"教网络重视被压区域"，与注入用自估 α̂ 解耦，避免训练早期 α̂ 噪声污染加权）。截断上限 8 是必须的：不截断则 α→0.05 处权重 20+，噪声梯度主导。目标 = 全亮度 T（GT 与合成渲染同源同曝光语义）。
2. **L_R（必保留，RDNet 原有 ×4 权重照搬）**：R 是能量主层，弱监督会让网络把 R 残留进 T̂ 的暗区（那里误差被 1/α 加权放大，最贵）。R 侧无需 α 加权。
3. **L_α（α 头监督，必贡献，~0.1 权）**：L1(α̂_c, α_c) + 轻 TV 平滑（α 物理平滑）。这是"α 感知"叙事能被独立度量的唯一来源，论文资产。
4. **L_cyc 物理一致性 ||I − (α̂⊙T̂ + R̂)||₁（大概率小贡献，保留作一行消融）**：GT 已全覆盖 α/T/R，前向回环的增量信息有限；它的真正价值是约束 α̂ 与 T̂ 的乘积不自相矛盾、给实拍定性一个合理性 check。判"小贡献项"而非"装饰"：成本一行，留。
5. **暗区结构/对比 loss（不单独设，判为装饰）**：重加权 + 梯度项已覆盖暗区；再设暗区 mask 项会与 w_c 重复并引入 mask 阈值超参。**若消融显示 α≤0.1 档结构指标仍差，再补局部对比项，不进默认配置。**
6. **感知 loss（保留 VGG L1（RDNet 原有 t_vgg 0.1 权），LPIPS 可选消融）**：T̂ 全亮度域与 VGG 特征域匹配，原权直接可用；LPIPS 大概率与 VGG 项冗余，作收尾消融即可，不默认加。

## 5. 训练协议（问题 4 的结论）

- **形态：官方权重微调为主，不做从零训**——平衡域预训练提供 T/R 解耦与纹理先验，合成数据池有限（516+2000 母本）撑不起从零收敛全亮度增益映射；两段式（先冻结 FocalNet 训头/列，后精修）既省显存又稳。
- **12GB 可行性判断（基于代码实读）**：官方训练 320²、bs2、fp32 在 12GB 紧。可逆列（save_memory=True，代码已内置）已省激活；再叠 AMP（scaler 已内置）+ 冻结 FocalNet（~196M 无梯度）+ 256² crops 即可在 12GB 稳跑 bs2–4；bs1@320 + grad accum 4 用于最终档。8×3080Ti 共享：跑 2–4 卡 DP 即可，**按 ᾱ 档位做卡间分层**（每卡固定吃 1–2 档的 batch），天然实现课程采样。
- **合成数据铺法**：T 池 = scenes 2000 + augmented label 516（真实照片），渲染前乘曝光抖动 e∈[0.6,1.4]（目标 T 同步乘 e，保持自洽）；R 池 = reflections + reflection_textures（4633）+ augmented reflection，含真实自反射人形子集（有则用，无则从 R 池取人形贴片合成），多层 blur/ghost/对比沿用 data_v4 的双玻参数族；α 场生成 = 全局档位（ᾱ 分层抽样 LogU(0.05,0.3)+1.0 平衡档，训练 batch 内按档位均匀，防低档欠采样）+ 平滑低频随机场（渐变膜/划痕/1/f 纹理，垂直拉长模拟贴膜工艺）+ 逐通道色偏 τ_c∈±15%；β 与 ᾱ 联采（ᾱ 越小 β 可越大，占走亮度预算）；噪声 n 取 data_v4 的 sensor_noise iso 400–6400。**测试集固定 seed 落盘**（每档 50 对，α 场固定、噪声固定），全论文不可变，保公平。
- 平衡域防遗忘：训练 mix 10–20% 原 ᾱ∈[0.8,1.0] 合成对（ReflectionSynthesis 现有代码 alpha_range 改小成本极低），保住标准集坐标不崩。

## 8. 决策门与两周内第一版实验路径

**决策门（与 9.9 文档联动）**：
- G1（第 1 周，E1）：ᾱ=0.2 处 zero-shot 掉幅 <1dB → 加重 β/噪声再测；>3dB → story 坐实。
- G2（第 2 周，E3 归因）：α<0.2 残差以暗丢失为主 → A 全配投入；以反射残留为主 → 主线转"分离强化"（加强 R 监督与 T/R 解耦），α 条件降级。
- G3（第 4 周，M2 vs M3）：A−B ≥0.3dB（ᾱ≤0.2 均值）→ 架构 claim 成立投 A；否则投 B。
- G4（M5 oracle-α）：全配 − oracle <0.3dB → α 头够用；否则换更精 α 头或写 limitation。

**两周路径（9.10–9.24，首日产出排序）**：
1. D1 冒烟：12GB 显存实测（320² bs1-2 AMP+冻结 FocalNet 梯度表）+ 官方 ckpt 加载改造后模型 forward 对齐（半天）。
2. E1 合成器 + zero-shot ᾱ 扫描曲线（第 1 周）——含"潜空间加法性"小测（GenSIRR 前提佐证）。
3. E2 oracle 三对照 + E3 归因（第 2 周，与 E1 并行）。
4. 在 E1 完成当刻即起 M1/M2 单档（ᾱ=0.15）小 pilot（2 卡×1 天，224²，1000 iters）——提前拿 M2 vs M3 的 Δ 信号，不等全量。
5. 产出：合成器+测试集落盘、三张论文图、10 行方法决策书（A/B 取舍 + G2 支路裁定）。
