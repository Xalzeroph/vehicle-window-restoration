# 2026.9.3 Transfer-Init 批判式评审（存档）

> 对象：`2026.9.3_联合迭代分离增强_idea.md` §9（迁移初始化：借用去反射/低光两领域成熟权重 + 3000 对自建数据微调）
> 评审方式：Claude Opus（pro 级模型）批判式论证；联网核实 10+ 文献（NTIRE/RDNet 微调惯例、GFRRN、DMDNet/NightIRS、ExpoMamba、MR-SDformer、CoLoRA/UIR-LoRA/Edit2Restore、DAP-LED 等，见文末引用）。
> 判定：**需修改后可行** —— 作为训练工程手段成立；作为论文卖点 /"迁移先验"claim 不成立；有一处**前提性错误必须先修**（MR-SDformer）。

---

## A. 数学与先验审视

**A1 偏移类型与负迁移判据。** 设预训练任务 h 的最优解 θ_p。RDNet 域到车窗域是**三重偏移叠加**：(i) 协变量偏移（输入亮度/α/噪声统计）；(ii) **标签/任务偏移**——RDNet 输出语义是 α≈1 下的"正常亮度透射层"（满足 I=T+R），车窗域的监督目标是 αT̂（或增强后的 T_GT），输出层需重定标 ~1/α×（乘性链上 α 与增强增益不可分，见方案 L 评审 A2，此处正是其工程表现）；(iii) 低光头来自**另一任务族**（LLIE 假设无反射），属跨任务迁移。判别式复原网中 θ_p 的可复用部分 = 低中频滤波器与"可逆双流分离"的结构先验；不可复用部分 = 输出头尺度、TAPG 的 (α,β)≈(1,0.5) 调制分布、BN/统计层。**负迁移的可操作判据**：比较 FT 与 scratch 两条 loss 曲线下方面积——若 θ_p 起步处 ∂L_t 与 L_h 残留主方向近乎正交（统计量：两任务梯度余弦），网络须先付"遗忘预算"（GFRRN 的 FFT 崩落正是此机制的极值）。判定实验：只比较终值 PSNR 不够，必须画 **epoch-loss 交叉曲线**。

**A2 双先验同时被违例的冲突机制。** 三个传播通道：(i) **重建恒等式差 α**：RDNet init 下输出头近似满足 I=T̂+R̂，微调目标变为 I=αT̂+βR̂，早期 L_recon 会把亮度差"判"进 R̂（对应已见"反射强时去不干净"）；(ii) **接缝口径**：ConvNeXt/LN 与低光类 U²-Net 的 BN 统计不同源，8–16GB 小 batch 全量微调时 BN running stats 会崩；(iii) **共享列梯度拔河**：增强 loss 的亮目标与分离 loss 的暗目标沿同一 T 列回传。**"先各自域内微调再联合"不是冗余**：四步法天然给出两级监督——黑布帧对（无反射 αT→GT）可独立微调低光头，混合帧对可独立微调分离头（R_GT 可推导）；分步把 (i)(ii)(iii) 逐级消解，代价仅数天。直接异域双头联合起步大概率不稳 → **分步为必做工程步骤**。

**A3 3000 对尺度与 PEFT。** 前提"3000 对不足以从头学"对低光头**不成立**：LLIE 界从头训的量级就是 485–900 对（ExpoMamba/RetinexFormer 在 LOLv1/LOLv2 的训练规模）。真正的稀缺在于 α(x) 物理未知、**无法合成贴膜域**——预训练 init 的真实价值是替你做不了的事：用 α≈1 域先验替代"α<<1 合成预训练"。若 3000 对只需学"乘性 α 扭曲 + CRF/噪声"，那是全局光照型偏移而非语义型——**全量微调安全，主干 LoRA 反而过约束**。GFRRN 结论（Swin-L 分类语义骨干 + FFT 崩）**不可外推到判别式复原主干**：其崩因是跨任务 + 巨型骨干 + 极小数据三者叠加；同任务同尺度的正例恰是 NTIRE 惯例——在 OpenRR-5k（5k 规模）上全量微调 RDNet 官方权重即可达挑战赛前列（YuFans 34.90dB 第 5）。PEFT/zero-init adapter 只应出现在**新增部件**（α head、融合接缝）——MR-SDformer 自身（HCE zero-conv 初始化）与 DA-CLIP 系（zero-init 防微调毁特征）均有先例。

**A4 收益趋零条件与干净对照。** 若任务结构差异大到现有权重只能提供暖启动（架构拓扑改了、分解恒等式变了），init 收益 ≈ 省下的训练时长。因此 claim 只能写"预训练初始化 + 微调获得 X"，**不得写"迁移了反射/低光先验"**，除非证明特征口径在 α 变化下不变。对照组：scratch（同预算同增强）vs FT vs scratch×3 预算（上界，仅当 FT 优势 <0.3dB 才做）。

## B. 文献验证

1. **微调惯例**：NTIRE 2025 SIRR 补充材料明确记载从 RDNet 官方权重加载 + 微调、两阶段协议（先冻结 ConvNeXt 训 TAPG 头、再解冻 MCRE）——**应直接照抄的配方**；同域正证据充分。**跨域反证据**：LLIE 跨数据集失败是常态（LOL 训练模型在实拍/跨相机上出伪影；LOL 基准间存在 train/test 泄漏，NeRCo 灰 PSNR 离群即泄漏产物——具体篇目待核实；"bilevel fast scene adaptation" arXiv:2306.01343 佐证裸微调不泛化）。
2. **MR-SDformer 前提错误（必须修）**：它**不是低光单任务模型**——全名 "Maximum-Value Retinex decomposition guided generative priors for joint deraining and low-light enhancement"（Information Sciences 739 (2026) 123136）；其低光能力大部分锁在**冻结的 SD2.1**（200 步 DDIM）里，可训部分仅 LRNet(7.7M) + HCformer。要拿的"判别式低光先验"在 MR-SDformer 上**不以可迁移权重形式存在**。ExpoMamba 才是合格的判别式低光头；两个低光模型拼接本身无意义，取一个即可。（用户侧以本地 PDF 为准复核。）
3. **DMDNet/NightIRS（arXiv:2601.00322）**：采集协议 = T 撤板直拍、I 插板拍、R 相机转向**黑靶**——与四步法同构但**无补光 GT、无 α<<1 衰减**；NightIRS 仅 1000 组且据摘要用于评测（是否参与训练：待核实）；**其训练是否从单任务权重初始化：公开摘要未披露（待核实，须查其代码仓库）**。"两单任务预训练头拼接微调"在图像复原中**无直接先例**；最近邻反证：DAP-LED（arXiv:2409.13496）明言串行 off-the-shelf 模型产生伪影、须联合学习——支持"联合微调"动机而非"拼接"动机。
4. **PEFT 实证**：CoLoRA/PROD（ECCV 2024，arXiv:2408.01099，合成多退化预训练→小真实数据微调，LoRA 胜 FFT）；UIR-LoRA（arXiv:2409.20197）；Edit2Restore（ECCV 2026 作坊，arXiv:2601.03391，16–128 对微调 12B FLUX，感知指标胜百万级基线而像素保真非其目标）——共同结论：**PEFT 的赢面在"大骨干/生成先验 + 感知目标"，车窗任务（α<<1 细节保真）恰在其输面一侧**。

## C. 实证设计（必做 E1–E4）

- **E1 init 消融 2×2**：两模块各"随机 vs 预训练 init"，同预算同增强 + **epoch-loss 交叉曲线**（负迁移判据）。
- **E2 遗忘双指标**：车窗评测 + Nature/Real20 保留度。
- **E3 域偏移量化（关键）**：补拍同照明"无膜黑布"帧（10–20% 子集）得 α̃(x) 分布，再用 α̃ 对标准 SIRR 对做乘性重标定合成诊断——E3 若成立（偏移≈乘性），全量微调 + 轻头即可，Transfer-Init 整体成立；若不成立，坐实迁移不可行，弃头改随机 + 重新合成。
- **E4 分步（冻结交替）vs 直接联合**。
- **浪费项**：PEFT 矩阵扫描（LoRA rank/层位）、逐层迁移率测量（架构已改无意义）、scratch×3 预算（留作 E1 触发项）。
- 注：方案 L 评审的 V1（oracle 反馈上限）仍为最高优先，与 E1 无依赖、可并行。

## D. 结论

**需修改后可行。** 亮点：分步监督被四步法天然支持；与修订方向正交——若最终走单向"先增强后分离"，两模块各自域内微调后级联即为现成高基线，接头冲突问题基本消失；Transfer-Init 抬高公平基线后，α(x) 建模的消融增量才能被干净读出——**这才是它在论文中的真实角色（工程手段，非贡献点）**。

**必须改**：
1. 删除"MR-SDformer 作为低光先验源"的表述（前提错误），或明确其权重只作 LLIE 基线；
2. 定位改写为"组件可靠化工程手段"，不作为贡献点单列；
3. 微调方案定为：**全量微调 + zero-init 接缝 + 分步**，PEFT 仅用于 α head；
4. 先跑 E1/E3 再投算力，否则无法区分"迁移有效"与"只是训得久"。
