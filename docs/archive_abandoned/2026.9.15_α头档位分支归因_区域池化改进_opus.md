# 2026.9.15 α 头档位分支失败归因与区域池化改进（Opus 子代理探针分析）

> 缘起：重建无泄漏匹配池后（见 `2026.9.15_α头失败根因分析_域不匹配与指标退化_opus.md` 文首修正框），
> 域匹配只救掩膜（taps AUC 0.762→0.845）不救档位（acc 0.556→0.333/0.361）。用户问"这个机制为什么失败、
> 要改进该用什么结构"，以 Opus 子代理做只读探针归因 + 方案设计。
> 探针脚本已入库：`scripts/probes_0915/probe_fac_features.py`（GPU 4 min）、
> `probe_level_stats2.py`、`probe_level_regionstats.py`（CPU）。**未启动任何训练。**

## 1. 判决（三层，含判据）

**(b) 架构层 = 主因。** 输入消融（用 `fac_taps_long` ckpt 的特征离线重放档位头）：
- 把 GAP+GMP(256 维) 置为训练池均值 → 模型对**所有**图恒判 0.6（acc 0.333）
- 把 21 维原始统计置为均值 → acc 与 p 分布几乎不动（v2.1 0.556→0.528，indomain 0.806→0.806）

⇒ **21 维统计是死输入；档位判决 100% 来自 backbone 全局池化**。跨域线性探针（同特征、200 场景拟合）：

| 特征 | →v2.1 acc | →indomain acc |
|---|---|---|
| gap+gmp(256)（模型实际在用的） | 0.556 | 0.806 |
| stats21（原始统计） | 0.722 | 0.722 |
| **GT 掩膜双区域池化 + 差分 + stats** | **0.889** | 0.722 |
| 模型 m̂ 掩膜同款（IoU 0.69） | 0.694–0.778 | 0.583–0.778 |

gap+gmp 探针与模型两域 acc 逐位相同 ⇒ 头部≈该 256 维的线性读出。全局池化把膜内 82%/膜外 18%
混成一个不变量，无法构造"膜内−膜外"比较，只能学域纹理签名 → 跨域即失效；这也解释匹配池训练反而
把 indomain 档位打坏（捷径被破坏后无处可依）。

**(a) 信息层 = 非硬墙。** 域内单帧档位 LOO 0.917（v2.1）；跨域探针 0.72–0.89。可迁移线索只剩**相对量**：
I=αT+R 中档位只经"αT 与 R 能量比"进入单帧观测量（r_obs≈0.3–1.0），T̄/R̄ 拆分不可知 ⇒ 单帧档位=
先验依赖后验。**"膜内/膜外原始对比度比值"本身不可用**（v2.1 AUC 0.24–0.67，被两区域内容差主导，
scene-σ 0.15–0.33 ≫ 档位效应）——相对量必须做在**特征/亮度级**。9.13"单帧可辨识上限"宜改口径为
"**域内可辨、跨域需标定**"。

**(c) 优化/损失 = 次因。** 训练样本 ĉ=0.997/0.598/0.300、acc 0.993、L_c≈0 → 非欠训练。但两缺陷真实：
①输入尺度不对称（21 维未标准化、量级≤0.7 vs 256 维单位量级）配捷径解 → 死输入；
②L_c 目标是名义档 {1.0,0.6,0.3}，数据里膜内 GT ᾱ=0.726/0.594/0.299（1.0 档系统性差 0.27），
CE+相对 L1 不治校准——实测 v2.1 ĉ=**0.624/0.448/0.300**（高两档压向中间档）。

## 2. 改进方案（3 个）

**方案 1（主改）m̂ 条件化双区域池化 + 显式相对量**：`_fac_heads` 内以 m̂（下采样 h/2、软权重）池化
feat：f_in=Σm̂f/Σm̂、f_out=Σ(1−m̂)f/Σ(1−m̂)；取 Δ=f_in−f_out、R=f_in/(|f_out|+ε)，并加低维物理量
（三通道膜内/外均值差及相对版）；档位头输入=[LN(stats21), LN(Δ), R, 亮度相对差]→MLP(≈280→64→3)。
注意力变体：f_out 作 K/V、f_in 作 Q 的 1 层 cross-attention（2 token）。**新增参数 ≈25K**。
预期 v2.1 0.556→0.78–0.89、indomain ≥0.75。风险：掩膜耦合（需软加权+面积兜底）；分辨率敏感
（v2.1@224 掉至 0.69）。

**方案 2（配套、近免费）序数回归 + 目标换 ᾱ_eff**：去 3-way softmax 改 2 阈值序数（或直接回归 ĉ），
L_c 目标改每图 GT 膜内 ᾱ。探针：相对特征 Ridge 预测膜内 ᾱ，v2.1 MAE **0.080**（模型 ĉ 0.099）、
斜率 0.59。预期治"低一档"（校准病）。风险：弱线索下收缩到均值，需保留 L_rank margin。

**方案 3（训练协议）T 域增广 + 相对量一致性**：训练池对 T 做亮度/对比度/γ 抖动，加"同场景三档相对
特征按 ᾱ 等距"一致性项，打掉域纹理捷径。依据：匹配池实验证明捷径不可依赖。风险：牺牲 indomain
上限，需与 A 域混训。

## 3. 最便宜验证（均已跑）

- **V1** 零训练 CPU<2 min：stats21 跨域 0.722、全局 std 档间差 0.003（vs 训练池 0.033）。通过线：跨域 ≥0.70（现状 0.556）。
- **V2** 单卡 4 min：(i) gap+gmp 探针=模型（0.556/0.806）；(ii) **m̂ 版相对特征 →v2.1 ≥0.70 且 indomain ≥0.70**（现状 0.694–0.778/0.583–0.778，边界通过）；(iii) GT 掩膜上界 0.889。若 (ii) 不过，先修 m̂（IoU 0.69）再上架构。
- **V3** 方案 2 检查（零训练）：MAE ≤0.10 且斜率 ≥0.5（现状 0.080/0.59，通过）。
- **上机唯一判决门**（后续 ~30 min 单卡）：v2.1 档位 acc ≥0.75 且 indomain ≥0.75 且 naked 破 0.771 常数基线。

## 4. 兜底口径

若 m̂ 版 V2 不过门或重训后仍 <0.70：不写"单帧 α 估计"，改写为——
① 可迁移的是**掩膜**（AUC 0.84）；② **档位 = 域内后验**（域内 0.72–0.92 可读，跨域必须标定）；
③ "全局池化 → 域纹理捷径"作**负结果诊断**入文（消融 + 探针 0.556 vs 0.889 是干净对照）；
④ "膜内外相对量"作方法论改进（附零训练验证）；⑤ 评测删 naked 0.90 门限、常数基线常驻。
失败即"可辨识性边界 + 结构改进"贡献。
