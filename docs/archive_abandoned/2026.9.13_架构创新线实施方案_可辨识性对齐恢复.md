## 0. 一页总览

**目标主张**（现实版，不吹分）：
1. **永不更差**：任何场景/档位下，端到端不低于 B 臂（v0）；
2. **可辨识区兑现增益**：重膜档（ᾱ=0.3）≥ B +0.3 dB；film 区 never-worse 成立；
3. **带校准的不确定性**：档位后验 + 覆盖率保证的区间（conformal），恢复算子消耗区间上界；
4. **边界/分割一等指标**：mask IoU / boundary-F1 作为独立可发表结果；
5. 论文叙事 = **负结果作动机章 + 理论指导的架构设计**（"不可辨识→因子分解+安全算子"）。

**非目标**：全面超越 B 的大幅 dB 增益（探针 v5/v6 已证伪这条期望；dB 主增量另寄组件④）。

**成本总览**：S0 数据（CPU 半天）→ S1（<1 GPU·h，只训头+算子）→ S2（约 1 GPU·日）→ S3（1-2 GPU·日）→ S4 评测（半天）。每步带门，不过即降级。

## 2. 组件①：分解式 α 头（Factorization Head）

### 2.1 参数化

与生成器结构同构：`α(x) = 1 − m(x)·(1 − c·g(x))`，其中
- **m(x)**：覆盖率掩膜（膜内=1）——**可辨识部分**，边界是主要监督对象；
- **c**：档位 ᾱ∈{1.0, 0.6, 0.3}（可选扩展到连续）——**不可辨识部分，输出后验**；
- **g(x) = 1 + s·f(x)**：膜内空间缓变增益，先验有界 g∈[0.7, 1.3]（生成器 s=0.3）。

三个子头共享现有 fused 特征（128@h/2；taps = adapter[0]∘x_stem + adapter[4]∘c3）：

```
z_m  = Conv(128→64→1)                  → m̂ = σ(z_m)            (1ch @h/2 → 上采 full)
z_g  = Conv(128→64→1)                  → ĝ = 1 + 0.3·tanh(·)   (有界，匹配 s 先验)
level: GAP+GMP(128×2) ⊕ 全局统计(21d)  → MLP → p∈Δ³ (softmax) → ĉ = Σ p_k·ᾱ_k
α̂ = clip(1 − m̂·(1 − ĉ·ĝ), 0.05, 1.0)   （naked 锚定由构造保证）
```

要点：
- **naked 锚定变成结构性**（m̂→0 ⇒ α̂→1），不再依赖 κ_naked 加权硬拉；
- 掩膜标签用**可观测膜指标** `m_lab = 1[α_GT < 0.95]`：档 1.0 下 g≥1 的膜像素 α 被 clip 到 1.0，物理上与裸区不可分（这也是档 1.0 最难的根因），监督这类不可观测像素会教出幻觉；
- 保留 `alpha_refine`（cat[up, I] 残差细化）不动，全分辨率边界精修可选升级；
- 初始化：调 z_m 偏置使初始 ᾱ̂≈0.5~0.7，避免重演 A_sat 冷启上移→除法放大→PSNR 10.9 的崩点。

### 2.2 损失

| 损失 | 形式 | 说明 |
|---|---|---|
| L_mask | BCE(m̂, m_lab)·w_b，w_b = 1 + 5·edge_band(m_lab) | edge_band = 形态学梯度后膨胀 3-4px；边界是主监督 |
| L_g | L1(ĝ, g_gt)·m_lab 归一化 | g_gt 由重渲落盘（D0） |
| L_c | CE(p, level) + 0.5·|ĉ−ᾱ|/ᾱ | 序数项压 Ĉ 的期望误差 |
| L_trip | L1(m̂, m̂′) + L1(ĝ, ĝ′)，**只在双方 α_GT<0.95 的可观测像素上** | 跨档一致性（同场景三连图，D0 构造） |
| L_rank | margin: ĉ(l=1.0) > ĉ(0.6) > ĉ(0.3)，margin 0.1·ᾱ | 序数约束 |
| L_α（辅助） | 现有 log 域 L1 × T_GT ×(1+10·band)，去掉 κ_naked | 保留原配方做正则 |

### 2.3 单元测试级自检（S1 前置）

- 前向形状：z_m/z_g @h/2、p∈Δ³、α̂ full-res，参数量 +≤0.1M；
- 初始 α̂ 均值 ≈0.5-0.7、naked 区 ≈1.0（结构性检查）；
- 三连图 batch 组装：同 scene_id 的 3 张进同一 batch（batch = k×3）。

### 2.4 特征源配置（P0 翻案实验内置）

`--encoder {taps, raw}`：
- `taps`：上述既有特征（默认）；
- `raw`：独立轻量编码器（4 级 conv，base 32，输入 = RGB + 廉价统计通道（box-mean×3 尺度，同探针 1），输出 128@h/2 特征，~2-3M 参数），**完全不用 FocalNet**。
同样的头、同样的监督，只换特征源——过/不过 G1 即是对"特征源假设"的判决。

### 2.5 训练协议与成本

- 只训头（沿用 `--alpha-only` 单列前向，0.085 s/it 量级），外加**缓存 R̂_B** 供算子训练；
- batch 6（2 场景×3 档），3000-4000 iter，lr 1e-4，AMP；
- 成本：缓存 R̂_B（2700 图，~6 min）+ 训练 10-20 min ≈ **<1 GPU·h**。

### 2.6 判定门 G1

| 指标 | 门限 |
|---|---|
| naked 锚定率（α_GT≥0.95 区 α̂ 均值） | ≥0.90 |
| film spread（档1.0 与档0.3 的 film α̂ 差） | ≥0.40（GT 0.42） |
| 级别内 corr | ≥0.7 各档 |
| mask IoU / boundary-F1 | ≥0.85 / ≥0.6（口径见 §9） |
| 档位 acc | ≥0.70 |
| **raw 编码器对照** | 若 raw 在 naked/spread 上 ≥taps −0.02 → 特征源假设翻案（B 组路线复活）；若两者同水平 → 平台归因坐实（写进论文诊断章） |

## 3. 组件②：保守除法算子（Risk-Averse Operator）

### 3.1 形式化

给定冻结的 R̂_B（T0 = I − R̂_B）与 α 的后验，求 `T̂ = clip(T0 / α̃, 0, 255)`，α̃ 由**非对称风险**决定：

```
α̃* = argmin_α̃  E[ w_b(x)·|T0/α̃ − T | ],   w_b = 1 + λ_o·1[T0/α̃ > T]   (λ_o ≈ 3)
```

即：**过曝代价为欠曝的 (1+λ_o) 倍**；最优点系统性偏向"少除一点"。同时硬约束：
- **裸区永不除**：`m̃ = m̂·1[p_max ≥ 0.5]`，`α̃ ← 1 where m̃ < τ_m (0.4)`；
- 熵门可选：`w = m̃`，`T̂ = w·T̂_div + (1−w)·T0`（默认关闭，作消融项）。

### 3.2 关键发现：端到端最优 α̃ ≠ GT α

v4@0.3（+0.70）> v3@0.3（+0.38）证明：冻结 R̂_B 在低档欠分离（隐式除数 0.342 > GT 0.293），除"GT α"不是最优——**算子必须针对 R̂ 校准，而不是追求 α 估计精度**。这是本组件的方法论卖点：解耦"估计"与"算子标定"。

### 3.3 两级实现

- **A 级（闭式，先做）**：`α̃ = 1 − m̃·(1 − ĉ·ĝ·κ_lv)`，κ_lv 为 3 个档位标量。初值由"隐式除数拟合"给出：在训练三连图（有 GT T）上做 1-D 搜索 `q(lv) = argmin_α E||T0/α − T||`（分档、分膜/裸区），κ_lv = q(lv)/(ĉ·ĝ̄)。然后 κ_lv 再随头端到端微调（仅 3 个参数，统计安全）。
- **B 级（学习，过门后）**：小卷积算子（3 层，输入 [T0, m̂, ĉ·ĝ, ĝ, 熵图, I 亮度]）→ 乘性残差场 δα，α̃ = α̃_A·exp(δα·m̃)。防过拟合：输出限制 ±0.3、dropout、权重衰减。

### 3.4 训练/评测与门 G2

- 训练：L_op = 上式非对称 L1（charponnier 平滑）；α 头输出 detach（算子不通过头反传，避免头被算子目标带偏）；
- 评测：全档 + 逐场景 Δ vs v0；另出"保守度扫描"曲线（α̃ 整体缩放 γ∈[0.8,1.2]× 下的 PSNR）作为论文图。
- **G2**：逐场景 min Δ ≥ −0.10 dB；均值 Δ ≥ 0；档 0.3 ≥ +0.30 dB。过不了 → 保守算子退化为"等于 B + 区间"，主张缩回 never-worse。

## 4. 组件③：反吸收训练（Anti-Absorption / 跨档不变性）

### 4.1 病理与机制

已观测：A 臂长训练 R̂ 退化、低档 oracle 增益被吃掉——R̂ 把 α̂ 偏差"吸收"进参数（pilot §6/§7）。生成器结构给出免费监督：**同一场景三档共享 T、R、m，只有 α 变**。所以：
- **R̂ 跨档不变**：`L_Rinv = Charb(R̂(I_l) − R̂(I_{l′}))`，三档两两，权重 (1−sat)；
- **形状跨档不变**：沿用 ①的 L_trip（在可观测像素上）；
- **梯度隔离（防即时补偿）**：两种方案任选——
  - 联合 + detach 方案（默认）：L_R 对 α 支路 stop-grad；L_op/L_α/L_trip 对 R 支路 stop-grad（除法路径保留物理耦合）；
  - 交替方案（兜底）：α 头+算子训 500 iter ↔ R 支路训 500 iter 轮转（α-only 模式快，轮转成本低）。

### 4.2 健康指标（每次评测记录，训练全程追踪）

- **隐式除数漂移** `q(lv)`（§3.3 口径）：健康状态应向 GT 0.717/0.582/0.293 收敛，而不是停在 0.61/0.51/0.34；
- R̂ 质量：vs GT R 的 PSNR（膜区/全图）；
- e2e Δ vs S1。

### 4.3 协议与门 G3

- 联合训练把 R 支路解锁，4000-6000 iter，lr 减半（5e-5）；3 seeds（最终数字）；
- 成本 ≈ 1 GPU·日（按 α-only 0.085 s/it、全网络约 3-4× 外推，跑前校准）；
- **G3**：q(lv) 误差较 S1 基线减半；e2e ≥ S1（不退化）；R̂ PSNR ≥ S1。

## 5. 组件④：条件化分离骨干（dB 侧主赌注）

oracle 数字表明 α 做满仅 +0.4~0.7 dB，**dB 大头在 R̂ 侧**（域适配 +5 dB 已证有肉）。三个递进选项：

| 选项 | 机制 | 成本 | 说明 |
|---|---|---|---|
| ④a 输入增益归一 | I′ = clip(I / clip(α̃, 0.3, 1)) 后再过 RDNet，输出反缩放 | 小时级，无训练 | 贴膜≈空间衰减片，先归一化再分离，消除 backbone 域漂移；免费试 |
| ④b FiLM 条件化 | 贴膜嵌入 e=[p(level), ĉ, m̂ 覆盖率, 统计] → FiLM γ,β 注入 5 个 adapter tap | 0.5-1 GPU·日 | backbone 仍冻结，只训 adapter+条件网（~1.1M→1.3M） |
| ④c DA 组合 | 既有 +5 dB 适配配方 + ④a/b | 1-2 GPU·日 | 论文的"配方"贡献升级版 |

**G4**：R̂ 质量指标（PSNR/隐式除数校准）↑ 且 e2e ≥ S1 + 0.3 dB；不过则砍掉或降级为 DA 配方附录。

## 6. 组件⑤：区间校准（Conformal，把不可辨识变成卖点）

- **目标量**：膜区 α 的预测区间 [lo, hi]，覆盖率 P(α_GT ≤ hi) ≥ 1−δ（**分裂 conformal**，场景级 exchangeability）；
- **分数与口径**：s = α_GT − ĉ·ĝ（低估为正）。按场景取膜内可见像素的 95 分位为场景分（避免单像素噪声主导），再用 ⌈(n+1)(1−δ)⌉/n 分位跨场景求 Δ；`α̃_hi = clip(ĉ·ĝ + Δ, 0.05, 1)`；
- **与②的接口**：算子直接用 α̃_hi（δ 即"保守度旋钮"）；输出 **风险-保守度曲线**（δ=0.05→0.5 扫，e2e PSNR 曲线）与 **覆盖率曲线**（名义 vs 实测）两张论文图；
- **校准集**：从训练场景族另切 15%（场景级划分，防泄漏）；δ 的选择在验证集上定，测试集只报数；
- 成本：小时级（无训练）。
