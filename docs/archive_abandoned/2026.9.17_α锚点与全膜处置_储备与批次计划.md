# 2026.9.17 α 锚点与全膜处置——储备与批次计划

> 缘起：S2 出口轮把瓶颈定位到 **α̃ 跨域校准**（α̃ 换真值 +4.3 dB，见 `2026.9.17_S2物理出口轮_实验记录.md`）；
> α 头线早有 **0.7 可辨识性平台**；文献调研（`2026.9.17_文献调研_单帧衰减场估计.md`）确认"单帧乘性场只能靠
> 先验/锚点/配对/多帧消歧"。本档记录 2026-09-17 讨论出的**三条路线**与**分批执行计划**（分批次做）。

## 0. 问题定义

`I = α·T + R`，单帧、α 为深色贴膜的透光率（硬边界 2–4.5px、块状/离散档位、α≪1）。
**对称性（不可辨的根源）**：对任意正空间场 `s(x)`，变换 `α→s·α, T→T/s` 观测不变 → 单帧只能确定乘积 αT。
现状：内容统计式的 α 估计器（4 个独立探针）全部撞 0.7 平台；S2 出口因 α̃ 跨域失准而失败。

## 1. 路线 A：DCP 式锚点（把未知量消掉，留 α）

DCP（He et al., CVPR 2009）的吸引力在于：它用**退化后仍成立的内容事实**（无雾图局部必有一通道近零）把场景项
消掉（J·t≈0），方程里只剩可观测项与待估 t。我们的同款候选：

| # | 锚点 | 方程/机制 | 前提 | 失效条件 |
|---|---|---|---|---|
| **A1** | **膜边界台阶** | 跨膜边差分 `D = I_裸 − I_膜 ≈ (1−α)·T`（R 不穿膜→两侧 R 相同；场景连续→T 连续）。沿边界回归 `jump(x) ~ I_裸(x)` → 斜率 ≈ (1−α)，**R 项在回归中被平均掉，无需逐像素知道 R** | 画面内含裸区；边界两侧 T 连续、R 不变 | 全膜（边界不在画面）；边界恰压在真实物体轮廓（T 本身跳变）；暗区 T≈0 台阶消失 |
| **A2** | **同场景多档配对**（我们独有、完全未用） | `I_j − I_k = (α_j−α_k)·T` → T 被解出，**α 的比值**可定 | 训练/合成数据有同场景多档（我们有 5 档） | 只给相对标度，绝对值仍需外部锚 |
| **A3** | **反射共享** | R 与膜无关（p=0）→ 裸区估 R（T 的 SNR 高），膜区用 R 一致性反推 α | 含裸区 | 同 A1 |
| **A4** | **裸区标度锚** | 裸区 α≡1 精确已知 → 给绝对标度、防漂移 | 含裸区 | 同 A1 |
| **A5** | 统计比值（膜区/裸区对比度比≈α） | 弱；我们试过的"能量比"同族 | 内容匹配假设 | 内容不匹配即失效；**低优先** |

- 先例：阴影去除/抠图正是靠边界（Chuang et al. SIGGRAPH 2003；SID ICCV 2019）；配对弱监督（RetinexNet BMVC 2018）。
- **关键点**：A1/A2 的方程只含**物理事实**（R 不穿膜、T 连续、p=0），不随域变化——正是跨域崩掉的 α̃ 所缺的。

## 2. 路线 B：全膜处置（无裸区参照）

**理论**：均匀膜假设下（真膜物理均匀），任意场 s(x) 的歧义塌缩为**一个全局标量**（α→s·α, T→T/s, s 常数）。
**实测**（`scripts/probes_0915/probe_fullfilm.py`，2026-09-15）：全膜裁片下档位头失效——真档 1.0 的 acc=0%，
α̂ 压向 0.35–0.51 低档常数；掩膜正常。⇒ **单帧逐像素估绝对档位在全膜下不可行**。

工程路线（按现实性排序）：

| # | 路线 | 说明 |
|---|---|---|
| B1 | **降维：场→单一标量** | 假设膜内 α 均匀 → 只剩一个数要定，证据需求降一个数量级 |
| B2 | **离散档位网格（VLT 规格）** | 汽车膜按 VLT 分档售卖（70/50/35/20/5%…）→ 估问题变"吸附到哪个标准格点"（分类而非回归） |
| B3 | **部署级标定（一次定标、长期复用）** | 同一车同一膜 α 是常数；借一次带参照机会（露出的未贴膜角、膜规格）标定，之后自动 |
| B4 | **时序/视频** | α 是静态层、R 随视角光照变化——"不变的是膜、在变的是反射"（我们的中值伪 GT 协议已在吃这块） |
| B5 | **任务驱动兜底** | 不需要物理 α 时，用无参考判据选全局增益（S2 的"工作点搬移"其实就是这个） |

## 3. 路线 C：候选族输出（把歧义显式化，人/判据来选）

**想法（2026-09-17 用户提出）**：全膜时输出多张候选（一维亮度族）给用户选。
- **结构性优势**：歧义本身就是**一维**的 → UI 就是一个滑块/胶卷条；人提供的恰是缺失的自然图像先验
- **最佳形态 = 交互即标定**：首次使用用户选一次 → 这一选就是该部署的标定样本；前 N 次交互后 α 已定 →
  之后全自动（B3 落地）。即"全膜从每帧不可辨 → 一次性标定问题"
- **量化实验（进论文的关键）**：
  1. `oracle@k`：k 张候选中离 GT 最近那张的 PSNR → 量化歧义里还剩多少可分
  2. **自动选择器**（无参考判据：对比度/熵/自然性统计；或学一个选档器）能到 oracle@k 的多少
  3. 选择准确率 vs k 曲线；用户研究（可选，最后做）
- 先例：Bousseau et al. 用户辅助本征分解（SIGGRAPH Asia 2009）；交互式上色（Zhang et al. SIGGRAPH 2017）；
  one-to-many 输出框架（SRFlow 类）
- 风险：审稿人视为"产品设计" → **必须配量化实验**，定位为"α 可辨识性章节的不可辨情形处置协议"，不作主 claim

## 4. 分批计划（每批 = 一轮研究循环，P0 时正式预登记门）

| 批次 | 内容 | 类型/成本 | 依赖 | 建议预登记门（草案） |
|---|---|---|---|---|
| **批次 1a** | A1 边界台阶锚零训练探针（合成集：定位边界带→回归 jump~I_裸→1−α̂，与真 α 比；含失效条件分档） | CPU <半天 | 无 | α̂ MAE < 0.10（含裸区场景） |
| **批次 1b** | A2 多档配对：训练集同场景 5 档验证 α 比值可恢复性（零训练） | CPU 半天 | 无 | 比值恢复相对误差 < 10% |
| **批次 1c** | C 候选族：oracle@k + 自动选择器初测（全膜 crop） | CPU <半天 | 无 | 自动选择 ≥ oracle@k 的 90% |
| **批次 2** | 把批次 1 的有效锚点做成显式损失（边界一致性 + 跨档比值）重训 α 头/档位头，检验能否破 0.7 平台 | GPU 1–2 晚 | 1a/1b 结果 | α MAE < 0.1 或档位 acc ≥ 0.85（P0 定） |
| **批次 3** | （条件）α̃ 达标后重开 S2 出口 | GPU 1 晚 | 批次 2 达标（出口重启条件 = 跨域 MAE<0.1） | 沿用 G-S2a |
| **批次 4** | 全膜协议落地：候选族 + 自动选择 + 部署标定流程（B1–B3 合体） | CPU/少量 GPU | 1c | 部署标定后选择误差 < 1 档 |
| **批次 5** | 论文整合：α 可辨识性章节 + related work + limitation（含"单帧 vs 偏振"对照） | 写作 | 前四批 | — |

**批次 1a/1b/1c 彼此独立、都是零训练**，可一批（一次循环）内并行做掉。

## 5. 与本项目其他线的接口

- 与 **α 头线**（0.7 平台）：批次 2 是该线的直接续作；A1/A2 提供**结构性**而非统计性的监督信号
- 与 **S2 出口线**：批次 3 是其条件性重开（冻结条件见 `2026.9.17_S2物理出口轮_实验记录.md` §6）
- 与 **实拍/视频线**：B4（时序）与中值伪 GT 协议同源；MyVideo 的"深色人形=拍摄者反射"是 A3 的真实素材
- 与**论文叙事**：可辨识性分档表（含裸区/全膜+规格/全膜+部署/全膜+视频/纯单帧未知膜）可直接进 limitation

## 6. 待确认/风险

- A1 的"R 在回归中平均掉"依赖 T 与 R 不相关——需在探针中检验（若相关，斜率有偏）
- 边界带像素少（2–4.5px），样本量/稳健回归策略要在 1a 里先摸清
- B2（VLT 规格）需确认目标市场的膜档位实际分布（可查车膜产品规格）
- C 的用户研究成本较高，最后做；先用"自动选择器 vs oracle@k"替代
