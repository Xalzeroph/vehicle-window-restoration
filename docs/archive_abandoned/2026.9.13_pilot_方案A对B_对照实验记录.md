# 2026.9.13 Pilot 对照实验记录：方案 A（αTAP）vs 方案 B（技巧包）vs M0 zero-shot

## 1. 协议与产物

- 数据：`train_pairs_pilot/`（2400 对，与 v2.1 同分布同隔离，I/T/R uint8 + α float16；三档 ᾱ=1.0/0.6/0.3 均衡）
- 训练（`scripts/finetune_alpha_tap.py`）：官方 rdnet.pth 初始化，冻结 FocalNet backbone（两臂同待遇）；阶段 1（0–300 iter）只训 α 头（`forward_alpha_only` + L_α）；阶段 2 β 线性 ramp 0→1（300–700）+ 全可训练参数，L = L_T + L_R + L_α；Adam 1e-4，batch 4，224²，AMP，1000 iter（≈5 min/臂）
- 方案 A：`inject=True`（prompt 拼 α̂ 统计 3 维 + P3 硬减法 T0=I−R̂+Δ̂ + 除法出口 T̂=T0/α̂@β=1）
- 方案 B：`inject=False`（官方参数化），L_T 用显式 w=clamp((0.3/α_GT)²,1,10)；α 头仍训练供 MAE 报告
- 评测（`scripts/eval_pilot.py`）：v2.1 测试集 12 场景 × 三档，raw + 增益匹配(gm) 口径
- 产物：`pilot_ckpt/{A,B}/ckpt_final.pth` + `train_log.csv`；`pilot_pred/{M0,A,B}/alpha_{1,0.6,0.3}/`；`pilot_eval_{M0,A,B}.csv`；核验图 `fig/pilot_compare_sheet.png`

## 2. 主结果（12 场景均值）

| ᾱ | M0 raw / gm | A raw / gm | B raw / gm | A−M0 | B−M0 | A−B raw | A−B gm |
|---|---|---|---|---|---|---|---|
| 1.0 | 17.14 / 17.88 | **16.98** / 19.48 | 16.21 / **19.84** | −0.16 | −0.93 | **+0.77** (11/12, t=3.54) | −0.36 |
| 0.6 | 14.67 / 14.99 | **17.78** / 18.86 | 17.34 / **19.20** | **+3.11** | +2.67 | **+0.44** (7/12, t=1.94) | −0.34 |
| 0.3 | 12.05 / 12.36 | **17.42** / **17.73** | 17.06 / 17.43 | **+5.37** | +5.02 | **+0.35** (8/12, t=1.91) | +0.30 |

SSIM（A−B）：α=1 +0.005 (6/12)；α=0.6 +0.006；**α=0.3 +0.029 (11/12, t=2.84)**。

要点：

1. **域适配是主效应**：两臂都把 α=0.3 档从 12.0 拉到 17.1–17.4 dB（+5 dB），α 依赖的崩塌被打平（A 全档 raw 17.0/17.8/17.4）。
2. **A−B 增量小但方向一致**：raw PSNR 三档全为正（+0.35~+0.77），α=0.3 的 SSIM 显著（11/12）。但 gm 口径下 α=1.0/0.6 档 B 更好——B 的过亮更接近全局尺度（gm 能归一），A 的误差更偏空间结构。
3. **"透明区不退化"未达成**：α=1.0 档两臂 raw 都略低于 M0（−0.16 / −0.93），输出均值 T̄ 109.5(A)/117.1(B) vs GT 88.7——过亮 20~30%。

## 3. E2 oracle 定位（α=0.3 档）

| 参照 | PSNR |
|---|---|
| 输入 I | 13.02（gm 13.27） |
| 完美去R + 全局增益（E2 上界） | 14.09 |
| 完美去R + 精确 α(x)（含饱和 / 去饱和） | 30.67 / 32.76 |
| M0 zero-shot | 12.05 |
| **A pilot** | **17.42（gm 17.73）** |

- A 已**超过"完美去反射+全局增益"上界 +3.3 dB**——空间 α 建模的必要性第一次在真实（微调）模型上得到佐证，而非只靠 oracle 差距画 motivation。
- 距精确 α(x) 上界尚有 ~13 dB，头空间在 α 头质量与 R̂ 质量。

## 4. 诊断：α̂ 头是当前瓶颈

α̂ 校准（测试集，eroded-core 内区统计，排除边界稀释）：

| 区间 | A α̂ | GT |
|---|---|---|
| naked（α≥0.95） | 0.60–0.64 | ≈1.0 |
| film @ α=1.0 档 | 0.48 | 0.72 |
| film @ 0.6 | 0.43 | 0.58 |
| film @ 0.3 | 0.34 | 0.29 |

- 头部输出**整体压缩向中段**：几乎不随档位移动（film 0.34→0.48 对应 GT 0.29→0.72），结构 corr(去均值) 仅 0.46/0.60/0.70（α=1/0.6/0.3）。
- oracle 除法（用 A 的 R̂、GT α、忽略 Δ̂≈0.003）：α=1 **+2.48 dB 头空间**；α=0.6 +0.31；**α=0.3 −1.29**——低档下 R̂ 已把有偏 α̂ 补偿进参数里，换真值 α 反而破坏补偿。即高 α 区是 α 头质量直接决定的，低 α 区是 R̂/α̂ 联合拟合的自由度。
- **欠拟合而非纯泛化**：A/B 在训练集自身（67 样本）naked α̂ 也只有 0.78/0.80、aMAE 0.20（比测试 0.13 还高）。1000 iter × batch 4 ≈ 1.7 epoch，α 头（尤其 stage-1 只有 300 iter）远未见充分数据。
- 另一处口径差异：训练 224² 方形裁剪 vs 测试 832×384 宽幅，分辨率/纵横比 shift 对冻结 backbone 特征的影响未控（两臂同待遇，不影响 A/B 对照）。

## 5. 结论与下一步

- **Pilot 裁决**：A ≥ B（raw 口径一致为正、目标档 SSIM 显著），但增量小；主要收益来自域适配。当前不构成"A 完胜"的证据，**α 头质量是两臂共同的短板**，因此 A 的"注入优势"被欠拟合的 α̂ 压制，小优势符合预期而非合格线。
- **Round 2（建议，成本 ≈20 min/臂）**：
  1. iters 1000→4000（α 头 ~7 epoch），其余协议不变；
  2. L_α 对 naked 区加权 `×(1+2·[α_GT≥0.95])`，直击高 α 压缩；
  3. 两臂一起重训（保持"同配方"口径），评测同协议，重点看：naked α̂ 是否 ≥0.9、α=1 档是否回到 ≥M0、A−B 差距是否随 α̂ 变好而拉开。
- 若 4000 iter 后 naked 仍压不上来，则升级头结构（全局档位上下文注入 / 更高分辨率头），而不是继续加 iter。

## 6. Round 2 结果与归因（2026-09-13 晚）

四个新 run（各 ≈19 min）：A_r2 = A + naked 加权(κ=2) @4000 iter；B_r2 = B @4000 iter（B 的 T 输出不经过 α 头，κ 不影响）；A_r3 = A @4000 iter κ=0。

| run | raw 1.0 / 0.6 / 0.3 | gm 0.3 | T̄@0.3 (GT 88.7) |
|---|---|---|---|
| M0 | 17.14 / 14.67 / 12.05 | 12.36 | 47.4 |
| A_r1 (1000) | 16.98 / 17.78 / 17.42 | 17.73 | 81.5 |
| A_r2 (4000, κ=2) | 17.94 / 17.22 / 15.53 | 16.04 | 67.3 |
| A_r3 (4000, κ=0) | 17.76 / 17.16 / 15.49 | 15.96 | 68.1 |
| B_r1 (1000) | 16.21 / 17.34 / 17.06 | 17.43 | 82.5 |
| **B_r2 (4000)** | **19.62 / 18.07 / 16.51** | 17.40 | 74.2 |

要点：

1. **A−B 裁决翻转**：1000 iter 时 A 三档全胜，4000 iter 时 B 三档全胜（+1.7/+0.9/+1.0）。A_r1 的 α=0.3 = 17.42 仍是该档最佳记录。**架构 claim 在等算力口径下不成立**。
2. **naked 加权无实效**：A_r2 ≈ A_r3（15.53 vs 15.49）——κ 只改了 α̂ 的自我报告（naked MAE 0.270 vs 0.352），对 T 输出无影响（R̂ 吸收了偏差）。α=0.3 档 17.4→15.5 的掉点是**训练变长的副作用**（B 同向：17.06→16.51），非 κ 所致。
3. **交叉组合归因**（用保存的 R̂/α̂ 重合成，忽略 Δ̂）：

| 组合 | 1.0 | 0.6 | 0.3 |
|---|---|---|---|
| A 实际 / B 实际 | 17.76 / 19.62 | 17.16 / 18.07 | 15.49 / 16.51 |
| (I−R̂_A)/α_GT | 18.74 | 17.20 | 15.12 |
| **(I−R̂_B)/α_GT** | **20.08** | **18.77** | **16.89** |
| (I−R̂_B)/α̂_A | 16.56 | 17.26 | 16.80 |

   - **A 落后主因是 R̂ 质量**：长训练 B 的 R̂ 三档反超 A 1.3~1.8 dB（A 的 R̂ 反而从 r1 的 21.76@0.3 退化到 20.8）；换成 B 的 R̂ 后，A 的 α̂ 除法在 α=0.3 得 16.80 > B 实际 16.51。
   - **α̂ 误差的代价集中在高档**：(I−R̂_B)/α̂_A vs /α_GT = −3.52(α=1) / −1.51(0.6) / −0.09(0.3) dB。
   - **(I−R̂_B)/α_GT 全档最优**（20.08/18.77/16.89，比 B 实际还高 +0.46/+0.70/+0.38）——物理除法参数化本身有正增量，但要求 α̂ 精度足以让误差代价 <0.5 dB。
4. **A 的优化失败**：训练集 L_T 收敛值 A 0.251 > B 0.200——A 自由度更多却拟合更差，说明除法+注入使优化更难（α̂/R̂ 联合退化方向 + 梯形梯度），非数据不够。
5. 附注：L_R/L_T 的 w=clamp((0.3/α)²,1,10) 在训练档位（α≥0.3）几乎恒等于 1（仅弧度调制低尾最多 ~2-4），所以 B 臂 ≈ "官方参数化 + 普通 Charbonnier 微调"，trick 部分的实质权重很小。

### 下一步（待裁决）

- **α 头饱和测试**（≈15 min，α-only 快速迭代 0.09 s/it）：单独把 α 头训到收敛（8-10k iter），看 naked/film 校准能否达标（naked ≥0.9）。达标 → A 换上好 α 头重测；不达标 → 头结构需改（全局档位上下文 / 更高分辨率），或放弃架构线。
- 同时正视 R̂ 退化：A 的 R̂ 在长训练下变差是独立问题（可能是除法路径的梯度耦合），修 α̂ 不一定能带动它。

## 7. α 头饱和测试（2026-09-13 下午，已执行 → 负结果）

协议：α-only 模式（`--alpha-only`，单列前向只到 α 头，~0.085 s/it，batch 4，L_α 同配方含 κ_naked=2）；
三个 run：A_sat（官方冷启 8000 iter）、A_sat_r3（A_r3 热启 8000 iter）、A_sat_cc（code 条件化头 v2，4000 iter，见 §7.2）。

### 7.1 结果（评估同 v2.1 测试集；α 统计为 12 场景像素级聚合）

| run | naked α̂ (GT≈1) | naked corr | film α̂ @档1/0.6/0.3 (GT 0.72/0.58/0.29) | raw PSNR 1.0/0.6/0.3 |
|---|---|---|---|---|
| A_r1 (1000) | 0.634 | 0.06 | 0.485 / 0.432 / 0.339 | 16.98 / 17.78 / 17.42 |
| A_r3 (4000) | 0.643 | 0.03 | 0.510 / 0.431 / 0.315 | 17.76 / 17.16 / 15.49 |
| A_sat (8000 冷启) | **0.711** | 0.06 | 0.509 / 0.445 / 0.327 | 10.89 / 11.08 / 11.67 |
| A_sat_r3 (8000 热启) | 0.693 | 0.01 | 0.553 / 0.453 / 0.311 | 17.10 / 16.60 / 15.55 |
| A_sat_cc (4000 code-cond) | 0.673 | 0.05 | 0.481 / 0.436 / 0.332 | 9.94 / 10.68 / 11.56 |

关键读取：

1. **迭代不是瓶颈**：8000 iter（≈7 epoch）只把 naked α̂ 从 0.63 抬到 0.71（冷启）/0.69（热启），film 档位几乎不动 → 原头在直接监督下**收敛于 ~0.7 平台**，距 0.9 目标不可达。饱和判据"仅 1.7 epoch 欠拟合"被证伪。
2. **头不是"学不到"空间结构，而是对比度被压缩一半**：α̂ 空间 std 0.205 vs GT 0.285；诊断场景 t00@0.3：naked α̂ 0.72（GT 1.0）、film α̂ 0.35（GT 0.32），即**膜区/裸区的方向正确、但膜−裸对比 −0.37 vs GT −0.68**。naked 区内部 corr≈0.05 是因为该区 GT 近乎常数、α̂ 却有 ±0.2 的局部抖动（噪声而非信号）。
3. **仿射校准探针（测试集上拟合，仅探上限）**：全局 α̂′=a+b·α̂（A_r1: a=0.081, b=1.04）把整体 αMAE 0.173→0.161、naked 0.344→0.241，但 film 反而 0.137→0.145、下界档几乎无改善 → **不是尺度问题**，是 α̂ 带有与 α 无关的局部噪声（frozen FocalNet 特征里没有可读的膜信号），后处理校准救不回。
4. **冷启 A_sat 的崩点**：α̂ 整体上移（film 0.51→0.44 档位差仍在）→ 除法放大 → T̄ 143（GT 89）→ PSNR 10.9。热启 A_sat_r3 因 T̄ 锚在 88.7（α=0.6 档与 GT 完全吻合）而没崩，但 PSNR 仍是 17.10/16.60/15.55 ≤ A_r3/A_r1 → **α̂ 变好（naked 0.63→0.69）带不动端到端**，印证 §6 交叉组合：R̂ 质量才是主约束。

### 7.2 code 条件化 α 头（v2，负结果）

动机：naked corr≈0 → 假设头缺"全局档位上下文"（裸区 α=1 与膜区 α=0.3 局部特征不可分）。实现
`FullNet_NLP_ATap_Code`（rdnet_atap.py）：z = 0.5·tanh(global_head(code)) + Δz_spatial(features+FiLM(code))，
Δz 零初始化（起点=纯 code 全局先验）。结果：naked 0.673、film 档位 0.48/0.44/0.33、corr 无改善 →
**classifier code 注入无效**。推断：τ̂（code 本义）与透射强度 α 的映射在给定场景分布内信息量不足，
或 6 维 code 的全局信息无法经由 α 头落到像素级；无论哪种，该路线关闭。

### 7.3 结论与建议

- **α 头架构 claim 的裁决**：等算力下 A < B（§6），且 α 头的空间/档位估计能力经三路挽救（长训 / 热启 / code 条件化）均无突破 → **"空间 α 建模"作为论文主 claim 的可行性存疑**。当前 α̂ 的水平（naked 0.7、对比度打半）不足以支撑 (I−R̂)/α̂ 参数化的物理优势。
- 两条现实路线（待用户裁决）：
  1. **换特征源**：α 头放弃 frozen FocalNet 特征，改接可训练的全分辨率/多尺度特征（如 decoder 浅层 + 独立轻量编码器），并允许高层信息下流。成本：中等（需改架构 + 重跑 pilot），预期不明。
  2. **降级 α 的角色**：论文主体转向"域适配 + 贴膜场景基准 + 诊断性负结果"，α 线只作为诊断一章（当前数据已足够支撑：域适配 +5 dB、E2 oracle 上界、α 头负结果本身就是有价值的故事）。
