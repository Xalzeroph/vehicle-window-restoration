# 2026.9.17 合成微调为什么不迁移：域差诊断

> 本轮问题：**合成域微调模型在合成测试集上比官方零样本强吗？** → 决定上一轮"实拍掉分"
> 该归因于**域差**还是**微调本身有问题**。
> 结论：**域差归因成立**。微调在合成域上极其有效（+3.4 ~ +7.2 dB），在实拍上却全面为负（−0.4 ~ −3.9 dB）。
> *人话：模型在合成考卷上从 60 分考到 95 分，换真考卷却比原来的 80 分还低——它学的是合成考卷的出题套路。*

## 1. 预登记判决门

- **PASS（域差归因成立）**：微调在 v2.1 上 ΔPSNR_gm ≥ +0.5 dB 且方向为正（以 α=0.3 档为主）
- **FAIL（微调本身有问题）**：|Δ| < 0.3 dB 或为负 → 回查训练配置/加载

## 2. 方法

- 零样本：`pretrained/rdnet.pth`（官方权重），本轮机跑，与出口轮**同脚本同口径**
  （`scripts/eval_rdt_tint.py --ckpt pretrained/rdnet.pth --tag zs0917 --sets synth_rrw_v21_0913,synth_rrw_v21_indomain`）
- 微调：`runs/ckpt/rdt_plain/ckpt_final.pth`，复用既有 summary（`eval_rdt_plain_synth_rrw_v21_*`）

- 成本：GPU 1 号卡单次 76 秒

## 4. 结论

1. **判决门 PASS，域差归因成立**：微调**不是坏的**——它在合成域上是压倒性有效的
   （α=0.3 档比零样本高 6.7 dB，且把"比调曝光还不如"的零样本从 −0.9 dB 拉到 +5.8 dB）。
   *人话：模型没坏，它只是把合成题做透了。*
2. **不迁移的幅度是同一个量级**：合成 +3.4~+7.2 dB ↔ 实拍 −0.4~−3.9 dB，
   说明训练分布的偏移足以让全部收益反转。
3. **零样本在合成上也是负贡献**（gm−in_gm = −0.2 ~ −1.9 dB）——与上一轮实拍"增益匹配后无优势"一致，
   即：**官方权重在贴膜域无论合成还是实拍都不加分**，这一点跨域稳定。
4. 候选域差（**均未验证**，按可疑度排序）：
   - **T 的噪声/编解码**：合成 T 无噪声，噪声只加在 I 上（σ=1.5）；实拍 T 有真实噪声 + JPEG
   - **R 的形态**：合成 R 来自 RRW 公开集（偏亮、有纹理）；实拍 R 是拍摄者深色剪影 + 金属高光
   - **α 场**：合成是人工空间场（5 档、覆盖突变 + 弧度渐变）；实拍是同款膜、空间上基本均匀、单一 α
   - **曝光关系**：合成 I 与 T 的差**只由 α 决定**；实拍 I 与 GT 之间还有全局曝光差
5. 微调版的 **SSIM 掉幅大于 PSNR**（实拍 6 月 0.662 vs 零样本 0.774）→ 行为特征指向**过度平滑**
   （与合成 T 无噪声、模型学成"见噪声就压"的假设一致）。
