## Abstract

真实场景的单图反射去除（SIRR）依赖"真实配对数据 + 微调"的范式，而真实配对几乎都必须借助某种透射层参考来获得无反射图。**本文重访这一范式在贴膜（染色）玻璃上的成立条件**，并在两个被忽视的层面给出分析与修正。

**其一，反射层本身不是一块平滑的正值薄膜。** 贴膜玻璃场景中普遍存在**反射洞**：当相机侧的前景物体（拍摄者的身体、手持物）遮挡了反射光路的一部分时，反射层在局部被大幅抑制，形成具有**锐利边界**的空间空区。我们给出反射洞的物理生成模型与可观测定义：设遮挡物挡住入射立体角的比例为 β(x)，则反射退化为 R_O(x) = R(x)·(1 − β(x))，反射洞定义为其水平集 Ω_δ = { x : β(x) ≥ δ }；可观测量由局部上包络与残差的凹陷给出。实测：Ω 内反射被压制到局部背景的 **约 30%**（7.51 vs 25.26 灰阶），**41.0%** 的 Ω 像素落在噪声底以内（外部为 14.6%），Ω 占画面中位 **21%**。由此可推出**过修命题**：对 Ω 内"只需去掉 30% 反射"的区域，按全局强度施加修正的方法其过修比约为 **2.7 倍**。

**其二，透射层的全局光度水平不可由单帧辨识。** 由 I = τ·T + R，目标 τ·T 只在"相差一个全局尺度"的意义下可辨识，该尺度由净衰减比 ρ = μ(τT)/μ(I) 唯一确定，而 ρ **不是输入的函数**。推论是逐像素监督的最优解退化为**域平均亮度**。实测：全部 34 个微调臂系统性偏亮 **7.02 灰阶**，闭式校正后平均回收 **+0.63 dB**、最大 **+1.86 dB**；而仅用一条 2 参数全局色调曲线作用于恒等输出，即比官方 SOTA 高 **+2.68 dB（apr）/ +2.04 dB（may）**，官方相对该平凡基线的净收益仅 **+0.30 / −0.32 dB**。

**其三，据我们所知，本文构建了首个面向贴膜玻璃的真实配对 SIRR 数据集与 benchmark**：631 对真实配对、13 个训练场景 + 12 个冻结测试场景、四档受控衰减水平、逐帧 Ω 标注与有符号反射层，并在其上系统评测多种公开方法微调后的性能与失效模式。

在方法侧，我们给出 **Ω 监督的免伤损失**（§3.5）：由于推理期检测 Ω 不可行（直连上界 IoU 仅 0.494），我们改用**仅训练期**的洞内相对误差与单边过冲惩罚，实测为六项损失中**唯一承重**者（去掉 **−2.91 dB**）。此外提出**干预式验收协议**（扰动条件标量、要求输出跟随，判据 ControlGain ≥ 0.50），实测冻结 SOTA（**0.02**）与基于吸收效应的条件化方法（**0.086**）均不通过。所有负结果一并报告。

## 1. Introduction

### 1.1 为什么要重访反射层

SIRR 的合成数据范式建立在三条关于反射层的假设上：**（A1）加性** I = T + R；**（A2）非负且空间平滑**，反射只是"在透射图上叠一层亮膜"；**（A3）全局一致**，反射层不随位置发生结构性变化。

真实场景的采集实践（移玻璃、RAW 相减、黑绒布遮挡）主要围绕**如何拿到参考图**展开【文】，而很少追问**参考图所隐含的反射层假设是否成立**。本文指出：**在贴膜玻璃上，A2 与 A3 都不成立**，而失效的方式是可形式化、可测量、且直接决定方法行为的。

### 1.2 反射洞：一个被忽略的空间结构

考虑相机透过贴膜玻璃拍摄。反射层是玻璃**背面场景**的镜像。若在相机一侧存在前景物体 O（最常见的例子：拍摄者自己、手持的手机/相机、三脚架），则反射光路被部分遮挡，**反射在某块区域内被大幅压制**。

这块区域具有两个关键性质：

- **边界锐利**——遮挡物是有界的实体，其剪影在镜像坐标下形成硬边；
- **不是零**——遮挡只挡住入射立体角的一部分（且环境散射光仍存在），因此反射被**衰减**而非消失。

我们将这块区域称为**反射洞（reflection hole）**，记为 Ω。

**为什么它重要？** 因为 A2 隐含地告诉模型"**每个像素都该减掉一点反射**"。而在 Ω 内，正确做法可能只是"减掉很少、甚至不减"。一个按全局强度工作的方法会在 Ω 内**过修**——把本来干净的区域压暗。实测给出该效应的大小（§4.3）：Ω 内反射仅为局部背景的 **30%**，过修比约 **2.7 倍**。

进一步，我们把误差按区域拆开（§4.3）：**全部 35 个臂在 Ω 内平均偏暗 −1.03 灰阶、在 Ω 外平均偏亮 +10.72 灰阶，其中 23 个臂符号相反。** 这说明所有方法都在施加**空间盲的修正**。

### 1.3 光度不可辨识：第二个被忽视的量

真实配对必须经过两次拍摄（有反射 / 无反射），两次拍摄的**全局光度水平**一般不同（自动曝光、补光、以及**遮挡本身改变了透射侧照明**）。于是配对监督里混入了一个**不由输入决定**的全局尺度。

由 I = τ·T + R 与参考 T_obs ≈ τ·T，对任意 λ > 0，把 (T_obs, R) 换成 (λ·T_obs, R + (1−λ)·T_obs) 会给出**逐像素相同的 I**。故目标只在"相差一个全局尺度"下可辨识，而该尺度由

```text
rho = mean(T_obs) / mean(I) = 1 / (1 + r),    r = mean(R) / mean(T_obs)
```

唯一确定。ρ 取决于反射与透射的相对强度，**不是 I 的函数**。

其后果是**可预测**的：使用错误尺度 λ 造成的误差为 (1 − λ)·ρ·mean(I)；且当尺度与图像近似独立时，逐像素监督的最优解趋向**域平均亮度**，表现为"欠校正 + 平滑"。

我们的实测与该推论一致：全部 34 个微调臂**系统性偏亮 7.02 灰阶**；把亮度闭式校正后平均回收 **+0.63 dB**（最大 **+1.86 dB**）——即"把亮度弄对"本身就是一个超过检测下限的效果量。

### 1.4 贡献

仿照 Zhu et al.【文】的三段式（新采集流程 → 新数据集 → 由数据产生的观察 → 方法/协议），我们给出：

- **C1 反射洞的形式化与验证**（§3.3, §4.3）：给出反射洞的物理生成模型 R_O = R·(1 − β) 与可观测定义 Ω_δ，并给出**过修命题**（按全局强度修正的方法在 Ω 内过修约 1/(1−δ) 倍）。实测 δ ≈ 0.70、过修 **2.7 倍**；并测得**洞内偏暗 −1.03 灰阶 / 洞外偏亮 +10.72 灰阶**（23/35 臂符号相反），即全部方法都存在**空间盲修正**。
- **C2 方法：Ω 监督的免伤损失**（§3.5, §4.3）：由 C1 的诊断出发，我们不在推理期检测 Ω（该上界仅 IoU 0.494），而把 Ω 作为**仅训练期**的监督：反射幅度归一化的洞内相对误差 L_err + 单边过冲惩罚 L_hinge。实测为六项损失中**唯一承重**者（去掉 **−2.91 dB**，0/15 场景胜，去反射率 **−45.6%**）。
- **C3 光度不可辨识的形式化与误差分解**（§3.4）：区分"可约的 τ"与"不可约的 ρ"，给出尺度可辨识性命题、ρ 不可辨识命题、误差分解与"条件有效性判据"（条件是 I 的确定性函数时不携带额外信息）。
- **C4 首个贴膜玻璃真实配对数据集与 benchmark**（§4.1–4.2）：631 对真实配对、四档受控衰减、逐帧 Ω 标注、有符号反射层、冻结划分；系统评测多种公开方法微调后的性能，并给出失效归因。**据我们所知为首个针对贴膜（染色）玻璃的此类基准**。
- **C5 干预式验收协议**（§3.6, §4.6）：以"扰动条件、要求输出跟随"作为条件通路的验收标准，实测现有条件化方法均不通过。
- **C6 采集缺陷的量化披露**（§4.1）：黑布 GT 协议的两处系统缺陷——**每场景单张 GT 且与输入相距中位 374 帧**、**遮挡同时改变透射照明（其量级约为反射本身的 2 倍）**——及其对上述所有结论的影响边界。

> **诚实声明**：本文不提出在平均 PSNR 上胜出的新方法。主张是：在该数据协议下，**反射层的空间结构（洞）与全局光度水平（ρ）构成两条独立失败轴**；对前者给出**形式化与仅训练期的监督方案**（C1–C2），对后者给出**不可辨识性证明与可干预验收协议**（C3, C5）。全部负结果与不可行结论一并报告（§4.7）。

## 3. Method

### 3.1 成像模型与贴膜玻璃的特化

对任一像素 x 与通道 c，线性辐射下

```text
I_c(x) = tau_c(x) * T_c(x) + R_c(x),      c in {R, G, B}
```

贴膜玻璃与普通玻璃的差别集中在三点：

| 对比项 | 普通玻璃 | 贴膜（染色）玻璃 |
|---|---|---|
| 透射率 | τ ≈ 0.95–0.99 | **τ 显著小于 1，且随通道变化**（膜吸收特定波段） |
| 反射强度 | 4%–8%（Fresnel） | 相对透射更强（透射被削弱，反射占比上升） |
| 反射空间结构 | 常被假设平滑 | **存在反射洞**（前景遮挡） |

任务目标取 T_obs := τ·T（保留贴膜的透光与色调，只去除反射），这一定义使"贴膜颜色"不被当作需要去除的内容。

### 3.2 反射层的重访：三条与标准假设的偏离

| 编号 | 标准假设 | 贴膜玻璃上的实际 | 可观测后果 |
|---|---|---|---|
| A1 | I = T + R | I = τ_c·T_c + R，τ_c 分通道且 < 1 | 输出必须保留 τ，否则"去反射"退化为"去色" |
| A2 | R ≥ 0 且空间平滑 | R 在 Ω 内被压到局部背景的 **30%**，且**边界锐利** | 按全局强度修正会**过修**（§3.3 命题 3） |
| A3 | R 全局一致 | 参考拍摄改变透射照明，τ 的有效值随拍摄条件变化 | 全局尺度（ρ）**不可由输入辨识**（§3.4） |

**A2 的破坏**是本工作最主要的观察；**A3 的破坏**解释了为何"更强的主干"无法解决问题。

### 3.3 反射洞：生成模型、定义与过修命题

#### 3.3.1 生成模型

设玻璃背面场景的辐亮度为 L(ω)（ω 为入射方向），x 处菲涅尔反射系数为 κ(x)，A(x) 为汇聚到像素 x 的入射立体角集合：

```text
R(x) = kappa(x) * Integral over A(x) of L(omega) d omega
```

在相机一侧置入遮挡物 O（前景物体），它挡住 A(x) 中与 O 相交的方向：

```text
R_O(x) = kappa(x) * Integral over A(x) minus O of L(omega) d omega
       = R(x) * ( 1 - beta(x) )
```

其中 β(x) ∈ [0, 1] 为**被遮挡的立体角比例**。

**关键性质**：由于 O 是有界实体，β 是**分片光滑且边界锐利**的——这正是"洞"与"渐变衰减"的区别。β ≡ 0 退化为标准假设 A2；β ≡ 1 退化为"该处无反射"。

#### 3.3.2 定义

**定义 1（反射洞）** 给定阈值 δ ∈ (0, 1)：

```text
Omega_delta = { x : beta(x) >= delta }
```

**定义 2（可观测量）** 实际只能观测到 R̂ = I − τ·T_obs。定义局部反射背景为其空间上包络：

```text
b_R(x) = Up90[ R̂ ](x)
```

其中 Up90 表示在 48×48 块上取 90 分位后双线性上采样（刻画"若无遮挡，此处的反射应当有多强"）。定义**凹陷深度**

```text
S(x) = b_R(x) - R̂(x)  >= 0
```

以及噪声尺度 σ̂ = MAD( R̂ − med3(R̂) )，阈值 τ_n := max(6, 5σ̂)。则反射洞的**可观测估计**为

```text
Omega = { x : S(x) > tau_n   AND   2 * R̂(x) < b_R(x) }
```

并保留面积占比 ≥ 0.5% 的连通域、填补内部孔洞（≤ 25% 面积），以保证 Ω 为实体区域。

**定义 3（衰减率）**

```text
delta_obs = 1 - mean( R̂ | Omega ) / mean( b_R | Omega )
```

#### 3.3.3 命题

**命题 3（过修）** 设某方法在 Ω 内按"全局平均反射强度"施加修正，即 Δ̂(x) ≡ mean(R)；而 Ω 内的正确修正为 mean(R | Ω) = (1 − δ_obs)·mean(b_R | Ω)。定义过修比

```text
OCR = mean over Omega of [ T̂(x) - I(x) ]  /  mean over Omega of [ T_obs(x) - I(x) ]
```

则当 mean(b_R | Ω) ≈ mean(b_R) 时，OCR ≈ 1 / (1 − δ_obs)。

**实测**：δ_obs ≈ 0.70（§4.3），故预期 OCR ≈ 3.3，与独立评测得到的 **2.7 倍**一致【实】。

**命题 4（洞不可由平滑先验恢复）** 若方法对 R 施加空间平滑先验（TV/总变分、低通、或"反射层应连续"的隐式偏置），则 Ω 的锐利边界被平滑，导致边界处**同时欠修（洞外）与过修（洞内）**。故"更平滑的反射先验"在本数据上**加剧**而非缓解误差。

### 3.4 光度不可辨识

#### 3.4.1 两类"不知道"

| 对比项 | τ（透射率） | ρ（净衰减比） |
|---|---|---|
| 含义 | 分通道透射率 | mean(τT) / mean(I) |
| 可辨识 | 否，但**可约**（吸收进 T 的尺度） | 否，且**不可约** |
| 部署是否需要 | 不需要（输出保留 τ） | **需要** |
| 结论 | **冗余参数，用不上** | **不可辨识，拿不到** |

#### 3.4.2 命题与推论

**命题 1（尺度可辨识性）** 给定 I，T_obs 的可辨识集为 { λ·T_obs : λ > 0 }；λ 由 ρ 唯一确定。

**命题 2（ρ 逐图不可辨识）** 存在单参数族 ( λ·τT, R + (1−λ)·τT ) 使 I 逐像素不变而 ρ 不同。故 ρ 不是 I 的函数。

**推论 1（误差分解）** 若模型采用的尺度为 λ（真值 1）：

```text
e_photo = ( 1 - lambda ) * rho * mean(I)
```

（实测：apr 预测 13.0 灰阶 vs 实测 11 灰阶，偏差 18%【实】。）

**推论 2（退化为域均值）** 当尺度与图像近似独立时，逐像素监督的最优解趋向域平均亮度，高频被平滑。（实测：全部臂偏亮 7.02 灰阶【实】。）

**推论 3（条件有效性判据）** 若条件量 c 是 I 的确定性函数，则 (I, c) 与 I 等价，c 不携带额外信息。**故"把某个图像统计量喂进去"不构成条件化**；条件必须能取到图像之外的值（部署配置、标定值，或与输入**独立采样**的反事实值）。

### 3.5 Ω 监督的免伤损失（本文方法本体）

#### 3.5.1 动机：把"定位"换成"监督"

§3.3 定义了反射洞，但**是否需要以及能否在推理期检测 Ω？** 我们的实测给出否定答案（§4.7）：以冻结骨干为特征、从 0.2M 到 5M 参数的直连预测器，Ω 定位上界仅 IoU **0.494**；跨域降至 0.09–0.14（随机水平 0.143）；**容量提升无任何改善**。这符合 §3.4 推论 3：Ω 由配对定义，强预测器只能从 I 里复现它已被编码的部分。

**因此我们改换路线：Ω 只在训练期使用，推理期完全不需要。**

- **代价**：必须有配对数据（本文数据集即为此提供，§4.1）；
- **收益**：不需要测试期检测器、不需要用户交互、不引入额外推理开销；
- **对照**：这与"检测后仅掩码域内合成"的路线（如 RemoVal 式检测 + 生成）在结构上不同——我们不生成、不检测，只用掩码**重加权监督**。

#### 3.5.2 定义

设 m_Ω ∈ {0,1}^(H×W) 为 §3.3.2 的可观测反射洞掩码，R̂ 为网络的有符号反射估计。定义**洞内反射幅度的归一化尺度**

```text
d_Omega = ( 1 / |m_Omega| ) * Sum over x of  m_Omega(x) * | R̂(x) |        （截断下限 1e-3）
```

以及两项监督：

```text
L_err_Omega   =  Sum over x of  m_Omega(x) * | T̂(x) - T(x) |
                 ------------------------------------------------
                 Sum over x of  m_Omega(x) * | R̂(x) |

L_hinge_Omega =  Sum over x of  m_Omega(x) * [ T(x) - delta(x) - T̂(x) ]_+
                 ------------------------------------------------------------
                 Sum over x of  m_Omega(x) * | R̂(x) |
```

其中过冲容限按**局部反射幅度**自适应：

```text
delta(x) = max( 4 , 0.5 * R_local(x) ) / 255
```

（R_local 为 R̂ 的局部中位幅度；早期实现用对比度指标 C_I 作锚点，语义已过时，本稿改为反射幅度。）

总损失按输出列加权（w_c = c + 1，与骨干的 4 列输出一致）：

```text
L_Omega = lambda_Omega * L_err_Omega + lambda_h * L_hinge_Omega
lambda_Omega = 3.0 ,   lambda_h = 1.0
```

#### 3.5.3 为什么是这两项

| 项 | 针对的失效 | 机理 |
|---|---|---|
| L_err_Omega | 洞内被错误地当作"该多减"的区域 | 洞内正确解接近恒等（T̂ ≈ I），该式在 T̂ → T 时自然降为 0；按 R̂ 归一化使不同反射强度的样本可比 |
| L_hinge_Omega | 洞内**过修**（实测洞内平均偏暗 **−1.03 灰阶**，§4.3） | 单边惩罚 [·]_+：只要不压过 T − δ 就不罚，δ 随局部反射幅度放宽 |

**与"通用损失加权"的三点区别**：

1. **归一化按反射幅度**（R̂ 而非固定常数），因而在配对间尺度不变；
2. **有方向性**——hinge 只惩罚一个方向（不许压过头），不是对称重加权；
3. **监督来源是配对数据**，而非测试期可得的图像统计量；因此它不违反 §3.4 推论 3。

#### 3.5.4 完整训练目标

```text
L = Sum over columns c of  w_c * [ Charb(T̂_c, T) + 1.5 * Charb(R̂_c, R) ]
    + 0.2 * || I - T̂ - R̂ ||_1
    + L_Omega
    + 0.5 * Charb(T̂, T)             （开源数据直督）
    + lambda_excl * || grad T̂ (*) grad R̂ ||_1
```

实测该 Ω 项占总损失的 **77–83%**（中位 **80%**），是主导项。

#### 3.5.5 与"定位路线"的对照

| 对比项 | 定位路线（§4.7 的 M1 探针） | 本文的监督路线 |
|---|---|---|
| 推理期需要 Ω | **是** | **否** |
| 需要用户交互 | 否（但需检测器） | 否 |
| 可达上界 | 直连 IoU **0.494**，跨域 ≈ 随机 | — |
| 效应量 | 无正结果 | **去掉该项 −2.91 dB**（0/15 场景胜） |

#### 3.5.6 两处已知的实现缺陷（如实声明）

| 缺陷 | 现象 | 本稿处置 |
|---|---|---|
| 归一化量取 `abs(I − T)`（早期实现） | I − T = R + (g−1)·T 被曝光失配主导（corr **−0.897**），使有效 λ_Ω 跨域漂移 **2.57–3.80** | **改用 `abs(R̂)`**（上式） |
| Hinge 锚点取 C_I | C_I 属旧语义，与"洞内反射仅剩 30%"不符 | **改用局部反射幅度** |

> **说明**：下文 §4.3 报告的 −2.91 dB 是在**早期实现**下取得的；改用 `abs(R̂)` 归一化后的结果需重测（§4.3 末尾给出该实验的预登记判据）。

### 3.6 干预式验收协议

**定义 4（ControlGain）** 设 T̂ = f_θ(I, c)，c 为条件标量：

```text
S = d mean(T̂) / d c            ControlGain = S / mean(I)
```

验收判据：**ControlGain ≥ 0.50**。理想物理出口 T̂ = (I − R̂)/τ（τ = 1/c）给出 1；取 0.5 为半效力下限。

**必带对照**：(i) **无信息条件**（训练时把 c 与样本随机错配），应 ≈ 0；(ii) **冻结基线**（不使用 c），应 ≈ 0。

### 3.7 评测协议（最低要求）

1. **必带平凡基线**：identity（T̂ = I）、identity + 全局色调（2 参数）、identity + 低阶空间亮度场（17 参数，oracle）。
2. **光度/结构分离**：报告闭式全局增益校正后的 PSNR（量化"亮度值多少 dB"）与结构指标（HF-PSNR、高通相关）。
3. **场景级配对统计**：以场景为独立单位，给出 95% 置信区间与最小可检测效应（MDE）。
