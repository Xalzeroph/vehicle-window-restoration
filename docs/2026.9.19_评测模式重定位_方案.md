## 1. 主张与边界

三条主张：

- **C1 现象**：现有 SIRR 评测对两类失效失明——① 强反射区感知残留（残留比中位 0.59 仍肉眼可见）；
  ② **干净区主动伤害**（近零反射帧 −3.9~−7.9 dB、砍 43% 梯度能量；r_obs<0.05 块 −2.26 dB / 72% 为负）。
- **C2 协议**："约束非劣"双轨：自适应 mask + 免伤项 + 感知项 + 恒等/糊化基线必同框 + 场景聚类 CI + 种子方差入门限。
- **C3 应用**：RDNet / RemoVal / 后续方法同框比较 → 判出"公开方法在实拍不优于 identity_gm"。

**诚实边界（"相对普适"的准确含义）**：

- 不称场景普适（同一块膜、同一手机、3 房间、24 场景、43 输入，均如实列出）；
- 只称"**失效机制与评测协议可移植**"，用 OpenRR-5k（独立来源 5000 对）分层抽 200 对复跑支撑；
- OpenRR-5k 反射强度只有目标域 1/3~1/4 → 幅度预期缩小，正文按机制陈述（§4a）。

**论文落位**：contribution 2（现象 + 诊断协议），约 0.75–1 页 + 附录；**诊断定位，不做排行榜**
（防与 OpenRR / NTIRE2026 类基准撞车）。退路：人评两周排不进 → 降为内部工具 + 附录。

## 3. 最小充分协议

**必进**：

- (i) **mask 自适应**：`D = max_c|I − g·T|`（g = T→I 最小二乘，修旧案方向错误），`thr = max(3σ̂_D, 8)`，
  σ̂_D 由 D 低分位稳健估计（实拍 σ_D 6.8–7.6 → thr≈20–23）；敏感性 {2,3,4}σ；mask 禁含被评输出；
  合成/实拍两域数字不混排。
- (ii) **NGR_bg（免伤项）**：非反射区；分母改 **σ=4 低通 + 16² 块级**（旧案 61% 像素被 n0 钳死退化成 L1）；
  报钳死比例，门 ≤30%。
- (iii) **感知项**：整图 + 裁剪 LPIPS；裁剪设降级门（组件 ≥2% 且 ≥64px、bbox ≤50% 面积，
  不满足则降级整图并标注）。
- (iv) **裁决规则**（替旧案自相矛盾的 G-D）：先过不劣约束（ΔLPIPS 中位 ≤0 且 CI 上界 ≤+0.005；ΔNGR_bg 同）
  → 违反即 FAIL；通过者比 ΔNGR_m 做场景级符号检验（p<0.05 判胜，否则 tie）；
  **权衡关系报 Pareto 面，不判"互斥 FAIL"**；ΔPSNR 仅作第 4 参考。
- (v) **统计**：场景聚类 bootstrap（13/6/5 簇，B=1e4）；可训练臂 ≥2 seed，
  判决门限 > max(CI 半宽, seed 极差 0.4–0.6 dB)。
- (vi) **基线必同框**：identity / identity_gm / const / blur_identity（`scripts/eval_real_pair.py` 已含）。

可选：Exist ρ/A（eval-only 报告）；r_obs 分箱曲线；myvideo 3904 帧 sanity。

**砍**：合成各臂重评、v23/indomain 胜负、固定阈值 mask、litgt 主表、直接上 600 判定。

## 4. 预登记判决门（先写后跑，可 FAIL）

**a. OpenRR 可移植性（同签名复现）**——四签名同看方向：

① 低反射分位区（r_obs<0.05 块）ΔPSNR(rdnet−identity_gm) 中位 <0 且 CI 上界 ≤0；
② 干净区梯度能量损失 >20%；
③ 强反射区（r_obs 上四分位）rdnet 残留 ≤ identity_gm；
④ identity_gm ≥ identity。

PASS=四向全对；FAIL=任一反向（尤其①>0 且 CI 下界>0）。
幅度只记区间不设门（OpenRR |R| 为目标域 1/3~1/4，**待实测校准**）；
CI 跨 0 或无方向反转但有幅度 = "机制可移植、幅度依赖 |R| 强度"，按机制陈述。

**b. 人评 pilot**：一致率 = 单图"机器更优者 == 人 Q1"比例。
判**可用**：总 ≥70% 且近零子集 ≥60% 且 trap 无偏好 ≥80%；
50–70% 判**需修**（改 Q2 措辞/图选后重跑）；<50% 或 trap 假偏好 >40% 判**失效**（机器判据不作证据）。

**c. RemoVal 臂**：支持"通病" = ≥2/3 套出现低反射分位区 ΔPSNR<0 且 CI 上界 ≤0，或干净区梯度损失 >20%；
推翻 = 三套均不劣于 identity_gm 且干净区损失 <10% → 主张降为"RDNet 特有，样本待扩"。
输出有对齐/尺寸差异一律 resize 回 GT（待实测）。

**d. 协议单测**（原 G-A 降级）：6 个合成解析用例——全反射图 / 无反射图(δ→0) / 常数增益(ΔNGR_bg≈0) /
JPEG 重压(钳死≤30%) / 裁剪 30%(LPIPS 降级触发) / 单色块(σ̂_D 稳定)。
容差：解析 ±1e-6、估计量 ±0.01。

## 8. 决议记录与旧案处置

### 8.1 旧案（9.17 新判据落地）四类硬伤（红队审读，2026-09-19）

① 实拍 mask 固定阈值移植错：thr=8 的"5.3σ"来自合成 σ=1.5；实拍背景残差 robust σ_D≈6.8–7.6
→ thr=8 仅 ~1σ → frac(D>8) 实测 jun 0.79 / apr 0.88 / may 0.74（构建口径 frac_M 中位 0.24，实际阈值 11–92）；
② 增益公式方向写反：应为 `|I−g·T|`（g≈1.1–1.2）；
③ NGR 分母 61% 像素被 n0 钳死退化成 L1；裁剪 LPIPS 在 mask 撑满时退化为整图；
④ G-D 判决门主集自相矛盾（"去反射↔免伤"权衡被判成互斥 FAIL）；种子方差未入 CI。
