## 0. 一句话目标

把 SIRR 从"总是输出一张修复图"重构为**选择性恢复**：在**无外部掩码**的条件下自动判断"**该不该动手、动多强**"，并以"**不劣于输入**"为硬约束——先在公共 SIRR 基准上验证通用性，再在车窗域验证最难情形。

---

## 1. 方法定义

```
P = RDNet(I)                     # 修复器冻结（官方权重），可换任意 SIRR 模型
Î = I + g ⊙ (P − I)              # g ∈ [0,1]^(H×W)：门控图，唯一可学之物
```

**三块组件（每块对应已核实的顶会论文）**

| 组件 | 出处 | 作用 |
|---|---|---|
| 严重度 + 可靠度双图估计 | UCMNet(CVPR26) / FUMO(ECCV26) / CBDNet(CVPR19) | 从单帧判断"该不该动、有多难" |
| 连续力度控制 | UniSER(CVPR26) 的 `αM` 软值掩码 / LUCID(SIGGRAPH26) | 二值开关 → 连续力度 |
| 区域路由与专家 | RegionFuse(CVPR26) MoRA / MoCE-IR(CVPR25) / MoLE(ICLR24) | {恒等 / 轻修 / 全修} 三档路由（升级项，第二版） |

**理论锚**：SelectiveNet(ICML19) 的 **coverage–risk** 框架 —— 在"伤害风险 ≤ ε"约束下最大化"动手覆盖率"。

**结构性优势（相对 S2 微调的关键改进）**：门控的动作空间是"两张**已有**图像之间的凸组合"，**无法自造像素**。最坏输出 = 输入。S2v2 那种"加约束 → 更糊"的对冲收缩**在结构上不可能重演**。

## 2. 监督信号（四层）

### 2.1 主标签：力度的闭式最优解 g\*

记 `a = I − T`、`b = P − I`，最小化 `‖a + g·b‖²`：

```
g* = −⟨I − T, P − I⟩ / ‖P − I‖²
```

几何含义：把真值 T 垂直投影到 I→P 线段上的落点。
- `g* = 1`：模型改动正好是缺的那块 → 全收
- `g* = 0`：改动完全帮倒忙 → 不动（**E4 的"36% 块不该动"即 g\* ≤ 0 的块占比**）
- `g* < 0` → 夹到 0；`g* > 1` → 夹到 1（只能在线段内插值，无法超越 P）

块级实现 = 块内做内积。**零标注、可溯源、逐块可算**。

### 2.2 感知修订 g\*\*

在 `g* ± 0.3` 内扫 5–7 个值，取"ΔPSNR 不降 **且** LPIPS 不劣"者。用途：治 L2 解的感知偏差（E4 已证 PSNR 与 LPIPS 会反判）。

### 2.3 物理一致性校验

在合成 `I = T + β·R`（β 已知）上检验 g\*\* 是否**随 β 单调递增**：
- 单调 → 标签可信 → 用回归目标；
- 不单调 → 退化用**排序损失**（只学"哪个更重"）。

### 2.4 兜底：no-harm hinge（不依赖任何标签）

```
L_harm = relu( |Î − T| − |I − T| )
```
只要输出比输入差就罚。这是"不劣于输入"的**直接目标函数**，在无标签、无 oracle 的情况下依然有效。

### 2.5 总损失草案

```
L = λ1·‖g − g**‖²        # 只统计 ‖P−I‖ 不接近 0 的块
  + λ2·L_rank            # 单调性（若 2.3 判为不单调）
  + λ3·L_harm            # no-harm 兜底
  + λ4·‖∇g‖²             # 空间平滑，防块间跳变
```

| 步骤 | 内容 | 成本 | 判决门（预登记） |

## 5. 对照臂（缺一不可）

| 臂 | 定义 | 作用 |
|---|---|---|
| identity | 输出 = 输入 | 平凡基线（E4 已证在 dev 上 ③④ 天然过） |
| RDNet | 输出 = P | 被修正的对象；也是"单一力度"的现行代表 |
| **ours** | `I + g⊙(P−I)` | 本方法 |
| oracle-binary | 逐块取优（E4 口径） | 二值上限（+2.02 dB） |
| **oracle-continuous** | 逐块用 g\* | **本方法族（插值族）的真正上限**，用于报"门控收下了上限的百分之多少" |
| （可选）第二 P | RemoVal 门控 | 检验门控是否对 P 泛化，非针对 RDNet 调参 |

## 6. 指标（必须同时报"平均质量"与"伤害率"）

1. **质量**：PSNR / SSIM / LPIPS（或 DISTS），逐数据集 + 宏平均；
2. **harm rate**：ΔPSNR<0 或 LPIPS 变差的图占比 —— **本课题新增的一等公民指标**（现有 SIRR 论文从不报）；
3. **细节保留**（判据 ⑤：Laplacian 能量比）；
4. **剂量-反应曲线**（按 r_obs 分箱的 ΔPSNR 与 g 均值）—— **论文主图**；
5. **上限收下率**：`(ours − identity) / (oracle_continuous − identity)`。

## 8. 结构性边界（先写清楚，防事后被指）

1. **门控只能治"过头"，治不了"不够"**：`g* > 1` 的块无法超越 P；而 E3 实测强反射区**残留比 0.59** 正是"不够"。→ **门控天花板 = E4 的 +2.02 dB，且属止损型收益，不含"把残留六成修掉"**。
2. **门控自己不保证域不变**：它也是学出来的。判决实验就是 B1 —— 若在 may 上**退化为 0**（不动手），及格线直接达成（0/11 → 9/11）且证明其保守性域不变；若**乱开**，则回到信号层改造（多模型一致性 / 无参考伪影检测）。
3. **不承诺**跨域"修好洞"（属 P2/P4，需数据或语义路线）。

## 9. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 门控过拟合训练域 | 容量压到 0.1–1M；输入仅用局部统计（对比度/亮度/残差幅度/梯度）；合成多域覆盖；干净图负样本 |
| 标签被 PSNR 带偏 | 用 g\*\*（感知修订）；所有结论同时报 LPIPS |
| 干净图负样本把门控压得过保守 | 先跑"有/无负样本"对照臂，再定采不采 |
| SIR2 污染基准 | 训练端硬性剔除（含 T 源） |
| A0 否掉前提 | 属有效判决：省下后续全部功夫，论文退回场景定位 |
