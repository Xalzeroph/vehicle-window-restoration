# 2026.9.15 贴膜退化场景分离器（RDNet-T）优化实施方案（Opus 规划）

> 缘起：E1 证明 RDNet 官方权重在贴膜衰减域 zero-shot 崩塌（29.0→9.5 dB，内容错误 15dB 主导）；
> 9.13 探针结论"端到端杠杆在 R̂ 不在 α"——分离器是"车窗透视增强"效果的主瓶颈。
> 本方案由 Opus 子代理产出（含 GPU6 显存实测 <10 min），可直接转为下一轮执行计划。

## 1. 路线选型

- **主线 = (a) 域适配微调 RDNet（冻 FocalNet-L，训 60.7M/266M）+ (c) 的"物理出口"作为方法增量**
- 证据：pilot 配方（冻 FocalNet，4000 iter）已把 v2.1 ᾱ=0.3 档 12.0→16.5 dB（+4.5，~5 GPU·h）；
  v2.1 上官方 zero-shot 在 gm 口径全档**不如"直接放大输入"**（17.84/14.95/12.31 vs 18.04/15.71/13.27）
- (c) 独立不成立（E3：失败是表征级内容损伤，α<0.12 像素占误差能量 78%、corr(R)≈0，后置头只能补亮度）；
  其中唯一有正增量证据的是**减法-除法物理出口**（(I−R̂_B)/α_GT 比 B 实际 +0.38~+0.70 dB）→ 作为主干训练后的参数化出口
- (b) 从零训 266M 无预训练先验、10GB/周期内风险过高，仅消融；(d) 级联仅兜底

## 2. 数据管线（含 9.15 泄漏教训约束）

- **T 池**：`data/pools/matched_pool_0915`（60%）+ sir2/nature/scenes（40%）；**训练前强制
  `check_t_src_leak.py` 内容级 md5 核查（vs v2.1 与 indomain 两个 gt），命中即重建**
- **R 池**：`data/pools/r_rrw_strong/pool`（69，排除测试场景），建议扩至 ≥150
- **档位**：核心 {1.0,0.6,0.3}（对齐 v2.1）+ 低档尾 {0.15,0.1}（各 ~10%）；不含 0.05（v2.1 已判死）
- **渲染 448²**（训时多尺度裁剪），物理参数与 v2.1 一致（coverage+arc+g、p=0、r_sat=0.45、σ=1.5），
  仅对 r_sat/cover/s/noise 小幅随机化；规模 4000 场景×5 档 ≈ 20k 样本（~6 GB）
- 代码改动小：`build_train_triplets.py` 加 `--levels`（现硬编码 3 档）

## 3. 训练配置（GPU6 实测）

| 配置 | 峰值显存 | 速度 |
|---|---|---|
| 冻 backbone bs8@224² | 6.3 GB | 0.62 s/it |
| 冻 backbone bs4@288² / bs6@256² | 5.6 / 6.2 GB | 0.58 / 0.61 s/it |
| 不冻 backbone bs2@224² | 8.1 GB | 0.64 s/it |
| 推理 832×384 fp16 | 1.6 GB | 0.21 s/img（全测试集 <30 s） |

主配置：**冻 FocalNet-L、bs8、随机裁剪 224-320²+宽高比抖动、AMP、Adam 1e-4 cosine、30k iter ≈ 5-6 h/卡**。
损失：4 列加权 Charbonnier(T) + 1.5·(R) + **逆衰减权重 w=clamp((0.3/α_GT)²,1,10)** + 0.2×recons。
OOM 兜底 bs4+累积×2（4.1 GB）。入口：新写 `scripts/finetune_rdnet_tint.py`（复刻 `finetune_alpha_tap.py` 骨架，
直用 `FullNet_NLP`，已验证 rdnet.pth strict 加载 missing/unexpected=0），加 Makefile target。

## 4. 评测协议与预登记门（候选）

测试：v2.1 + indomain（双测防过拟合）+ **新建 v2.2 scan**（v2.1 物理 × 6 档 ᾱ，12 场景，CPU 5 min）出 E1 式曲线。
基线四线：input 放大（18.04/15.71/13.27）、RDNet zero-shot（17.84/14.95/12.31）、
pilot B_r2（19.62/18.07/16.51，预算对照）、noA oracle（23.40/18.90/14.09，上界）。（数字见 pilot 记录）

- **G-R1 提升门**：v2.1 ᾱ=0.3 ≥17.5（+1.0 over pilot）、全档不低于 pilot −0.2、indomain−v2.1 ≤1 dB
  （口径修订见 §10：主口径=raw；indomain 降报告项）
- **G-R2 方法门（同算力对照）**：物理出口/损失组件 ᾱ=0.3 ≥+0.3 dB 且 ᾱ=1.0 ≥−0.2 dB（never-worse）
- **G-R3 压力门**：v2.2 scan ᾱ≤0.15 处 ≥ ingm+3 dB（消除"不如直接放大"）

## 6. 风险与兜底

① 合成域过拟合 → 双测试集+实拍 sanity+参数随机化；② 低档噪声放大 → w 上界 10、监控；
③ R̂ 退化（pilot A 前车：长训 R̂ 反降）→ 出口零初始化+ramp、不回流主干；④ 域不匹配（历史坑）→
matched pool+强制 md5 门+domain_stats；⑤ **不达标时论文写法**：域适配 baseline（+5 dB、never-worse）
+ 失效分析章（E1 崩塌曲线 / E3 归因 / oracle 上界 / α 头三路负结果）——素材已齐，方案天然可降级。

## 7. 补充待做（2026-09-15 晚，用户确认挂起）

**[待做] Retinex 式自估场的消融实验**（零训练，CPU ~30 min）：
背景——R 分离后 `T0 = α·T` 本身就是 Retinex 形态的问题（乘性平滑场），物理出口（除 α̃）与
Retinex（自估场）数学同族，区别在**场的来源**与**边界假设**（膜边界 2-4.5px 硬边 vs Retinex 的平滑先验→光晕）。

设计：合成 `T0 = α_GT·T`，比较三条路的 PSNR：
- A 用 GT α 精确除（上界）
- B 纯 Retinex 式自估场（大核滤波/包络等）
- C 锚定结构化估计（α 头口径：硬边掩膜 × 平滑增益 × 档位）

产出：B 相对 A/C 的差距 + **边界带 vs 膜内的分区误差**（量化光晕代价）→ 进论文消融表，
论证"结构化/锚定估计"的必要性。另：全膜无参照时 Retinex 式感知增强作为兜底分支（与分析章绑定）。

**[储备] 9.15 idea 2.0：下游任务评测章**（YOLO 检测 / 车窗后人脸识别 / 姿态；四臂+降窗天花板；
解决实拍 GT 像素对齐难题+应用叙事；详见 `docs/2026.9.15_idea2_下游任务评测方案_储备.md`（记忆 `project-idea2-downstream-eval`））。
