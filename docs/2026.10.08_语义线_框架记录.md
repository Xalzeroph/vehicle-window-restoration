# 2026.10.08 语义线（P6）框架记录

> **性质**：候选主线（止损后指定的主线）的**记录档**。用途：把"为什么看过那么多图却没有语义先验"这个问题、已有机制证据、三步路线与**生死判据**固化，供决定投入。
> **与 ③ 的关系**：③（诊断论文）不依赖新方法成功、确定性最高；本线**依赖一个尚未验证的诊断**（S10 探针），风险更高但上限更高。

---

## 0. 命题

> SIRR / 车窗增强的失败**不只是低层问题**：在"反射被遮挡者挡住"形成的暗区（Ω，人影洞）里，逐像素证据弱到不足以下判断（M1：单帧定位 IoU 上界 **0.494** ≈ 瞎猜 0.143），而**对象级语义先验**从未进入训练目标——因此模型只能"往均值糊"（S2v2 对冲收缩）。

**要回答用户原问题**：为什么看过那么多图，却还是没有语义先验？

## 1. 已有机制证据（5 条，可溯源）

| # | 机制 | 证据 |
|---|---|---|
| M1 | **损失决定上限**：逐像素回归的最优解 = 条件均值 `E[T\|I]` → 多峰处必然糊 | S2v2 加保真项后细节保留 **0.832 → 0.73**（对冲收缩）；`docs/2026.9.21_S2训练_结果与归因.md` |
| M2 | **骨干有语义但接不到输出**：FocalNet 分类预训练、PEFT 只学像素增量 | `docs/2026.9.3_反射去除调研.md`（Mona-tuning 消融：去掉掉 0.63 dB） |
| M3 | **监督里没有对象**：训练图以像素目标出现，模型学的是"局部外观统计→修正量" | 注入实验：**按"暗"动手、不按对象**（官方 corr_dark 0.29、臂 0.39–0.53） |
| M4 | **分类级语义 ≠ 非模态补全**：认识茶盒 ≠ 推断被遮住那半的形状 | 文献侧（ICCV25 Contact-Aware Amodal Completion、CVPR25 Diffusion Priors for Amodal Segmentation）；我们未验 |
| M5 | **像素级定位封死，对象级未封** | M1 探针：IoU 上界 0.494；"抄上一帧" 0.67–0.83（但约束单帧） |

## 2. ⚠️ 今天新增的反向证据（必须计入预期）

用 CLIP（强）+ ResNet18（弱）在 ImageNet 空间测"输出可辨识度"（`eval/trustgap_imagenet_1008.csv`）：

| 量 | 输入 I | 干净真值 T | 差值 |
|---|---|---|---|
| gap（强弱一致率），lovo_k2 | 0.17 | 0.30 | +0.13 |
| CLIP 置信度 | 0.096 | 0.106 | **+0.010** |
| ResNet 稳定率 | 0.48 | 0.53 | +0.05 |

**读数**：从"带反射的退化输入"到"干净真值"，**语义可辨识度的变化很小**（CLIP 置信度只差 0.010）。
→ 说明**我们的退化并没有严重破坏"物体还能不能认出来"**，因此**基于可辨识度的语义监督（FoCo 式）动态范围很小**。
→ 这条也**间接压低**"语义线"的预期：如果失败主要是低层（色调/细节），语义先验能救的部分可能有限。**这正是 S10 必须先做的原因。**

## 3. 三步路线

### S10 语义探针（判决性，~0.5 GPU·h）——**本线的生死门**

**判决问题**：洞区（Ω）覆盖的是"**语义对象**"还是"**无语义纹理**"，失败形态是否不同？

- **做法**：在 **GT（干净透射图）** 上用 **SegFormer-B0-ADE(150 类)** 分割 → 把 Ω 按语义类别分箱为
  **对象类**（table / cabinet / car / person / chair…）与 **stuff 类**（floor / wall / ceiling / sky / road…）
  → 比较两箱上的失败指标：Ω 内修复进度 ρ、细节保留（Laplacian 能量比）、ΔPSNR。
  *（在 GT 上标注而非在输入上，可绕开"分割器在低光/反光图上本身会崩"的问题）*
- **预登记门**：
  - **PASS**：两箱失败指标差异 **≥0.15**（或排序在 apr/may 双域一致）→ 缺语义先验的诊断成立，本线继续；
  - **FAIL**：差异 **<0.05** → 失败与语义无关，瓶颈在低层 → **本线止损**，资源回到 ①/③。
- 资产：SegFormer-B0-ADE 已就位；Ω 掩膜、各臂预测、LOVO 统计脚本均已有。

### S11 有监督非模态补全（2–4 GPU·h）——**我们独有的优势**

- **独有资产**：**真配对 GT（黑布档）**——公开 SIRR 数据集没有"同场景同机位、只有反射被挡掉"的真值；amodal 文献多靠合成遮挡。
- **做法（两选一或并行）**：
  1. **合成洞训练**：在 GT 上按真实 Ω 形态挖洞 → 训练"用周围内容 + 对象先验补回"的分支（监督 = GT 被挖掉的部分）；
  2. **真实 Ω 监督**：直接用 apr/may 的真实洞做监督（输入 = 带反射帧，目标 = 黑布档）。
- **判据**：Ω 内结构恢复（细节保留回升 ≥0.1、ρ 达标）**且不过冲**（沿用 9.20 的特异性护栏：Ω 外 |Δluma| ≤3/255、真暗物对照区削幅 ≤25%）；另报"对象一致性"（补出的结构与周围对象是否连续）。
- **风险**：审稿人会问"是不是生成/幻觉" → 用配对 GT 与过冲护栏挡。

### S12 reflection-invariant 训练（1–3 GPU·h）——**零采集成本**

- **资产**：**MyVideo 24 场景 / 3904 帧**（含大量"拍摄者自反射"帧，9.21 已记录）；同场景多帧 = 同一透射在不同反射/遮挡形态下的多个观测。
- **做法**：约束"同一场景不同帧的输出必须一致"（自监督，无需额外 GT）→ 逼出**忽略反射形态、锁定透射语义**的表示。
- **判据**：跨帧一致性提升；且 may 上细节保留回升（针对"域外低通"这一已知机制）。

## 4. 与文献划界

| 已被占 | 谁 | 我们不能声称 |
|---|---|---|
| 低光增强的多基础模型协作（FoFA/GaTA） | FoCo (CVPR 2025) | ❌ 协作机制本身（且已实测：作信任信号 FAIL） |
| 半透明遮挡统一处理（反射/阴影/光晕） | UniSER (CVPR 2026) | ❌ 统一软效果框架 |
| 非模态补全 / 用扩散先验做 amodal | ICCV25 / CVPR25 多篇 | ❌ "用扩散/先验做补全"本身 |

**我们独有**：① 反射被遮挡形成的 **Ω 反事实退化**（不是合成遮挡，是真实物理成因）；② **同场景同机位真配对 GT**（黑布档）；③ 单帧约束下的对象级（而非像素级）路线。

## 5. 审稿人攻击与预备回答

| 攻击 | 回答 |
|---|---|
| "所谓语义先验就是幻觉/生成" | 用**配对真 GT**监督，不是无中生有；并报过冲护栏（Ω 外 |Δluma|、真暗物对照区） |
| "单帧凭什么推断被遮挡内容" | M1 已证**像素级**定位上界 0.494；本路线不做像素级定位，做**对象级一致性**（不同问题） |
| "洞区就是低光，为什么扯语义" | 这正是 S10 的判决内容：若两箱失败无差异，我们自己会撤（已预登记） |
| "GT 有黑布偏色" | 9.22 已量化并给出协议 v2（锁 AE/AF）；补拍数据可对照 |

## 6. 缺口与风险

| # | 缺口 | 成本 |
|---|---|---|
| G1 | **S10 未跑**（生死门） | 0.5 GPU·h |
| G2 | Ω 语义分箱需要**人工抽检**（SegFormer 在 ADE 上的可靠性） | 你侧目检 ~10 分钟 |
| G3 | 若走 S11，需要设计"补全分支"与主干的关系（并联/串联/后处理） | 设计 |
| G4 | S12 需要整理 MyVideo 的多帧配对结构 | 1 GPU·h |

**主要风险**：S10 判否（语义不是瓶颈）→ 本线止损；以及 §2 那条反向证据提示的"语义动态范围小"。

## 7. 判定顺序（建议）

```
S10 探针（0.5 GPU·h）──PASS──→ S12（便宜、零采集）──→ S11（贵、上限高）
        │
        └──FAIL──→ 本线止损；资源转向 ① 数据线 / ③ 诊断论文
```

> **一句话**：语义线的上限最高、也最贴用户最初的问题，但它的**生死由 S10 决定**——先花 0.5 GPU·h 判决，再谈投入。
