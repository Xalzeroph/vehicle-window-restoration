## 四、一句话总结

**方法层三个病（单一力度 / 微调反噬 / 语义缺位）、数据层两个病（域覆盖 / 监督有偏）、任务层一个硬上限（单帧定位）、评测层一个缺口（跨域协议）。**

- ~~最有正结果潜力且撞车可控：**方法层的"自动选择性恢复"**（S1+S3+S4+S5）~~ → **2026-10-08 已试并止损**（见第二批）；问题本质是**域判别**而非力度调节；
- **当前主线**：**方法层 P6「语义缺位」**（S10 语义探针 → S11 有监督非模态补全 → S12 reflection-invariant），这是唯一还没被否掉、且与"为什么看过那么多图仍无语义先验"直接对应的方向；
- 新增**评测层硬要求**（本轮产物）：车窗数据上 PSNR 类结论**必须光度归一化**，且**必带平凡基线（affine + 标量）**；否则会出现假 PASS（门控 v1 即为实例）。
- 最硬的边界：**P4 的单帧定位上限**（0.494）只封死"逐像素定位"，没封死"对象级推理"。

## 五、与既有文献的划界（不得再声称新颖的两条）

1. "反射 + 阴影 + 光晕统一处理"（半透明遮挡家族）—— 已被 **UniSER（CVPR 2026）** 占；
2. "可控力度 / 区域编辑"本身 —— 已被 **UniSER（mask+strength）** 与 **LUCID（SIGGRAPH 2026，CFG）** 占。

**我们仍独有**：① **自动**（无掩码）判断且判据为"不劣于输入"；② **人影洞（Ω）** 这一反事实退化；③ **跨域留一协议 + harm-rate 指标** + 可解释失败诊断（剂量-反应 / 门控 headroom / 注入触发）。
