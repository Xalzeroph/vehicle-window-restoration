# 2026.9.13 α 线改进方向评审：零训练探针归因

> 状态：**评审已入库；P0 实验未执行（待裁决）**。本文汇总 2026-09-13 晚的四组零训练探针（纯 CPU、闭式解/秒级），对 α 头饱和负结果做归因，并给出改进方向清单与决策门。

## 0. 判决（先说结论）

**"换特征源提精度换 PSNR"的前提被推翻**：0.7 平台不是 FocalNet 特征或 α 头架构的锅，而是**任务级的可辨识性现象**——四个互相独立的估计器（训练 8000 iter 的 α 头、31 维原始统计线性回归、B 臂自洽比值、全局统计档位分类）全部收敛到同一平台。端到端探针更进一步：**所有现实可得的 α̂（含完美掩膜、oracle 场景水平）做除法都打不过"不除法"的 B 臂**；只有 GT 逐像素 α 有 +0.38~0.70 dB。

建议裁决方向：**"换特征源"不再作为主线**；论文防御/诊断收口为主线 + 一个受控的"分解式 α"实验（带预登记判定门）+ 若要挤 dB，算力投给 R̂ 而不是 α。

## 2. 探针证据（全部可复现，方法见附录 A）

### 2.1 探针 0：α 头特征通路形状核验（FocalNet → 头）

实测（96×96 输入，`/tmp/focal_head_probe.py`）：

```
x_emb (stem out): 192×48×48  (= h/2)
x_base: [192@h/2, 384@h/4, 768@h/8, 1536@h/16]
adapter[0]: x_stem → 64@h/2             (α 头 tap 1)
adapter[4]: c3     → 512@h/16           (α 头 tap 2 的上游)
fused feat 128@h/2 → logits 1@h/2 → 双线性↑full → alpha_refine → α̂
init: α̂ ≡ 0.525 (零初始化 ⇒ σ(0)=0.5)
params: total 266.6M / 冻结 backbone(baseball.) 205.7M / adapter 1.06M / α 头 0.11M
```

**修正 opus 评审**：其假设 "x_emb = h/4" 有误，实为 **h/2**（vendored `focalnet.py` 的 PatchEmbed 是 stride-2）。`rdnet_atap.py` 模块 docstring 里 h/4、h/32 亦为过期注释。修正后头的信息通路比 opus 假设略好（h/2 stem 特征直连），不改变其 D1-D10 主体结论。

### 2.2 探针 1：31 维原始统计线性回归 vs α 头

每像素 31 维特征（RGB、3 尺度 box-mean、中心-局部对比、色度/归一化色差、全局均值广播），ridge 闭式解。训练：train_pairs 300 图 stride 4（94 万像素），10% 留出选 λ（ALL λ=10, val MAE 0.2247；GLOBAL λ=0.1, val MAE 0.1371）。测试：v2.1 全 12 场景，stride 2，分区口径同 `scripts/analyze_alpha_sat.py`。

| 估计器 | naked α̂ (GT 1.00) | film α̂ @1.0/0.6/0.3 (GT 0.717/0.582/0.293) | band MAE | all MAE |
|---|---|---|---|---|
| α 头 A_sat（8000 iter 训练） | 0.711 | 0.509 / 0.445 / 0.327 | — | ~0.17* |
| **ridge-ALL**（线性，31 维） | **0.741** | 0.630 / 0.614 / 0.550 | 0.193 | 0.203 |
| ridge-GLOBAL（每图常数，21 维全局统计） | 0.634 | 0.658 / 0.602 / 0.563 | 0.231 | 0.248 |

（*α 头的 all MAE 为旧口径 αMAE，非同口径重算；film 聚合 GT 0.49，ALL/GLOBAL 聚合预测 0.591/0.596。）

读法：
1. **线性原始统计在 naked 上超过训练 8000 iter 的头**（0.741 vs 0.711），整体 MAE 只差一点；头的优势仅在档位区分（film spread 0.18 vs 线性 0.08）。"FocalNet 特征没膜信号"应改成"**廉价特征里都只有这么多膜信号**"。
2. 头的 naked−film@1.0 对比度差 0.202，线性 0.111，GLOBAL 甚至为负（0.634 vs 0.658，naked 预测低于 film）——**GLOBAL 常数连"裸 vs 档1 膜"都分不开**，因档 1.0 场景几乎全裸、全局统计被 naked 主导。

### 2.3 探针 2：B 臂自洽比值 α̂=(I−R̂_B)/T̂_B（零额外参数）

直接用 B_r2 的输出（`/tmp/alpha_ratio_probe.py`）：

| 档 | naked α̂r (GT 1.00) | film α̂r (GT) | band MAE | all MAE | α̂r>1 份额 |
|---|---|---|---|---|---|
| 1.0 | 0.680 | **0.612** (0.718) | 0.215 | 0.268 | 1.0% |
| 0.6 | 0.655 | **0.508** (0.583) | 0.256 | 0.217 | 0.4% |
| 0.3 | 0.605 | **0.342** (0.293) | 0.239 | 0.158 | 0.3% |

读法：**B 臂已经隐式持有与专用 α 头同级、且 film 档位更准的 α 信息**——这是对"专用 α 头"novelty 的坏消息，对"自洽比值 + 修正头"是路线图。naked 依旧差 0.3+（与所有估计器一致）。

### 2.4 探针 3：除法变体的端到端 PSNR（B_r2 的 R̂ × A_sat_r3 的 α̂）

T0 = I − R̂_B，T̂ = clip(T0 / clip(α̃, 0.05, 1))（`/tmp/gated_division_probe.py`）：

| variant | α=1.0 | α=0.6 | α=0.3 |
|---|---|---|---|
| v0 不除（=B_r2） | **19.62** | **18.07** | 16.51 |
| v1 全图除 α̂ | 16.19 | 16.58 | 16.82 |
| v2 阈值门控 τ=0.75/0.85/0.95 | 16.08 / 16.13 / 16.17 | 16.41 / 16.51 / 16.57 | 16.78 / 16.80 / 16.82 |
| v3 **oracle GT α 除** | **20.08** | **18.77** | **16.89** |

追加（`/tmp/gated2.py`，oracle 掩膜 = α_GT<0.95 只除膜区）：

| variant | α=1.0 | α=0.6 | α=0.3 |
|---|---|---|---|
| v4 完美掩膜 + α̂ 膜内除 | 18.07 | 16.92 | **17.21** |
| v5 完美掩膜 + 场景真值水平（空间常数） | 19.47 | 17.50 | 16.21 |
| v6 完美掩膜 + α̂ 场景级校准 | 19.16 | 17.52 | 16.88 |

四条关键读数：
1. **oracle 天花板只有 +0.46 / +0.70 / +0.38 dB**（v3 vs v0）——α 全部做对也只有这点收益。
2. α=1.0 档的 −3.4 dB 崩点是 **naked 过除**：α̂≈0.7 把裸区放大 1.43×，过曝。naked 失准是除法路线的头号杀手。
3. **阈值门控救不了**：门控依据 α̂ 本身，而 α̂ 恰好在裸区失准——需要**独立分割**而不是 α̂ 阈值。
4. 即使完美掩膜 + oracle 水平：v5（空间常数水平）仍全档 ≤v0（−0.15/−0.57/−0.30）——**收益要求逐像素形状正确，不是"档位级"正确**。v4 的意义是例外验证：0.3 档 α̂(0.327)≈GT(0.293) 时膜内除法 +0.70；高档 film α̂ 低估（0.51 vs 0.72）→ 过亮为负。

### 2.5 探针 5：档位（ᾱ∈{1.0,0.6,0.3}）单图分类

21 维全局统计 + softmax 回归（`/tmp/level_clf_probe.py`）：train acc 0.469，**test acc 0.556**（chance 0.333），混淆矩阵（行=GT 1.0/0.6/0.3）：

```
[[8 4 0]
 [1 8 3]
 [0 8 4]]
```

1.0↔0.6 互混，0.3 有 8/12 被判成 0.6。**单图档位本身就是弱可辨识**（线性下界口径；探针 1 的 GLOBAL 与此互证）。

### 2.6 附带核验：训练/测试口径差异

| 口径 | 训练对 (train_pairs_pilot, 2400) | 测试 (v2.1, 12 场景均值) |
|---|---|---|
| clip_frac（饱和像素占比）mean | 3.8%（median 1.1%，p90 11.3%，max 47.2%） | 1.4% / 1.1% / 0.9% @档1/0.6/0.3 |
| clip_frac @档1.0 | **6.1%** | 1.4% |
| α_eff | 0.896 / 0.658 / 0.405 | 0.892 / 0.655 / 0.410 |

α_eff 分布对齐（探针可比性没问题）；但**训练集饱和 headroom 明显更大**（档 1.0 差 4×+，max 47%），训练数据值得重渲——OOD 与泛化问题需记一笔。

### 2.7 旁证：B 臂 R̂ 已把有偏 α̂ 补偿进参数

pilot 记录 §7：低档（0.3）oracle α 除法增益最小（+0.38），因 R̂ 在训练中已把 α̂ 偏差吸收；高档收益直接受 α 质量限制。除法路线的收益结构 = 高档靠 α 质量、低档已被 R̂ 吃掉。

## 3. 反思：负结果证明了什么、没证明什么

| 候选瓶颈 | 现有证据 | 强度 |
|---|---|---|
| **可辨识性**（水平由先验主导） | 4 个独立估计器同平台（§2.2-2.5）；opus 评审 §2.4 理论（4 维乘性零空间）；E3 档位级误差 | **强（主因）** |
| **特征源**（frozen FocalNet 不可读） | 被削弱：31 维原始像素统计的**线性**回归即可复现平台；但非线性 raw 编码器未试 | 中（未排除） |
| **容量/优化** | 已证伪：8000 iter、热启、code 条件化三路无突破 | 已排除 |
| **损失几何**（log-L1→中位数 + 加权） | 未独立检验；affine 校准已排除"纯尺度问题" | 弱 |

没被证明的：「α̂ 不可能更好」（非线性 + 分布型损失未试）、平台的具体归因（贝叶斯行为 vs 先验匹配度）。

## 4. 改进方向清单（按瓶颈分层）

**A 组 — 把可辨识的部分做扎实（推荐主线，无论论文走哪条路都需要）**
- A1 **膜区分割/边界一等公民**：分割头 + 边界损失，指标用 IoU/boundary-F 而不是 α MAE。边界是唯一"真能学好"的部分（α̂ 结构 corr 0.46-0.70 已有基础）。成本低。
- A2 **水平后验化**：输出档位分布（或带区间），训练用同场景跨档配对；报告校准曲线。把"不可辨识"从缺陷变成卖点。成本中。
- A3 **naked 锚定损失 + 跨档排序 loss**：同场景 1.0/0.6/0.3 三连图**需重渲构造**（`build_train_pairs.py` 为逐样本随机源、无跨档配对；见《架构创新线实施方案》§7.1）。成本低。
- A4 **保守除法出口**：只在高置信膜区、按区间下界除。探针 v4/v6 表明它难为正值——定位为"安全性设计"而非增益来源。

**B 组 — 特征源/架构（预期已下调，只做受控一跑）**
- B1 **独立 raw 图轻量 α 编码器**（多尺度 + 绝对亮度/色度支路）：唯一能"翻案"特征源假设的实验，1 GPU·h。**预登记判定门 G-α1**：naked≥0.85 且 film spread≥0.25 → B 组继续；否则 α 精度线关闭。
- B2 全局×空间分解头（α̂ = lvl(I)·shape(x)，shape 锚定 naked=1）；B3 LoRA/浅层解冻、`stem_comp` 启用；B4 全分辨率细化升级 + **训练分辨率对齐**（224² vs 832×384，边界剂量差 ~4×）。

**C 组 — 端到端 dB 的真正杠杆（不在 α）**
- C1 R̂/分离质量续投（域适配已实证 +5 dB）；C2 **解耦判定**：freeze B 的 R̂ 只训 α+除法，隔离"α̂ 好能否转化"；C3 M4-gainmap 对照（论文必跑）；C4 输出参数化微调。

**D 组 — 论文防御（独立于成败，必做）**
- D1 三组 OOD 压测 + gainmap + shuffle；D2 claim 重写（"分布内透射场后验推断"，平台现象作为不可辨识性的实证）；D3 统计口径（场景数/多 seed/分桶指标/clip 口径）；D4 降级版结构（诊断章）。

## 6. 评审视角与 claim 边界

- 审稿人最可能的攻击是"你在做先验匹配"。今天的证据反过来是最佳防御材料：**四个独立估计器（训练头/线性统计/自洽比值/全局分类）收敛同一平台**——"单帧 α 水平不可辨识"的实证，写进 limitation 章节比任何辩解都有力。
- 现在最硬的三块：基准 v2.1 + 实拍对齐；ρ 解析上界（实测吻合 0.1-0.5 dB）；OOD 界定。**α 估计的措辞必须降级为"分布内后验推断"**。
- 若 P1 失败，论文形态：①贴膜域失效证据 + 基准 ②全局族上界定理 ③空间 α 价值 18.4/19.6/18.7 dB（oracle 除法 desaturated）④估计不可行性诊断（负结果即贡献）⑤域适配配方（+5 dB）——"基准 + 分析 + 配方"型论文，站得住。
- **明确不推荐**（见附录 C）：继续堆 α 头容量/迭代/特征宽度换 PSNR；期待"档位级"估计换 dB（v5 证伪）；affine 后处理校准。

- 档位分类：softmax 回归（全批梯度，600 iter，标准化），训练用 train_pairs meta.json 的 `samples[].id/level`。

## 附录 B：与 opus 评审的修正关系

- x_emb 实为 h/2（非 opus 假设的 h/4），模块 docstring 过期；不影响 D1-D10 与 §2 可辨识性主体结论；§7 分辨率预算的具体档位数字不受影响（h/2 tap 结论反而更有利）。
- opus §3.4 的 clip 校正余量（18.4/19.6/18.7 dB desaturated）与探针 3 的 oracle α 增益（+0.46/0.70/0.38 dB）方向一致：α 做满是有限但真实的空间增益，naked/过除是主要风险。

## 附录 C：登记为"不推荐"的动作（避免重走）
