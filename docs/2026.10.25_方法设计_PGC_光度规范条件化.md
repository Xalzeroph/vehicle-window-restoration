# 2026.10.25 方法设计：PGC —— 光度规范条件化（Photometric-Gauge Conditioning）

> **状态：设计稿，未验证。** 本文只做三件事：把病因逐条钉到实测数字上、给出最小可测方法、写清什么情况算失败。
> 判据与成本见 `2026.10.25_预登记_PGC两臂.md`。
> 前提校正与六篇对照见 `2026.10.25_局部退化条件化_六篇精读与联合退化对照.md`。

---

## 0. 一句话

> 现有去反射模型**已经**在条件化（RDNet 有冻结 ConvNeXt 出的 6 维 code），但那个条件**没有物理含义、也没有被验收过**。
> 本文把条件**锚到一个逐对可算的物理标量 ρ（净光度比）**，并给出**功能性验收协议**——即"改变退化，条件必须跟随"。

**这不是新加一个模块，是把已有的条件从黑箱变成可测、可验收的量。**

---

## 0.5 ⚠️ 数学评审后的**形式变更**（本节覆盖下文的写法）

形式化（`2026.10.25_PGC形式化与数学评审.md`）给出两条命题，**改变了方法的数学形态**：

1. **命题 2**：净光度比 `ρ` **逐图不可辨识**（对 `I` 做任意常数分解都保持 `I` 不变）。
   ⇒ `ρ̂` 只能是**先验条件期望** `E[ρ|I]`，**不是"衰减估计"**。claim 必须按此写。
2. **推论 6**：若训练时恒取 `ρ_tgt = ρ_sample`（称 R1），则 `L_ρ` **与 L1 的全局分量同向、不携带新信息**；
   而若 `ρ̂ ≠ ρ_sample`，两者**互相拉扯**。

⇒ **`ρ` 必须从"被估计的量"改成"控制变量"**：

```
训练：ρ_tgt ~ U[ρ0−Δ, ρ0+Δ]   （R2，counterfactual，与 I 独立采样）
      T' = T · (ρ_tgt · μ(I) / μ(T))      ← 用已知物理操作造目标，结构不变
推理：ρ_tgt ← ρ̂(I)
```

**只有 `ρ_tgt ≠ ρ0` 时，条件才携带"图像之外"的信息**——这是 PGC 与 AirNet/PromptIR/RDNet-code
（条件都是 `I` 的函数）的**数学分界**。

> **附带好消息**：E2 的剂量集 `real_pairs_1020_apr_dark{08,11,14}` 是"同一 `I`、不同 `ρ_tgt`"，
> 在**估计**范式下是陷阱，在**受控**范式下恰是所需监督（推论 4）。数据没错，是问题提法变了。

## 1. 病因 → 解，一一对应（方法 = 三个已量化病因各配一个最小解）

| # | 已量化的病因 | 数字 | 对应组件 |
|---|---|---|---|
| 1 | 域效应远超任何损失项；主因是**整体亮度偏置** | 域效应 **+2.003 dB**（12/12 场景，校正后 CI [+1.141,+2.865]）；apr 亏空 **68%** 是纯加性偏亮（事后色调上界 +1.325） | **C1 ρ̂ 头** |
| 2 | **净暗化分布**决定域性能；补对能回收 | E2 `dark14` = **+1.267 dB**（3 种子，12/12，校正后 CI [+0.843,+1.692]），自 2.05% 补到 14.35% | **C2 全局光度一致性损失（R2 下才有信息）** |
| 3 | 模型**没有恒等分支**："改 1.3% 像素却砍 43% 梯度"；近零反射帧 **−3.9 ~ −7.9 dB** | 见 `docs/2026.9.17_定位重审_动机与第一性原理.md` §2 | **C3 恒等门（降级为经验项）** |

## 2. 三个组件（全部增量，不动任何既有 state_dict key）

### C1 ρ̂ 头（< 0.2 M）

- 输入 `I` → 轻量卷积 + 全局池化 → 标量 `ρ̂ ∈ (0,1]`
- **标签零成本**：`ρ = mean_luma(T) / mean_luma(I)`，**每一对都能算**（不需要任何人工标注、不需要合成）
- **受控剂量天然可用**：`data/train_sets/real_pairs_1020_apr_dark{08,11,14}` 与原始池是**同一批 126 对、4 个 ρ 值** → 可直接做留档检验（见预登记 P4）

### C2 全局光度一致性损失

```
L_ρ = | mean(T̂) − ρ̂ · mean(I) |
```

- 只约束**全局均值**，与既有逐像素/感知项**正交**，不抢它们的活
- 为什么必须显式加：E2 已经证明"训练目标的 ρ 错了，输出就系统性偏亮"，而**隐式 loss 学不出这个量**（Zheng 的 e 实测斜率 ≈0.086，等于没学到）
- 施加在最后一列输出（`w_c` 最大的那一列）即可，避免 4 列重复计

### C3 恒等门（可选经验项，**不是构造性保证**）

> ⚠️ **本节已被数学评审修正**（见 `2026.10.25_PGC形式化与数学评审.md` §6 错 1 与"附"）：
> ① 原式 `σ(w(ρ̂−1))` 在 `ρ̂=1` 处等于 **0.5 而不是 0**，是硬 bug；
> ② 更根本地，"`ρ≈1` 就该不动手"这个推理**不成立**——`ρ=1` 同时对应"无反射"与"正负抵消的反射"，
> 而由命题 2，单帧分不开这两者。故 C3 **不能声称免伤保证**，只能作经验性保守项。

```python
# 修正后的门：ρ_tgt = 1 时严格为 0（用指数门或带偏置 sigmoid）
gate = 1 - torch.exp(-kappa * torch.relu(1 - rho_tgt))        # kappa=3 → gate(0.67)=0.63, gate(1)=0
T_hat_final = gate * T_hat + (1 - gate) * I
```

- **注入点选 Mona**（对齐 `scripts/rdnet_peft.py` 的硬约束）：
  ```
  x = x + gate · mona(x, (H, W))       # mona 是 token 级加法，gamma 初始化 1e-6
  ```
  只引入 1 个标量参数，`add_module` 语义不变，**不改、不重命名任何既有 key**（否则 `rdnet.pth` 的 `baseball.*` 会静默加载失败）
- **P3（免伤）相应降级**：从"由构造保证的性质"变为"待实测的指标"，且必须报 gate 分布

## 3. 为什么这不是"加模块"（与竞品划界）

| | 条件是什么 | 有物理标签 | 有功能验收 | 面向衰减 |
|---|---|---|---|---|
| AirNet | 对比学习退化表征 | ❌ | ❌ | ❌ |
| PromptIR | 隐式 prompt | ❌ | ❌ | ❌ |
| **RDNet（我们的 baseline）** | 冻结 ConvNeXt 6 维 code | ❌ | ❌ | ❌ |
| Diff-SemiER | 软掩码（合成透射率） | ✅（合成） | 部分（掩码消融） | 半透明遮挡 |
| Zheng'21 | 吸收标量 e | ✅ | ❌（实测失效：斜率 0.086） | 反射端 |
| **PGC（本设计）** | **ρ（净光度比）** | ✅ **真实配对可算** | ✅ **增益扫描 + 腐蚀测试** | ✅ **I 侧** |

> 六篇里**没有一行**同时做到"条件有物理标签 + 有条件的功能性验收"（见对照文档 §2.1）。

## 4. 明确不做（已证伪，不要回头）

| 不做 | 证据 |
|---|---|
| 空间 α / τ 场、逐像素掩码定位 | M1 封线：直连上界 **0.494**、跨域 ≈ 瞎猜 **0.143** |
| 逐像素免伤门控 | 4 条线全 FAIL；病是**全图低通收缩**，空间门控结构上修不了 |
| 损失叠罗汉（梯度/拉普拉斯/高频/梯度余弦） | 全为负结果；唯一承重是 Ω 双向项 |
| 强衰减（α≪1）作为主 claim | **τ 在配对协议中是"可约去的冗余参数"**（对照文档 §0.2）：<br>数据既不监督它、任务也不需要它（用户要的是 $T_{\text{obs}}$，不是 $T_{\text{obs}}/\tau$）；<br>且**没有需求侧支持**。注意：这**不是**"不可辨识之墙"，是"设问不成立" |

## 5. 失败模式（写死，便于审稿人反驳我）

| 风险 | 判据 | 处置 |
|---|---|---|
| **ρ 单帧不可辨识** | 零 GPU 探针：用现有 300+331 对回归 `I → ρ`，**R² < 0.30** | **不启动方法线**。结论改为"条件退化需要外部先验"，仍是可写的诊断结论 |
| ρ̂ 学到**场景捷径**（按场景而非亮度） | 4 档剂量跨档检验：同一批对的 `ρ̂` 是否随档单调变化 | 失败则说明 ρ̂ 记住了域，方法降级为"域条件化" |
| ρ̂ 与既有 6 维 code **冗余** | 三臂消融：只用 code / 只用 ρ̂ / code+ρ̂ | 若无增量，说明 RDNet 的 code 已含该信息 → 方法是负结果 |
| 恒等门退化成常数 | 报 gate 分布；若方差 ≈0 即无效 | 删门，只保留 C1+C2 |
| **条件即使不准也有用**（Diff-SemiER 的反直觉发现） | 腐蚀测试：ρ̂ ±0.10，性能平稳退化 → 加分；剧烈崩 → 说明押错在"准"上 | 若腐蚀即崩，改设计为鲁棒融合（学 Diff-SemiER 的 SMAF 思路） |
| 与 Zheng'21 撞车 | 已有区分：他反射端+额外输入通道+无一致性+无验收；我们透射端 ρ+一致性+验收 | 写作时按对照文档 §3 的划界句 |

## 6. 与既有实验的关系（不算新账）

- **E2 是本文方法的"数据侧预演"**：E2 用**改训练集 ρ** 证明了这个量的因果重要性（**+1.267 dB**，3 种子）；PGC 把它变成**模型内部可接收、可验收**的条件。二者互补，E2 可作为方法动机的实测支撑。
- **域消融是"域效应有多大"的证据**（+2.003），PGC 回答"域效应里那块可操作的部分（ρ）能不能在模型里被抓住"。
- **M1 / 门控线是"为什么不做空间量"的证据**，直接进 limitation 与 design rationale。

## 6.5 部署：ρ_tgt 从哪来（这是方法能否落地的关键）

> ⚠️ 本节为 2026-10-25 修正版。初版写"读产品 VLT → 得 τ → 得 ρ"，**绕了一道且不准**；
> 由 $\rho=1/(1+r/\tau)$，τ 不能单独决定 ρ。正确做法是**直接标定 ρ**。

### 误差的可分解性（决定了部署该做什么）

由实测（域间差 ≈0.11 灰阶→13；域内 std 0.018–0.075 灰阶→2.1–8.8）：

$$\text{总误差}\;=\;\underbrace{(\rho_A-\rho_B)\mu(I)}_{\approx13\ \text{灰阶 · 标定可消除}}\;+\;\underbrace{\sigma_\rho\,\mu(I)}_{\text{2–9 灰阶 · 单帧不可消除（命题 2）}}$$

$$\Longrightarrow\ \textbf{部署的正确形态 = 一次性标定 }\rho_tgt\textbf{，它消掉前一项的全部。}$$

### 四种 ρ_tgt 来源（按精度排序）

| 来源 | 做法 | 适用 | 精度 |
|---|---|---|---|
| **① 一次性标定（推荐）** | 固定安装后，隔玻璃拍一张灰卡/白墙，与不隔玻璃参考比 → 直接得 ρ_tgt。**存一次、长期复用** | 监控、行车记录仪、固定机位 | **最高**（实测） |
| **② 产品规格（VLT）** | 车窗膜/建筑膜必须标 VLT；一阶 ρ_tgt≈1/VLT，再用 ① 修正 | 汽车、建筑（法规要求标注） | 中（离散档） |
| **③ 外观先验 ρ̂** | 网络从图像学"这种场景通常多暗" | 膜未知、无法标定 | 低，**且只在本域可靠** |
| **④ 用户滑杆** | 手动给（类似曝光补偿） | 专业/消费 | 用户主观 |

### 部署流程

```
安装时：  ① 标定 或 ② 读规格   →  ρ_tgt（存一次，长期复用）
运行中：  T̂ = f(I, ρ_tgt)       →  每帧只多一个标量输入，推理成本不变
换膜/换镜头 → 重标定一次
```

### 部署侧必须写进 limitation 的

| 不解决 | 原因 |
|---|---|
| 反射的**局部结构**没去掉 | 另一根轴（结构/细节） |
| 膜**空间渐变**（贴歪、边缘黑边） | 全局标量不够；空间场又被 M1 封线（0.494） |
| 夜间低光 + 噪点 | 另一根轴（lowlight 方向） |
| 强反射下 `ρ≈1/VLT` 一阶近似偏 | 需 ① 标定兜住 |
| **域内 2–9 灰阶散布** | 命题 2 的**不可约误差**，不是实现问题 |

## 7. 一句话给评委

> 我们不去估计**算不出来的**（τ 空间场、人影位置、逐图 ρ），只把**可标定的**（净光度 ρ）变成输入条件，
> 并要求模型对它**可被干预式检验**——因为一个无法被检验的条件，和没有条件是一样的。
