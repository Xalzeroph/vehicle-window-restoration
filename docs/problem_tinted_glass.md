# 深色贴膜玻璃透射成像增强 —— 问题定义与研究纲领

## 背景：这是什么问题？

当前 SIRR 社区关注的场景包括：商铺橱窗、室内玻璃隔断、眼镜镜片、手机屏幕等。这些场景的共同假设是 **透射层足够强**，反射只是浅层叠加。但对于**贴了深色膜的玻璃**（深色膜透光率可低至 5%），物理条件完全不同：

- 透射率 α 极低（深色膜 α < 0.3，甚至 α < 0.1）
- 反射 R 以人形/环境光等高亮结构化内容为主
- 透射层细节被**双重衰减**：**贴膜吸收 + 反射淹没**
- 透射侧本身可能处于低照度

物理上这不是一个单纯的反射去除，而是一个 **耦合的去反射 + 低光增强** 问题：

```
I = αT + βR      (α << 1, 且 α 空间变化)
```

贴膜玻璃广泛存在于：
- 车窗/出租车防护隔板
- 安检玻璃
- 商店贴膜橱窗
- 墨镜/头盔面罩
- 建筑贴膜玻璃幕墙

透射层（你要拍的东西）和反射层（干扰内容）可以是任何场景、任何物体——问题不绑定于特定环境，核心技术挑战来自 **介质本身的透射衰减特性**。

---

## 物理模型

### 透射-反射模型
```
I(x) = α(x) · T(x) + β(x) · R(x) + ε(x)
```
- I: 输入图像（透过贴膜玻璃拍摄）
- T: 透射层（玻璃后的目标场景）
- R: 反射层（玻璃前方的环境反射）
- α(x): **空间变化的透射率**（贴膜的不均匀衰减，0.05~0.5）
- β(x): 反射强度系数（通常 0.4~0.9）
- ε(x): 噪声项（低光条件下的传感器噪声放大）

### 与标准 SIRR 模型的差异
```
标准模型:    I = T + R
退化模型:    I = αT + βR - T∘R   (DSRNet)
贴膜玻璃:    I = α(x)T + β(x)R + ε   (α << 1, 空间变化)
```

关键区别：
1. **α 是空间变化的** —— 贴膜有磨损/划痕/气泡/不均匀敷贴，每个像素的衰减不同
2. **α << 1** —— 透射信号能量极弱，T 和 R 的能量比严重倒挂
3. **低光耦合** —— 透射侧光照不足时，R 在能量上主导了 I
4. **T 和 R 的内容无约束** —— 可以是任意物体、任意场景，没有语义先验

## 问题难点（区别于通用 SIRR）

### 难点 1：能量比大范围动态变化
通用 SIRR：T 约占 I 的 60-80%，R 占 20-40%
贴膜玻璃：T 约占 I 的 10-70%，R 占 30-90%

→ 问题比"总是从强噪声中恢复微弱信号"更复杂——网络需要在**能量比极端多变**的条件下自适应。同一张贴膜，透射侧光照充足时 T 可占 70%，转入暗光环境后 T 被压缩到 10% 以下，两种情况的处理难度完全不同。

### 难点 2：透射率 α 空间不可知
- 贴膜工艺导致 α 在不同区域不同（边缘 vs 中心、划痕处 vs 完好区域）
- 长期使用产生划痕、磨损、气泡 → α 的空间分布进一步复杂化
- 需要从单张输入中估计 α(x) 的空间分布

### 难点 3：透射层自身可能处于低照度
- 透过贴膜玻璃拍摄时，透射侧可能是暗光环境（车内、室内、阴天）
- 即使完美去除反射，透射图像 T 仍然是暗光/欠曝的
- 需要联合的去反射 + 增强策略

### 难点 4：语义无约束
- 反射层和透射层的内容完全不可预知
- 可能是反射层是"人"、透射层也是"人"（语义歧义）
- 可能是反射层是"建筑"、透射层是"风景"（无规律）
- 不能依赖特定内容的语义先验来引导解耦
- 必须利用**边缘模糊度/色彩饱和度/景深/双反射**等物理线索

## 研究路线图

### Phase 1：理解当前 SIRR 的理论极限（已完成）
- ✅ RDNet [CVPR 2025] — 可逆解耦 + TAPG，验证了在贴膜玻璃场景的基本鲁棒性
- ✅ NTIRE 2026 Challenge — 11 种方法的对比，验证了 RDNet 系架构的主导地位
- ✅ 验证了现有方法在 α 极低时的失效边界

### Phase 2：低光 + 反射去除的联合建模

**核心假设：** 低光增强方法（如 Zero-DCE, RetinexNet）的 illumination estimation 和 TAPG 的 α 估计共享底层表征——两者都在做"从衰减信号中恢复原始信号"。

**调研方向：**
- Retinex-based 方法用于带衰减介质的成像恢复
- Illumination-aware SIRR 架构
- 低光 + 去退化（去雾/去雨/去反射）的联合模型

### Phase 3：空间变化透射率估计

**核心假设：** α(x) 的空间变化可以通过隐式学习或显式参数预测来捕捉。

**调研方向：**
- 空间自适应归一化/调制 (SPADE, AdaIN)
- Pixel-wise parameter prediction
- 可微物理模型（将 α(x) 作为可学习参数图）

### Phase 4：贴膜玻璃场景专用数据集构建

**必要性：** 现有数据集均不覆盖 α << 1 且空间变化的情况。

**方案（思路）：**
- 透过不同透光率贴膜（5%/15%/30%/50%）拍摄各类物体/场景
- 双帧采集：移除膜（GT） vs 透过膜拍摄
- 覆盖多种光照条件（明亮/阴天/黄昏/夜间）
- 包含不同使用程度贴膜（新膜、磨损膜、带划痕膜）

### Phase 5：耦合的去反射 + 增强端到端框架

**最终目标：**
- 同时输出：去反射透射图 T + 增强后 T_enhanced
- 或直接输出到达视觉可用的增强透射图

## 实验评估指标

### 定量指标
| 指标 | 优先级 | 说明 |
|------|--------|------|
| PSNR (T) | ★★★ | 透射层重建精度 |
| SSIM (T) | ★★★ | 结构保真度 |
| LPIPS | ★★★ | 感知质量 |
| NIQE | ★★ | 无参考质量（真实场景无 GT 时） |
| ΔE (color) | ★★★ | 颜色保真度（衰减介质首要关注） |
| Low-light metrics | ★★ | 低光增强质量 |

### 定性指标
| 指标 | 说明 |
|------|------|
| 反射残留等级 (1-5) | 人眼评估 |
| 透射细节保留度 (1-5) | 能否看清透过玻璃的物体/文字 |
| 颜色偏移程度 (1-5) | 校正后是否偏色 |
| 噪声放大程度 (1-5) | 增强过程是否放大了 sensor 噪声 |
