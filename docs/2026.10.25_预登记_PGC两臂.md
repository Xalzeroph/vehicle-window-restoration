## 0. 先修一个设计陷阱（写在这里以防自己犯）

**剂量集不能当可辨识性测试集。** `real_pairs_1020_apr_dark{08,11,14}` 与原始池是**同一批 126 对**，`I` 完全相同、只有 `T` 被平移 ⇒ ρ 变了而 `I` 不变。

> **这恰恰证明：ρ 不由 `I` 唯一决定**（否则 E2 造不出 4 个不同的 ρ 而 I 不变）。

因此：
- **不能**用剂量集检验"ρ 能不能从 I 估出来"（那是自欺）；
- 剂量集的正确用途是**验证 ρ̂ 的域级先验是否被正确排序**（档间对比，P4b）；
- 真正的可辨识性探针必须在**不同 I** 上做（§1 P0）。

这条如果不写下来，后面一定会有人（包括我自己）拿剂量集算出个好看的 R² 然后误判。

## 1. P0：零 GPU 可辨识性探针（**方法的总闸门**）

**问题**：给定单帧 `I`，能否预测该对的 `ρ = mean_luma(T)/mean_luma(I)`？

**数据**：`real_pairs_1020`（300 对 / 13 场景）+ `real_pairs_1019split`（331 对 / 3 场景）。
标签 ρ 由 `I, T` 实算，零成本。

**三个基线**（必须**同时**报，缺一不可）：

| 基线 | 说明 |
|---|---|
| B_const | 全体均值常数 |
| **B_domain** | **域内均值常数**（按 apr/may/jun/1019 分域）← **真正要打的对象** |
| B_scene | 场景内均值（上界参考，训练时不可用） |

**判据**

- **P0-A（必要）**：`ρ̂` 的留域（leave-one-domain-out）MAE 必须 **< B_domain 的 MAE**，且 95% CI 不含 0。
- **P0-B（决定方法形态）**：若 `ρ̂` 只能到 B_domain 水平（打不过），则**方法的 claim 必须降级**为"域级 ρ 先验条件化"，**不得**写成"从单帧估计衰减"。
- **P0-C（kill switch）**：若 `ρ̂` 连 B_const 都打不过 → **整个方法线不启动**，转诊断结论。

**成本**：0 GPU（特征可用现成 ConvNeXt code + 简单图像统计），约半天。

> **顺序铁律**：P0 不过，不烧任何训练。

## 2. P1–P4：训练后判据

### P1 有效性

- 对比：`A`（现 baseline，RDNet+Mona 6000 iter / bs6 / lr1e-4 / 30:40:30 / `--lam-grad 5 --lam-lap 2 --legacy-fidelity`）vs `B`（A + C1+C2+C3）
- 数据：训练 `real_pairs_1020`（300 对 / 13 场景）；测试 `real_pair_1019_testsplit12`（12 场景）
- 统计：沿用 `scripts/agg_dom_v1.py` 口径（种子均值 → 12 场景配对 t → Bonferroni）
- **判据**：校正后 CI 下限 > 0
- **功效**：`R-apr` 种子 std **0.578 dB** ⇒ 3 vs 3 种子 MDE ≈ **1.31 dB**。
  ⟹ **P1 只可能被 ≥1.3 dB 的效应通过**；目标是修复"占 68% 的主因"，量级与 E2 的 **+1.418 dB** 同阶，**不是** 0.2 dB 级微调。
- **因此 P1 用 3 种子**（否则测不出也不许解释为"无效"）。

### P2 功能性验收（本文核心贡献，**与 P1 独立**）

**目的**：证明"条件真的跟随退化"，这是全表六篇都没做的一环。

- **P2a 增益扫描**：对 `I` 施加 `g ∈ {1.00,0.95,0.90,0.86,0.80,0.75,0.70,0.67,0.60}`，测 `ρ̂` 的斜率。
  - **判据**：斜率 **≥ 0.50**
  - 参照：`Zheng'21` 实测 **0.086**（他自己域）/ **0.089**（我们域）；baseline 的隐式 code **预期 ≈0（须实测确认）**
- **P2b 条件腐蚀**：把 `ρ̂` 人为偏移 ±0.10 再送入模型。
  - **判据**：ΔPSNR 的下降 ≤ **0.5 dB**（平稳退化）
  - 依据：Diff-SemiER 的实测教训——条件不准也能靠融合救回；若我们一腐蚀就崩，说明押错在"准"上
- **P2 的独立性**：即使 P1 不过，**P2 单独成立也是可发表的方法学结论**（"条件必须被验收，否则和没有条件一样"）。这一条先写死，防止事后被当成借口。

### P3 免伤

- 在 ρ≈1 的近零反射子集（按 ρ 分位数取最低档）上：`ΔPSNR(B − A) ≥ 0`
- 同时报 C3 的 gate 分布；**gate 方差 ≈0 视为 C3 无效**

### P4 硬件梯子（已知 τ 的真值检验）

- 数据：`D:\c_course\reflection removal\code\CarWindowsDataset1105.zip`（同场景 无玻璃 / 车窗 τ≈0.99 / 投影膜 τ≈0.67）
- **P4a**：三档的 `ρ̂` 必须**单调跟随**档位（无玻璃 > 车窗 > 投影膜），Spearman = 1 或 2/3 一致
- **P4b**（剂量档间）：4 档剂量的 `ρ̂` 必须**单调跟随档位**（同一 I 下只能说"域级先验排序"，不作为可辨识性证据，见 §0）
- **若 P4a 出现饱和（例如预测膜档但 ρ̂ 卡在 0.95）** → 报告饱和点，这本身即"可辨识性界"，与 Zheng 的 0.7 地板形成对照

## 3. 臂与成本

| 阶段 | 内容 | 成本 | 门 |
|---|---|---|---|
| **S0** | P0 探针（纯 CPU） | 0 GPU，~0.5 天 | 不过 → 全线停 |
| **S1** | 单种子探索：A vs B（各 3.3 h） | 2 × 3.3 h ≈ **7 GPU·h** | 只看 P2（便宜、快）与曲线是否健康 |
| **S2** | 补到 3 种子（A/B 各再 2 个） | 4 × 3.3 h ≈ **13 GPU·h** | P1 判定 |
