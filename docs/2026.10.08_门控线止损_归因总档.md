## 1. 这条线原本要解决什么

- **P1 单一力度**：算子对全图同一力度 → 收益集中在强反射、代价压在干净区；
- **P2 跨域崩塌**：微调后外观门控锁死训练域，跨域比官方更伤；
- **假设**：模型不缺修复能力，缺的是「**该不该动手、动多强**」的判断。
- **拟解法**：`O = I + g ⊙ (P − I)`，只学门控图 g（P 冻结），监督用闭式 g\*（把真值投影到 I→P 线段）。

## 3. 机制归因：为什么「力度调节」不是瓶颈

1. **信息的可观测性**：单张图上没有「域」这个观测。域影响的是全局统计（曝光、色温、噪声、反射强度分布），而这些统计与图像内容混淆（「图暗」可能是环境暗，也可能是物体本黑）。
2. **不是表达力问题**：门控约 8.7 万参数、逐像素 25 万输出自由度，「输出常数 α」完全在其能力范围内；它**确实收敛到近常数解**，只是**档位选错**。→ **信息不足，非表达不足。**
3. **域外最优策略是「不要应用该模型」**：α\* ≈ 0.1。这说明需要的是**域判别 / 拒答**，不是逐像素力度调节。
4. **逐图调 α 的天花板本就很低**：每图 oracle α 仅比最佳全局 α 高 **0.6–0.7 dB**。
5. **关系式**：`α* = f(域)` —— 要把力度选对，必须先知道域（或等价信息），这就是死结。

## 5. 本线的净产出（仍成立，可写进论文）

1. **harm-rate 指标**：即使同分布，**2–18% 的图被弄更差**（LPIPS 2–10%）；跨域 wild55 达 18%。现有 SIRR 论文从不报此数。
2. **色调混杂的量化 + 归一化评测协议**：一条 **2 参数全局色调曲线**即打败官方 RDNet（比其原始输出高 **+2.0 ~ +2.7 dB**）。→ 车窗数据上任何 PSNR 类结论**必须光度归一化**，且**必带平凡基线（affine + 标量）**；否则会制造假 PASS（轮 1 即为实例）。
3. **跨域失灵的机制证据链**：越 OOD 越伤 —— postcard199 2% < objects200 6% < real20/nature20 15% < wild55 18% < 车窗干净区 72% 块为负；A0 在公共基准上复现同一梯度。
4. **边界论证**：逐图 oracle α 仅比最佳全局 α 高 0.6–0.7 dB，且域外 α\*≈0.1 → 「调力度」这条路天花板本就很低。
5. **纪律资产**：预登记 + 平凡基线 + 归因自查，三轮共 **≈3 GPU·h** 否掉三条候选机制。
