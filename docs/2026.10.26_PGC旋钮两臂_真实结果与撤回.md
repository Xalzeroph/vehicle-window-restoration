# 2026.10.26 PGC 旋钮两臂：真实结果（并撤回上一条假阳性）

> **⚠️ 撤回声明**：本实验**第一次运行**（eval 时忘了 `net.eval()`，网络停在 train 模式、BN 统计在更新）
> 得到 `ControlGain = 2.861`、三项目全 PASS、"METHOD WORKS"。
> **该结果作废。** 修正后（`net.eval()`）结果为 **CG = 0.244，P1 FAIL**。
>
> 两次结果差 12 倍，原因是测量错误，不是模型变化。**记档以防再被引用。**

---

## 1. 设置

| 项 | 内容 |
|---|---|
| 骨干 | 官方 RDNet（只冻 `baseball.*`，Mona 可训 —— 与 `finetune_rdnet_s2.py` 完全一致） |
| 条件注入 | `ScalarFiLM`：`code' = code·(1+γ(s)) + β(s)`，**250 个参数**，零初始化（起步恒等） |
| 数据 | `real_pairs_1020`，128²，11 场景训练 / **2 场景（jun）验证** |
| 训练 | 900 iters，bs 8，Adam lr 5e-5，梯度裁剪 1.0，AMP |
| **A 臂（反事实）** | 每 iter 采 `u ~ U[0.85,1.15]`，`s = u·ρ_true`，目标 `T' = u·T` |
| **B 臂（固定）** | `u ≡ 1`（普通训练，没有反事实） |
| 干预测试 | 推理时扫 `u ∈ {0.85…1.10}`，测输出均值 |
| 判据 | `ControlGain = (dμ(T̂)/ds)/μ(I)`；**P1 A ≥ 0.50**，**P2 B ≤ 0.20** |

（推导：`s = u·ρ_true` 且 `ρ_true = μ(T)/μ(I)` ⟹ `T' = T·(s·μ(I)/μ(T)) = u·T`，所以反事实目标就是"按 u 缩放 GT"。）

---

## 2. 结果（修正后，`net.eval()` 已开）

验证集：`μ(I)=0.3395  μ(T)=0.3120  ρ̄=0.9204`。理想响应 `dμ/du = μ(T) = 0.312`（对应 CG = 1.0）。

### A 臂（反事实）

| u | μ(T̂) | PSNR |
|---|---|---|
| 0.85 | 0.2657 | 26.243 |
| 0.90 | 0.2687 | 26.738 |
| 0.95 | 0.2719 | 27.309 |
| **1.00** | **0.2758** | **28.014** |
| 1.05 | 0.2801 | 28.835 |
| 1.10 | 0.2848 | 29.767 |

- `dμ/du = 0.0763`（理想 0.312）→ **ControlGain = 0.244**
- 冻结 RDNet（无 FiLM）：`μ=0.2689  PSNR=26.738 dB`

### B 臂（固定 u≡1）

| u | μ(T̂) | PSNR |
|---|---|---|
| 0.85 | 0.3137 | 32.810 |
| **1.00** | **0.3148** | **32.634** |
| 1.10 | 0.3152 | 32.556 |

- `dμ/du = 0.0062` → **ControlGain = 0.020**
- 冻结 RDNet：`μ=0.3133  PSNR=32.805 dB`
- **⟹ B 臂 ≈ 冻结模型**（PSNR 32.63 vs 32.81），Mona 几乎没动

### 判决

| 门 | 结果 |
|---|---|
| **P1** A 臂服从旋钮（CG ≥ 0.50） | ❌ **FAIL**（0.244） |
| **P2** B 臂不服从（CG ≤ 0.20） | ✅ **PASS**（0.020） |
| **P1/P2 对比度** | **12.4×**（0.244 / 0.020） |
| **P3** u=1 不伤（≥ 冻结 −0.5 dB） | ❌ **FAIL**（28.014 vs 26.738 冻结；但 B 臂 32.63 远高于 A） |

## 3. 三条可用的读数

### 读数一：**冻结的 RDNet 完全不服从任何光度标量**

B 臂 ≈ 冻结模型，`CG = 0.020`。即：**预训练 RDNet 对"你告诉它该多亮"这件事毫无反应。**

**这是论文可以直接写的一条**（对应 `2026.10.25` 推论 6：条件是 I 的函数时不携带额外信息）。
而且它是**测出来的**，不是推出来的。

### 读数二：**反事实训练确实能造出旋钮，但很弱**

`u` 从 0.85 拉到 1.10，A 臂输出单调上升（0.2657→0.2848），B 臂纹丝不动。
**12.4× 的对比说明"反事实采样"是产生可控性的必要条件** —— 但只有 0.244，**不到门槛的一半**。

### 读数三：**可控性目前是用精度换来的**

| 臂 | u=1 时 PSNR |
|---|---|
| 冻结 RDNet | 32.805 |
| **B（固定）** | **32.634**（几乎不损） |
| **A（反事实）** | **28.014**（**−4.8 dB**） |

**A 臂为"能拧"付出了 4.8 dB。** 而且 A 的输出系统性偏暗（0.276 vs 目标 0.312），
且 **PSNR 随 u 一直升到 1.10**（29.77）——说明"A 臂希望比真值更亮"，即**它没学准水平，只学了"跟着 u 动"**。

## 4. 结论：方向活着，但这一版不够

| 判断 | 结论 |
|---|---|
| 旋钮能被造出来吗 | **能**（12.4× 对比，12 倍于对照） |
| 现在达标吗 | **不达标**（0.244 < 0.50） |
| 代价可接受吗 | **不可**（−4.8 dB） |
| 能不能写进论文 | **只能写"可行性 + 失败模式"，不能写"我们的方法"** |

**最诚实的一句话**：这一版证明了"**可控性可以被训练出来，而不是免费的**"——
它换来了 4.8 dB 的精度损失，且只达到目标强度的 24%。

## 5. 下一步（如果还要走这条路）

| # | 改动 | 理由 |
|---|---|---|
| 1 | **加显式准则损失** `L_ρ = \|μ(T̂) − s·μ(I)\|`，而不是只靠"目标缩放" | 现在模型只学到"跟着动"，没学到"动到位"；准则损失直接管水平 |
| 2 | **缩小 u 范围**（如 ±0.08） | 现在 u∈[0.85,1.15] 相对 ρ̄=0.92 意味着目标亮度差 ±15%，但模型的输出动态范围不够 |
| 3 | **加大训练预算**（900 → 5k iters）、或用更多种子 | 900 iters 下 Mona 几乎没动（B 臂），A 臂可能是"被扭曲但没学会" |
| 4 | **先修曝光失配再谈旋钮** | A 臂系统性偏暗 0.276 vs 0.312，与 `2026.10.08` 的 I↔GT 增益 0.78 同源 |
| 5 | **验证集扩到 5+ 场景** | 现在 2 场景，PSNR 差异的置信度很低 |

**我的建议**：先做 #1 + #2（半天），因为它们是"让旋钮动到位"的直接修法；
#3/#5 是功效问题；#4 是数据问题，优先级最高但不在这个方法里。
