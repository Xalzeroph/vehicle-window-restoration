> 本轮问题：**S1 域适配微调是否过 G-R1 提升门？w(α) 损失组件是否过 G-R2 方法门？**
> 预登记门见 `2026.9.15_分离器域适配实施方案_opus.md` §4/§10（跑前已定，未改口）。

## 3. 判决（预登记门）

| 门 | 判定 | 依据 |
|---|---|---|
| **G-R1**（freeze 主臂，raw，2-seed 均值） | **FAIL** | α=1.0 档 18.72 < 19.42（缺口 −0.70；两 seed 单臂 19.04/18.39 均不过）；0.6 档 17.97 vs 17.87 **贴线 +0.10**（噪声内）；0.3 档 18.54 ≥ 17.5 过  |
| G-R1（plain 对照臂，非登记二次应用） | PASS（**secondary**，标注） | 19.66/19.73/18.48 全过；但 α=1.0 余量 +0.23 < seed 极差 0.49，单 seed plain_s101（19.41）不过 → 不单独作强证据 |
| **G-R2**（w 组件，freeze − plain，raw，配对 n=24） | **FAIL** | α=0.3 仅 +0.07（95%CI [−0.64,+0.78]，**不可分辨**而非"确为零"）< +0.3；α=1.0 −0.94（CI [−1.34,−0.53]）、α=0.6 −1.75（CI [−2.43,−1.06]）→ never-worse 违例。"w 高档有害"稳健（两 seed 同向、raw/gm 同向）。gm 口径下 0.3 条款会翻（+0.43）→ 按**预登记 raw** 判 FAIL |
| G-R3（v2.2 scan，raw，ᾱ≤0.15 ≥ in_gm+3） | **FAIL（补判）** | α=0.1：freeze 15.76/16.29 = +3.52/+4.05 **过**，plain 13.88/14.25 不过，pilot/zeroshot 不过；α=0.05：最好 freeze 12.71/13.45 = +1.04/+1.78 **全败** → 合取 FAIL |

**v2.2 scan 曲线（raw）**：freeze/plain 在 α=0.3–0.75 稳定 20.2–21.6；pilot 同段 16.8–20.3（低档差 3~4 dB）；
α≤0.1 全体掉入 12–16 区（freeze 好于 plain +0.8~1.9）。in_gm 基线 11.67→21.08。

**⚠ 判决拼接约束**：G-R3 的 α=0.1 通过项**只属于 freeze（w 臂）**；主臂切 plain 即丢掉该项。
"弃 w 过 G-R1" 与 "留 w 过 G-R3(0.1)" 是**同一权衡的两端**，报告/论文中不得拼接。

## 4. 补充面板：常数基线与结构相关（本轮新增，已固化 `eval_rdt_extra.py`）

- **常数基线（GT 均值填充图）**：v2.1 = **17.68 dB / SSIM 0.742**（三档同值；indomain 14.48；v2.2 同 GT 同 17.68）。
  即 α=0.3 档 pilot（16.51）**低于平坦图**；四臂 18.27–18.68 仅超之 +0.6~1.0；四臂 SSIM(0.68–0.71) 反低于常数(0.742)
  ——低对比 GT（σ≈34/255）下 PSNR/SSIM 被"平坦图"占据，**单独引用低档 PSNR/SSIM 会误导**。
- **结构相关 corr（去均值，v2.1）**：α=0.3：zeroshot 0.259 → pilot 0.500 → 四臂 **0.615–0.632**（常数基线恒为 0）；
  α=0.6：0.468/0.571/0.626–0.687；α=1.0：0.644/0.684/0.677–0.736。
  → 低档增益是**真实结构恢复**（corr 翻倍余），非仅电平对齐；但绝对 PSNR 余量薄，论文低档结论应以
  corr/SSIM 相对 zeroshot 的形态呈现，并显式带常数基线行。
- 输入均值常数（非 oracle）：15.74/17.40/16.41（α=0.3/0.6/1.0）。

## 6. Opus 红队复核结论与已吸收修正（P4）

审核判定"数字与脚本算术全部复现正确"，提出 3 处翻车点，均已吸收：
1. **G-R3 漏判** → 已补判（§3 末行）并写入"判决拼接约束"。
2. **R̂ 归因撤回**：不采用"w 使 R̂ 变差"的说法——r_raw 差 0.3~0.5 但 r_gm 仅 ±0.07，属全局尺度伪影；
   本轮不对 G-R2 做 R̂ 侧因果归因。
3. **"两 seed 同向"修正**：v2.2 的 α=1.0 两 seed 反向（−0.62/+0.10），"w 在 α≥0.6 有害"仅 v2.1 全档、
   v2.2 的 0.6/0.75 档成立。
另吸收：plain PASS 标 secondary（§3）；+0.07 表述为"不可分辨"（§3）；v2.1 与 v2.2 scan **共用同 12 张 GT**
（md5 一致）→ 跨集合同向**不构成独立复现**；§4 原文 noA oracle（14.09@0.3）"上界"标签**错误**——本轮 18.5
已超其 +4.4 dB，引用时改称"完美去 R + 全局增益参照"。

## 7. 结论与下一步

**结论**：
1. 域适配本身成功且可复制：v2.1 α=0.3 档 12.05（零样本）→ 16.51（pilot）→ **18.3~18.7**（本轮，corr 0.26→0.62）；
   相对 pilot 逐 seed 为：0.3 档全面 **+1.75~+2.17**（配对 CI 不含 0）；0.6 档 plain +1.43~+1.88、freeze 持平
   （+0.02/−0.21）；1.0 档 plain 持平（+0.28/−0.21）、freeze 略低（−0.58/−1.23）。
2. **w(α)（锚点 0.6）作损失组件被否**：净效应高档有害、低档不可分辨；仅在 α≤0.2 的极端档位（v2.2 0.05–0.2）有
   +0.5~2.2 优势——按预登记弃用。
3. 主配置更新为 **plain**（官方参数化 + 普通 Charbonnier + 冻 backbone，30k iter）；G-R1 在其上为 secondary PASS。
4. 低档极限（α≤0.1）距"直接放大"仍有缺口（G-R3 FAIL），是 S3 的压力位。

**下一步（建议）**：
- S2 方法臂（软除法出口 `T̂=T̂0·(1−β+β/α̃)`）以 **plain 为基座**开轮；w 若复用，只作"低档专支"候选（S3 权衡表）。
- 把常数基线/结构相关纳入后续所有 rdt 评测默认面板（脚本已固化）。
- 实拍 sanity（S3）仍是泛化主证；v2.2 因共用 GT 不能承担该角色。
