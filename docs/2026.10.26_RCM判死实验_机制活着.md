# 2026.10.26 RCM 判死实验（K1/K2）：机制活着，但证据还不能写进论文

> **一句话**：**条件通路是真的被使用**（K1 PASS）——同一架构、同一预算下，
> 喂**有信息**的图时模型会消费它（shuffled override 引起 **5.20 灰阶**输出变化），
> 喂**无信息**的图时模型学会无视它（**0.49 灰阶**，10.7× 差距）。
>
> **但**：① 训练设置不稳（`nomap` 臂 −17.6 dB 发散）；② 预言机图的增益只有 **+0.376 dB**；
> ③ 验证集只有 2 个场景。**所以 K1 可信，K2 与"收益"不可信。**

---

## 1. 设计

| 项 | 内容 |
|---|---|
| 骨干 | 官方 RDNet **冻结**（Mona both，`rdnet.pth` missing 非mona=0） |
| 缓存 | 300 对 → 冻结输出 `T0`（128²，`outs[-1][:,3:]`），用时 95 s |
| 调模块 | `ModNet`：`[I, T0, m]` → 残差 → `T_hat = T0 + 残差`（末层零初始化，起点即 T0） |
| m | **预言机相对反射强度**：`|R| / mean(|R|)`（每图自归一化） |
| 训练 | 900 iters，bs 8，Adam 2e-3；**11 场景训练 / 2 场景验证**（jun 的两个场景） |
| 臂 | A 真 m ／ B **打乱 m**（每 iter 取他人样本）／ C 零通道（无图） |
| 干预 | 推理时**强制替换 m** 为 {0, 1, 噪声, 打乱}，测输出变化 |

**判据（跑前写死）**
- **K1 图被使用**：`max|Δμ| ≥ 1.0 灰阶` 或 `RMS ≥ 0.01`
- **K2 图有用**：`PSNR(A) − PSNR(B) ≥ 0.3 dB`

---

## 2. 结果

| 臂 | val PSNR | vs 冻结 T0 | override：zeros | ones | noise | **shuffled** |
|---|---|---|---|---|---|---|
| **A 真 m** | **30.676** | **+0.376** | 10.99 灰 | 13.33 灰 | 9.35 灰 | **5.20 灰** |
| **B 打乱 m** | 27.624 | −2.676 | 0.63 灰 | 0.57 灰 | 0.48 灰 | **0.49 灰** |
| C 零通道 | **12.690** | **−17.610** | 36.89 灰 | 27.47 灰 | 23.15 灰 | 19.44 灰 |

（冻结 RDNet 自身 val PSNR = **30.300 dB**）

### 2.1 K1：机制成立（这是可信的部分）

**最干净的对照不是 zeros/ones/noise，而是 `shuffled` override**——因为打乱只在样本间重排，
**保持分布不变**，不引入 OOD：

| 训练臂 | shuffled override 引起的输出变化 |
|---|---|
| **A（真 m）** | **5.201 灰阶**（RMS 0.043） |
| **B（打乱 m）** | **0.487 灰阶**（RMS 0.005） |
| **比值** | **10.7×** |

**判读**：给**有信息**的图，模型学成"读它"；给**无信息**的图，模型学成"无视它"。
**⟹ 条件通路不是装饰，架构愿意消费空间条件图。K1 PASS。**

### 2.2 K2：字面 PASS，但不该信

`PSNR(A) − PSNR(B) = +3.052 dB`，超过 0.3 门槛。**但这个数不可用**，原因见 §3。

---

## 3. 三个必须先修的坑（诚实清单）

### 坑 1：`nomap` 臂 −17.6 dB 发散 → 训练设置不稳

零通道臂从 30.3 掉到 **12.69 dB**，说明**训练本身在毁模型**（过拟合 11 个场景 / lr 偏大 / 无早停）。
**既然 C 臂能崩成 −17.6，A 臂的 +0.376 就不能当"方法的上限"讲。**

### 坑 2：预言机 m ≈ 答案本身

`m = |R|/mean(|R|)` 几乎就是"要去掉的那张图"。**把答案直接喂进去，只换来 +0.376 dB**
（且低于 12 场景配对检测下限 0.42 dB）——这是个**发人深省的数**：

> **即便把"哪里反射多强"近乎完美地告诉模型，小调制模块也只拿到 +0.38 dB。**
> **⟹ 瓶颈大概率不在"空间信息缺失"，而在别处（光度标定 / 结构 / 训练稳定性）。**

**这与既往全部负结果一致**（M1 定位不可行、4 条门控全败、级联 +0.37 但结构变差）。

### 坑 3：验证集 2 个场景

jun 两场景 44 帧。**K2 的统计功效几乎为零**，只能定性看。

## 4. 判决

| 问题 | 答案 | 可信度 |
|---|---|---|
| 条件通路会被使用吗？ | **会**（10.7× 对照差异） | **高** |
| 该架构能靠预言机图涨点吗？ | 仅 **+0.376 dB**，且低于检测下限 | 低（设置不稳 + 2 场景） |
| 换成"学习的图"会怎样？ | **未测**；预期 ≤0.376 再减去预测误差 | — |
| 这个方向能不能写进论文？ | **机制可以写；收益暂时不能写** | — |
