- **对标配方**：RDNet（CVPR2025）= 90 对 real（Zhang CVPR18）+ 200 对 Nature（IBCLN）+ VOC 合成 =
  **290 对真实（全权重）**；GFRRN（CVPR2026）用**同一套**。我们的微调只用了 **16 对**。

**方法侧（两轮实测）**
- 官方 RDNet/RemoVal 在 Ω 上全判据 **0/40**（不动/压暗假修复）；

- 归因：**数据可辨识性**（16 对单机位不足），非损失缺项。

**竞争**

- 我们的独家素材：洞/人影问题定义、Ω 定式、判据集①–⑤、低通对冲发现、评测协议。

### 3.2 架构线 M1/M2（掩码门控；唯一通向"方法正结果"）

**科学问题（精确化）**：S2 已证"人影任务训练域可学"（16/16、ρ_p25 0.77）——M1 **不问"能不能学"**，
而问 **"出域时丢的是定位还是修复"**（S2 端到端混学，二者分不开）。若证"定位可迁移、修复不可迁移"
→ 方法支点成立（可迁移部分固定、不可迁移部分限制在小区内赌）；若定位也不可迁移 → 结构线判死
（"数据可辨识性"归因被进一步坐实，负结果仍成立）。

**架构（M1 极简探针版）**
```
T̂ = I − m̂ ⊙ D
    D = 官方 decoder 残差（冻结白拿）；m̂ = 掩码头从官方特征预测（唯一可训）
```
- **参数划分**：冻结 **266.4M**（baseball 205.8M + subnet×4 56.8M + decoder 2.78M + adapter 1.06M
  + prompt 0.04M）+ cls_model 49.5M；**只训掩码头**（占比 ~0.07% → 纯架构可归因）；
- **逐位置取值**：m̂≈0（非人影）→ T̂=I **一个像素不动**（③⑤由构造满分）；m̂≈1（人影）→ T̂=I−D
  （放行官方修复，①④ 待测）；边界为软过渡（防硬边）；
- **末层 bias=−4**（初始 sigmoid≈0.02）+ **硬性自检**：训练第 0 步输出与输入差 <1/255；
- **对照矩阵**：identity / 官方 RDNet / **M1** /（消融）随机掩码 / perfect=T；
- **不插 Mona**（M1 是探针，越简越好；Mona 留给 M2）；
- **M2 演化**（M1 有信号后）：`T̂ = I − m̂ ⊙ D_new`，新增洞内小修支（2–3 层，输入 I⊕m̂⊕环带上下文）。
  注：M1 的 Δ 借官方残差（不新增修复能力）；最终形态可选"官方输出 + m̂⊙增量"接法（普通反射仍由官方处理）。

**容量阶梯（预登记，防"头太小"混淆）**

| 档 | 掩码头规模 | 成本 |
|---|---|---|
| 小 | ~0.2M | 2 GPU·h |
| 中 | ~1M | 2 GPU·h |
| 大 | ~5M | 2 GPU·h |

**诊断逻辑（先写死）**：① 三档**训练域 IoU 都高** + 跨场景都低 → **泛化问题**（结论成立）；
② 仅大档训练域高 → **容量问题**（升级主力重跑）；③ 全档训练域都低 → 任务/标签问题（回查掩码监督）。
**训练域 IoU 每个 ckpt 顺手评**（零成本，第一时间分清"学不学得会"与"迁不迁得动"）。

**大掩码头设计（5M 档）**：U-Net 风格多尺度解码器——
官方 FocalNet 四级特征（1/4~1/32）→ 1×1 投影统一 128ch → 逐级上采样+skip 拼接 + 2×Conv3×3（×3 级）
→ 拼高分辨率 skip(c0, 保边界精度) → 输出头（3×3→1×1）→ 1ch logit → 上采样 → **软掩码**。
- 每设计对应一个失败模式：多尺度=人影大小差异；高分辨率 skip=边界精度；软掩码=保守施工（不确定处温和）；
- 训练：BCE+Dice；**正负样本都喂**（无洞帧防误报）；随机裁 224–320 + 翻转；
- **备选（若容量救不了）**：加输入通道（高分辨率细节 / 低频亮度通道——人影的物理签名=大块亮度凹陷）
  ——"**加信息**"而非"加容量"。

**掩码训练数据**：正样本=apr Ω（365 帧提取后更丰富）+ **洞合成器**（标签精确免费，可无限造）；
负样本=无洞真实帧 / 合成挖洞（标签全零）。

### 3.3 下游诊断线（首轮已完成 2026-09-21；补测矩阵预登记待 M1 后）

**首轮结果**（产物 `scripts/probe_downstream_0921.py`、`eval/eval_downstream_0921*.csv`、
`fig/downstream_{ghost,person_evidence}_0921.jpg`）：
- Faster R-CNN（COCO）+ Keypoint R-CNN × apr 16 / may 14 / MyVideo 384 帧；
- **个案铁证**：人影被检出 person（0.56–0.77 分、4 帧 / 3 场景）、Keypoint 在暗人影上画出完整骨架，
  GT 同位置零检出（视觉核验通过，用户已看图）；
- **系统性不成立**：预登记门（≥2/3 场景 ∧ ≥1/3 帧）在 person-only 口径下 = 3/6 场景、25% 帧；
  may 全零；**措辞只能写"本检测器/本帧数下未测出"**；
- **方法点（可进协议节）**：检测器自身抖动占差异约 **8 成**（I-vs-I 相邻帧对照，同量纲比较）；
- 处置：降级为"个案 + 抖动地板方法点"；系统性阴性进 limitations；**不进 contribution 2 系统臂**。

**补测矩阵（预登记；M1 出结果后跑，~1 GPU·h）**——把"未测出"从单模型局限升级为跨模型族结论：

| 任务 | 模型（各 ≥2） | 指标 |
|---|---|---|
| 检测 | Faster R-CNN ✓ + YOLO/DETR | AP / ghost 率 |
| **分割** | Mask R-CNN / SegFormer | mIoU |
| 关键点 | Keypoint R-CNN ✓ | person 分 |

**纪律（防 p-hacking）**：全部模型 × 全部任务**一次测完、全部如实报告**（禁"换模型直到测出"）；
判定门沿用首轮（≥2/3 场景 ∧ ≥1/3 帧）；jun 锁死不动。

**判定句**："人影伤害下游任务，且现有 SIRR 方法修不掉"（后半句 **2026-09-22 更正口径**：官方在 Ω/弱反射区
为**过修**（−20 压暗、误差翻倍），非"不动"）。

**范式参照（FoCo, CVPR 2025；PDF `docs/papers/FoCo_CVPR2025_lowlight_downstream.pdf`）**：
- 三任务 × 低光专用集 × 固定下游模型 × 标准指标：分类（CODaN，ResNet18+EfficientNet，Acc）、
  人脸检测（DarkFace 1800 张，S3FD+DSFD，AP）、实例分割（LIS 2230 张，Mask R-CNN，mAP）；
- 关键设计：**Raw 基线（原图直通下游）** + 11 个增强器作前置臂 + **每任务 ≥2 个下游模型交叉**；
- 动机句式："低光条件严重损害下游任务性能"——我们换成"人影损害下游任务"（同构）。

**我们的适配（比 FoCo 更硬：配对天花板）**：
- 臂改**配对三态**：**I / 修复输出 / T（同场景同机位干净图 = 天花板）**——FoCo 参照是"别的图"，
  我们参照是"同一张图的干净版本"，伤害测量更精确；
- 测法：同场景配对 I vs T 让下游模型分别跑 → 三分类：共同框 / **ghost 框**（只在 I，误检）/
  **漏检框**（只在 T）；**ghost 落在 Ω 内的比例**定位元凶（人影 vs 普通反射）；
- 任务优先序：① person/vehicle 检测（人影=伪人形，主故事）② Keypoint R-CNN（"人影被认成人"实锤图）
  ③ 人脸（facexlib 已装）④ 分类/分割（可选，对齐 FoCo 加入）；
- 模型（照搬 FoCo"每任务 ≥2 模型"）：Faster R-CNN（torchvision，权重源可达）+ DETR（transformers，hf-mirror）
  + Keypoint R-CNN；YOLO 可选（需装，非必须）；
- **判定门（预登记）**：ghost 或漏检**跨场景一致（≥2/3 场景）且 ≥1/3 人影帧** → 伤害存在；否则整线关；
- **对照**：Raw(=I) 基线、纯提亮臂（防"亮度混淆"）、RDNet 零样本、T 天花板；
- **陷阱**：I/T 同曝光（我们数据天然优势）；阈值/类别预登记锁死。

**场景与样本量（说服力 = 场景数 × 任务数 × 形态数）**：
- 配对场景现状：apr 6 + may 5 = **11**（jun 13 锁死留 S3）——跨场景一致性（≥2/3）勉强够、不宽裕；
- **新拍 = 一石二鸟**（无需额外拍）：每个场景自带 I/T 配对 → 训练（人影洞多样性）+ 下游诊断（三态）
  同时受益。**拍摄三建议**：① 场景内要有**可检测真目标**（车/人/物——"漏检"侧需要画面里本来有东西）；
  ② 人影大小/角度有变化（远/近、正对/侧对）→ 测"多大的影子骗得过检测器"；③ 多环境（室内外/反射强度）。
- **MyVideo 零成本扩容**：24 场景 3904 帧含大量"拍摄者自反射"帧 → **无配对帧做 ghost 侧单侧统计**
  （检测器在人影位置检出假人；人影位置≈拍摄者站位，可半自动定位）→ 场景数 11 → **30+**，补 jun 锁死缺口；
- 可选：FoCo 用的公开低光集（CODaN/DarkFace/LIS）下载备用（若扩任务矩阵）。

## 5. 论文策略

  → WACV/ICME 或 TCSVT/JVCIR。
- **顶会（CVPR/ICCV/TIP）**：需一个正结果——最小版 = **掩码探针为正**（掩码可迁移）或泛化曲线为正。
- **贡献定位**：contribution 2（评测协议）吸收下游诊断作"任务级臂"；**不设独立第 4 contribution**。
- 与 GFRRN 划界：我们是"洞/人影 + 评测协议"；不宣称 PEFT 新颖。
