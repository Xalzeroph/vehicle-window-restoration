# 2026.9.17 E4 step1：免伤门控的上限检查 + 感知指标交叉验证

> 本轮问题（预登记）：**能否做出"免伤"去反射算子**——对任意输入输出不劣于输入，同时保住强反射区收益？
> step1 只答一个子问题：**"该不该动手"这件事本身有没有价值**（oracle 选择器上限）。
> 结论：**PASS**。块级 oracle 相对纯 RDNet **+2.02 dB**；
> 且 **LPIPS 判定 RDNet 感知上比输入更差**（0.3635 vs 0.3083）——**PSNR 与感知给出相反判决**。

---

## 1. 预登记判决门

- **PASS**：块级 oracle 相对纯 RDNet 提升 ≥ **+1.0 dB**（PSNR）且 LPIPS 同向改善 → 门控有空间，值得做
- **FAIL**：提升 < 0.3 dB → "选不选"没价值，免伤只能靠退回输入

## 2. 方法（零训练，复用现成预测）

`scripts/e4_oracle_gate_headroom.py`：三套实拍配对集 43 张输入，对每张图与每个 64×64 块
计算 `psnr(input, GT)` 与 `psnr(RDNet, GT)`，oracle = 逐块取优；同时用 pyiqa 算图像级 LPIPS。
（LPIPS 权重从本机缓存加载 `/home/zmy/data/cache/torch/hub/pyiqa/LPIPS_v0.1_alex-*.pth`；
`pyiqa` 已装入 `xreflection` 环境。）

## 3. 结果

### 3.1 Oracle 上限（PASS）

| 口径 | 输入 | RDNet | oracle | **oracle − RDNet** |
|---|---|---|---|---|
| 图像级 PSNR 中位 | 18.54 | 19.42 | 20.57 | +1.08 dB |
| **块级 PSNR 均值** | 22.20 | 23.09 | **25.11** | **+2.02 dB** |

选 RDNet 的块占比中位 **64%** → 多数块该动手，但**36% 的块该保持原样**。

### 3.2 感知指标交叉验证（关键）

| LPIPS（越低越好） | 输入 | RDNet | 差 |
|---|---|---|---|
| 中位 | **0.3083** | **0.3635** | **+0.0518（RDNet 更差）** |

> **PSNR 说 RDNet 更好（19.42 vs 18.54），LPIPS 说它更差——两者判决相反。**

与 E3 的残留度量互相印证：误差砍半（+5 dB）但**残留比中位 0.59**、78% 强反射块残留 >30%，
即"**PSNR 奖励 MSE 下降，感知惩罚可见残留**"。用户的肉眼判断与 LPIPS 一致。

## 4. 结论

1. **免伤门控有真金白银**：完美"选不选"的 headroom = **+2.02 dB（块级）**，且 36% 的块本该不动。
   *人话：只要判断对"这块该不该擦"，就能白捡 2 dB。*
2. **纯 PSNR 无法作为本轮判据**：同一批图上 PSNR 与 LPIPS 判决相反（PSNR 说改善、LPIPS 说变差）。
   后续判据改为**双指标**：`全帧 ΔPSNR ≥ 0` **且** `LPIPS 不劣`。
3. 与 E3 合并后的完整失效陈述：**"强反射区数值改善但感知残留（0.59）；干净区主动伤害（−2.26 dB、72% 为负）"**。
