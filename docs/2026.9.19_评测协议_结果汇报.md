## 1. 协议口径（实现细节，Opus 已核）

- mask：`D=max_c|I−g·T|`，`thr=max(3σ̂_D,8)`，**σ̂_D=1.4826·MAD(D|D≤p70(D))**（q=0.70 三套标定：
  σ̂ 中位 jun 7.5/apr 9.3/may 6.7 → thr 22/28/20，与构建口径 11~92 同区间）；
  **k 敏感性（Opus 补测）**：frac_M 对 k 敏感，k=2/3/4 中位 = 0.53/0.37/0.22（入附录）。
- 全部结构量逐通道后跨通道平均；主口径 gm（各臂 LS 对齐 T）；identity≡identity_gm。
- 非劣门限：Δper ≤ +0.005 / Δbg ≤ +0.02（沿用旧案）。
- **⚠ 钳死比例**：NGR 分母 <n0=3 的像素占掩膜内 22–48%、免伤域 27–62%（>30% 门）。
  Opus 复算 n0=1 与域限方案：**Δbg 符号与排序不变** → 判决不依赖钳死；但 Δbg 门限 +0.02 相对
  度量基线（~2.6）与 CI 半宽（0.3–2）≈零容差，**无区分度，降为描述性证据**。
- machine"更优者"规则（人评一致率用）：`d_perc>0→igm；否则 d_struct<0→rdnet；否则 tie`（逐图启发式，非协议判决）。

### 6.2 正式 pilot 设计修订 v2（重做材料前**重新预登记**）

> 修订触发（2026-09-19）：用户质疑"问自然度必然偏向实拍原图"。Opus 判读：**质疑条件成立**——主对全为失败样本时
> 自然度=送分题，且送分方向与 machine 方向（选 igm）共线 → 一致率虚高且不可证伪；但非逻辑必然
> （模型若把强反射干净去除，输出可胜"带反射原图"，反射本身即伪影）。**一致率改挂"损伤检出"轴。**

1. 题型定序：**Q_dmg 逐侧损伤**（糊 / 细节丢失 / 图案被抹 / 亮度异常；"残影"须写"处理重影"防混轴；可答"双无"）
   → **Q_eff 去反射效果**（哪侧残留更少；保留——C1① 人证 + 模型侧唯一"本应赢"的可证伪轴）
   → **Q_pref 更愿保留哪张**（描述性，不入一致率）
2. 材料：主对 16（近零/中/强 = 6/5/5，medD 分层 9.3/38.7/53）；**方向对照 3 对**（模型有效的强反射对，
   取自 OpenRR/合成——校准"送分偏置"）；trap = A=A×2 + 注意力 trap×1（**强降质如 ×4 下采样；禁 blur_identity**
   ——其可见性本身即被测对象）+ 亮度探针×1（描述性）
3. 一致率定义：仅对 machine 有向且 **|d_perc|≥0.005** 的主对计（旧材料 12 主对约剔 2）："人报单侧损伤侧 = machine 较差侧"为一致
4. 判据（重登记版）：① 注意力 trap 5/5 指名、A=A 无偏好 ≥8/10；② 损伤一致率 ≥70%；③ 近零档：模型侧被 ≥2/5 人
   报损伤的对 ≥3/6 且基线侧 ≤1/6（C1②）；④ 强档：模型侧"仍有可见残留" ≥3/5（C1①）；⑤ Q_pref 选模型侧 ≤30% 仅描述
   ——对照中也全选原图侧则坐实送分、偏好层弃用。被试排除知情者；发放说明不提自测（防启动效应）
