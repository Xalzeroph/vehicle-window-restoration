## 2. 判据（跑之前定好，结果出来只允许按这个判）

**主判据 P**：`E2-dark14`（3 种子）− `R-apr`（3 种子）的**种子级**两样本 95% CI。

- 若 **CI 排除 0 且下限 > 0** → **成立**：写成"补暗化有效，+Δ dB（种子级 95% CI [...]）"。
- 若 **CI 覆盖 0** → **不成立**：写成"3 种子下无法确认补暗化的收益"，**并撤回**单种子下的 +1.418 结论。
- 不设"接近 0 也算"的余地。**区间覆盖 0 就是不成立**。

**预期量级**（现在写下来，便于事后对账）：以 `R-apr` 的 std 0.578 当同方差假设，
3 vs 3 的两样本 SE = 0.472，t(4, 0.975) = 2.776 → MDE = **1.31 dB**。
若三点均值仍 ≈21.6，则 Δ ≈ 1.42、CI ≈ **[+0.11, +2.73]**。

**辅助判据 Q**（描述性，不作结论）：3 种子均值的种子 std 是否 ≤ 0.6 dB。
若 std 远大于 0.6（如 > 1.0），说明 14.3% 这档本身不稳定，需在文中说明"该剂量对种子敏感"。

## 3. 明确**不**能得出的结论

1. **不能**据此说 14.3% 是最优剂量 —— 依然只有 1 个种子在 8.3% / 11.3% 上，剂量排序不可能由此得到。
2. **不能**把 3 种子均值与 `may`（22.206，3 种子）的差当成"打平"或"仍有差距"：该对比仍需单独的种子级检验，
   而 §3.5 的 MDE 说明 0.5–0.6 dB 量级的差在本设计下大概率测不出。
3. **不能**回收"打穿色调上界 +1.325（108%）"这个说法 —— 若 3 种子均值低于 21.53，这个"打穿"就只是种子运气。
