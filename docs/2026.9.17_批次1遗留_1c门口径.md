# 2026-09-17 批次1遗留：1c 自动选择门 — 双口径读数 + 补充两判据

**一句话**：五条无参考判据没有一条显著优于"亮度先验 96.4"；若必须在两种口径里二选一，建议取**口径 A（前二命中率 ≥90%）**做门，
并把口径 B（悔值 ≤0.91 dB）降级为监控指标——因为 B 要求的"均值悔值 ≤0.91"事实上只有近似 oracle 的选择器才能达到（见下）。

## 0. 读数约定（口径定义）

- 悔值 = oracle@k PSNR − 选中候选 PSNR。**跨度 9.13 dB := 20.23（oracle@k 均值）− 11.10（恒选最差档 α=0.2 均值）**；10% 门 = **0.91 dB**。
- **口径 A（命中率）**：top1 = 选中档 = 最优档；top2 = 选中档与最优档相同或相邻（即人只需在 ≤2 个候选里挑）。
- 样本：118 个全膜裁片（`eval/probe_b1c_candidates.csv` 上批三判据 + 本批 `eval/probe_b1c2_selectors.csv` 新判据，逐样本对齐、0 差异）。oracle@k=20.23，真 α 候选=19.95（距 oracle 仅 0.28 dB，网格无表示误差），真 R+真 α=31.15。

## 4. 建议（一句）

**选口径 A（前二命中率），门线定 top2 ≥90%（全样本）**，理由数字化：③当前 92% 唯一达标且是产品形态对齐的读数（交付 ≤2 候选给人挑，人工成本封顶 2 张）；口径 B 的"均值 ≤0.91"差 2.8 倍、无参考判据可及性近零，做门会全场不通过、失去区分度，宜作监控（另注：若将来采用"交付选中±1"形态，B 立刻可过、+0.28 dB）。
附带提醒：A 的 90% 仅 2 个点余量、且在网格内子集降到 89%，下一轮若沿用该门，建议同时记录"网格内 top2"以防送分档撑门面。

## 追加（2026-09-17 晚）：扩档重测——门槛反而更严

用户采纳口径 A（前二命中 ≥90%）后，按"补 α=0.1/0.05 候选档再测"的建议重跑（k=7：0.75/0.6/0.45/0.3/0.2/0.1/0.05，脚本 `scripts/probes_0917/b1c3_extgrid.py`，输出 `eval/probe_b1c3_extgrid.csv`）：

|---|---|---|

**结论**：扩档**不能救人**——"前二命中"在 k 增大时是更严的判据（分母变大、oracle 变强）。**按采纳的门（前二 ≥90%），当前状态为 FAIL**（89% / 86%，仅 v21 子集 93% 过线）。
结构性含义：**自动选择单独不足以交付**，"全膜 = 一次标定"的路线（批次 4）承担主力；本门建议降级为监控指标，或等"学习式选择器"（用候选自身的无参考特征训练）再议。
