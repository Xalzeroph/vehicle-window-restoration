## 1. 目标（一句话 + 判据集 ①–④）

**把后端从"混合式微调"升为"能真正消除人影的修复器"**：在 R 主导的人影区让反射证据显著消退、
区外不劣、且可安全回退。

| # | 判据 | 数字（dev 校准后） |
|---|---|---|
| ① **消退**（T 锚定，口径 v2） | 适用 = Ω 非空 ∧ den_ok；Ω 内修复进度 `ρ=(C_I−C_A)/(C_I−C_T) ≥0.5` 且不过冲（Ω 内 luma ≥ T 的 Ω 内 luma − max(4, 0.5\|C_I\|)） | **identity 必败①**（ρ=0）；S1.5 现后端 ① = 0/40 |
| ② **参考改善** | Ω 外扩 5–10px，对配对无反射参考的裁剪 LPIPS 改善 **≥0.02** | 必要非充分（S1.5 证伪其鉴别力：可为窗内非 Ω 区改善买单，Ω 内不劣由 ④ 兜底） |
| ③ **不劣** | Ω 之外 ΔPSNR ≥ −0.2、ΔLPIPS ≤ +0.01；全局沿用**冻结的 GATE-1 数值** | 安全底线 |
| ④ **Ω 内不劣**（S1.5 新增） | `med_ratio = med\|A−T\|[Ω] / med\|I−T\|[Ω] ≤ 1.0`（硬线）；≤0.8 为 S2 目标次级线、不作判决 | 补 ② 的鉴别力缺口；perfect=0、C 案 3.2 被 ①④ 同抓 |

**判决 = ①∧②∧③∧④ 全过**；den 不足 / C_I<0 仅加诊断旗标、不剔除（S1.5 判决：保留，避免事后过滤；二者本就全挂①）。

**特异性护栏**（防作弊）：Ω 外 |Δluma| ≤3/255；真暗物对照区 Ω_ctrl 深度削幅 ≤25%
（全局提亮/γ 作弊会在 Ω_ctrl 同幅变亮而挂）。

- **`data/pools/r_signed_0920/`（+128 有符号，已完成）**：我方 43 层（jun/apr/may 直算 I−T）
  + RRW 9 场景（txt 配对帧、时域中值；|R| 均值 11.5–17.7、neg 4.5–20.9%）
- **OpenRR-5k**：仅小 |R| 低反射场当"洞"源，逐图重拟 s 并 clip0（负值多为曝光失配，不得直当"暗反射标签"）；
- **增广配方**：RRW 真 R × 反照率 mask `m∈[0.05,0.3]` → `I' = s(T + mR)`，验收=增广 Ω 深度分布不越实测包络；
- **用户新拍（ROI 最高，待拍）**：同机位三脚架，"人走入→走出"，切帧成对，5–10 场景，选有亮反射源的环境；
- **jun 锁死**（唯一确认集）；apr/may 为 dev。

## 4. 方法（两步走）

1. **LoRA/PEFT 双后端**（RDNet + RemoVal）——失败更像分布问题而非容量问题；adapter 可关 = 保留恒等回退；
2. 若 dev 两轮不过 → **结构路线**：检测头（人影/反射掩码）+ 仅掩码域内合成（参照 RemoVal 检测+LaMa，
   但绝不全图生成）。

**训练目标（S2 定稿，2026-09-20 晚）**：
```
L = Σ_c w_c[ Charb(T̂_c,T) + 1.5·Charb(R̂_c,R) ] + 0.2·|I − T̂ − R̂|      （4 列输出，w_c = c+1）
  + 1_real · [ 3·(M_Ω ⊙ |T̂−T|)/ΣM_Ω + hinge_过冲 + 0.2·DISTS(T̂,T)|_(Ω+10px 窗, 末列) ]
  + 1_src  · 0.5·Charb(T̂,T)          （开源直督：OpenRR / SIR2）
  + 0.1·‖∇T̂ ⊙ ∇R̂‖₁                  （exclusion；RDNet 代码算了未反传，此处补上）
```
- **hinge 过冲罚**（新）：Ω 内 `T̂ < T − max(4, 0.5|C_I|)` 的像素加权——防"压过头"式假修复
  （S1.5 实测：官方臂 ρ≥0.5 的 5 条帧全败于此）；
- **Ω 内误差按 |I−T| 归一化**（新）：防放弃大反射（难）场景；
- **感知项用 DISTS 而非 LPIPS**（2026-09-20 终裁）：与判据②（pyiqa-LPIPS 评测）**异族异实现**，
  避免"对着判据练"（Goodhart）；感知项居约束位（权重 0.2、仅末列、仅 Ω 外扩窗），选模不看②（①④为纲）；
- 不上对抗（小数据不稳，RDNet 代码默认开 GAN 是论文外行为）；**本轮只训 RDNet**，RemoVal 留 S3 后同配方。

### 5.2 S2 数据管线（配比 真实:重合成:开源 = 3:4:3）

- **真实 Ω 监督**：`train_pairs_omega_0920/` = apr 6 视频 16 对（I, T=GT, R=I−gT 有符号, Ω）；Ω 需补齐 6 视频；
- **在线重合成**：`T'=s·T, I'=s·(T+b·R)`，a≡1 全加性；R 白名单 = apr16+RRW9=25 层（jun/may 场景名黑名单硬排）；
  b~logU[0.4,1.5]（中位 0.77）、s~U[0.5,1.0]；T∈{RRW/SIR2/nature/scenes/VOC}-T；保留 R 高斯模糊增广；验收 R/T∈0.12–0.25；
- **开源直督**：OpenRR-5k 小|R| 子集 + SIR2 499 对（loss×0.5）；nature200+scenes2000 进在线合成；
- **VOC224**：短边 256→随机裁 224² → `data/external/VOC2012/VOC2012_224_png/`（15287 张，原 id 溯源）；
- 验收（过检才进训练）：内容级泄漏（T 源池 vs jun/may/v2.1，jun 零命中断言）+ R 白名单 0 命中 +
  Ω 语义（apr 6 视频手检≥60%）+ 包络（R/T 中位∈[0.12,0.25]、I'∈[0,1]）。

训练配置：Mona `both`（+5.23M）、冻主干、prompt 用冻结 ConvNeXt、grad-ckpt+AMP、save-memory；
10k iter ×2 seed(101/202)、bs6、lr 1e-4 cosine→1e-5、warm200；4 卡 = 卡1/2 双 seed 主臂、卡3 B1 对照、卡4 评测。

## 6. Ω（洞区）定式与标定（S0 产出）

```
s = q05(I_lin/T_lin)（γ=2.2）;  R = I − (s·T_lin)^(1/γ)·255
σ = 1.4826·MAD(R − medfilt3(R))；τ = max(6, 5σ)
bg = 分块 p90（48px）上采样；S = bg − R
Ω = CC{(S>τ) & (2R<bg)}，面积≥0.5%，填内洞；帧级闸 q90(R)<max(12,6σ) → Ω=∅
```

标定（`eval/eval_omega_v2.csv`、`fig/omega_v2_0920.jpg`）：jun/170941 人影 bbox 覆盖 76%/61%（用户目检通过）；
jun 21–34% / apr 15–28% / RRW 9%；~~may 15–25%（目标 ≤5%，k 扫描无解）→ 弱反射类判"Ω 不适用"~~
——**2026-09-20 S1.5 修正**：may 按 `den_ok` 口径照常入判（14 帧中 3 帧 Ω 空记 N/A，11 行有效），
报告标限域；S3 以 jun 为准。
