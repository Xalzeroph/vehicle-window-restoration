## 3. 数据合成脚本链

| 脚本 | 功能 |
|---|---|
| `fetch_hf_tintedglass_sources.py` | 下载 HF 原始数据，划分训练/验证来源 |
| `materialize_hf_tintedglass_v2.py` | 生成玻璃反射数据、目标图与 `metadata.json` |
| `curate_hf_tintedglass.py` | 过滤部分非自然摄影来源 |
| `vehicle_film_forward.py` | **训练时在线生成**反事实反射与相机响应 |
| `train_vehicle_optical.py` | 训练与验证 |

### 在线合成参数

| 参数 | 设置 |
|---|---|
| 玻璃衰减等级 | `[0.30, 0.45, 0.60, 0.75, 1.00]` |
| 反射来源 | 每个样本随机选**两个不同来源** |
| 反射强度 | **Log-uniform [0.65, 1.45]** |
| 反射模糊 | Gaussian，半径 **[0, 1.2]** |
| 反射空间分布 | `spatial` |
| 噪声标准差 | **1.5/255** |
| 白平衡增益 | 每通道 Uniform **[0.7, 1.3]** |
| Gamma | Uniform **[0.85, 1.15]** |
| 曝光 | 按样本亮度 **95 分位**定防裁剪曝光 |
| 随机增强 | 随机裁剪、水平翻转、反射变化 |
| 相机干预 | 两种相机响应 × 两种反射条件 |

**核心合成关系**：

$$\alpha(x)=\operatorname{clip}\!\big(l\,g(x)\,m(x)+1-m(x),\;0.01,\;1\big)$$
$$I_{\mathrm{raw}}=\alpha(x)\,T+R_{\mathrm{spatial}}+\epsilon$$

随后经曝光、白平衡、Gamma 生成训练输入与对应的透射目标。

## 4. 数据准备命令（他的原始命令）

目标目录需为空。

```bash
cd /data/hdd3/agent-research-runtime/vehicle-window-restoration
BASE=/data/hdd3/agent-research-runtime/vehicle-assets
SOURCE=$BASE/datasets/tintedglass-rdt-synth/train/rdt_0915

  --out "$DATA/train" --fold train --variations 2

  --out "$DATA/validation" --fold validation --variations 2

  --out "$DATA/train/photo_manifest.json"
python scripts/curate_hf_tintedglass.py --source "$DATA/validation/manifest.json" \
  --out "$DATA/validation/photo_manifest.json"
```

## 5. 训练命令（他的原始命令）

```bash
BASE=/data/hdd3/agent-research-runtime/vehicle-assets
RUN=$BASE/runs/rdnet_logodds_display_v4_hf_20261029_full
export PYTHONUNBUFFERED=1 PYTHONDONTWRITEBYTECODE=1 CUDA_VISIBLE_DEVICES=4 OMP_NUM_THREADS=4
export TMPDIR=$BASE/tmp/rdnet_train XDG_CACHE_HOME=$BASE/cache/rdnet_train TORCH_HOME=$BASE/cache/rdnet_train/torch

nohup $BASE/.venv/bin/python -u scripts/train_vehicle_optical.py \
  --train-manifest $BASE/runs/tintedglass_hf_rebuild_20261029/train/photo_manifest.json \
  --val-manifest   $BASE/runs/tintedglass_hf_rebuild_20261029/validation/photo_manifest.json \
  --checkpoint $BASE/checkpoints/official-rdnet/rdnet.pth \
  --classifier-checkpoint $BASE/checkpoints/official-rdnet/cls_model.pth \
  --out "$RUN/weights" --device cuda:0 \
  --steps 1200 --batch 1 --crop 128 --lr 1e-5 --seed 20261029 \
  --reflection-field spatial --eval-limit 15 --cpu-threads 4 --log-every 10 \
  >> "$RUN/train.log" 2>&1 < /dev/null &
```

**重跑需换新的 `RUN` 目录**（脚本不覆盖已有输出）。

## 7. 与我们 2×2 实验的差异（**影响结论解读，必读**）

| 项 | 他的实际配置 | 我们正在跑的 2×2 | 影响 |
|---|---|---|---|
| **数据** | 他的合成 `rdt_0915`（320 源 × 2 变体 = 640 样本） | **我们的 170 对真实配对** | 完全不同分布；两边数字**不可直接比** |
| **步数** | **1200** | **6000** | 我们多 5× |
| **batch** | **1** | **6** | 我们多 6× |
| **crop** | **128²** | **224→256→320²** | 我们每步像素多 3–6× |
| **等效样本量**（crops×面积） | ≈ 1200 × 16 K px ≈ **20 M px** | ≈ 36000 × 60 K px ≈ **2.2 G px** | **我们约 110×** |
| **lr** | **1e-5** | 1e-4（他的损失）/ 1e-3（补偿臂） | 我们的损失量级大 ~50×，故 lr 也大 |
| **grad clip** | **1.0** | 我们的脚本**未启用** | ⚠️ 他的稳定性依赖 clip；我们缺这一项 |
| **损失** | 显示域 H1（像素 + 梯度 MSE） | N1/O2 用 `lam_grad=2.0` 近似；N2 用我们的 6 项 | N1/O2 只是**近似**他的损失（缺 clip、lr 差 100×） |
| **可训练参数** | FocalNet 末层 + 其余（**266.4 M**） | 同（`--arch clean1029`） | 一致 |
| **初始化** | `official-rdnet/rdnet.pth` | 同一个 `pretrained/rdnet.pth` | 一致 ✅ |

### 三条必须写进结果的限定

1. **他确实训练过 1200 步**并产出了 `rdnet_counterfactual.pth`，但**未报告任何 PSNR/SSIM**（`report.json` 是训练报告，不是基准表）。此前"他完全没训过"的说法应更正为：**训过，但没有可比指标**。
2. 我们的 N1/O2 是"**他的损失 × 我们的配方**"（lr 大 10–100 倍、无 grad clip、步数多 5 倍），**不是复现他的实验**；只能回答"这个架构在我们的训练预算下如何"。
3. 他的合成数据与我们实测的**RRW 系统性色偏**（a*=+6.7, b*=+10.8, t=+69）同源（`pools/` 全是 RRW 帧），因此他的数字里可能含有"匹配偏色"的成分；我们用自己的真实配对做 2×2，正是为了排除这一项。
