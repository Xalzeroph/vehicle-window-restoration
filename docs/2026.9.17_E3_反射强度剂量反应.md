# 2026.9.17 E3：反射强度剂量-反应 + 残留度量（定位轮的验证实验）

> 目的：验证定位文档中**因果排序 ①**（"R 主导是辨识性硬退化"）。
> 结论：**① 被否**。块级数据显示强反射区 RDNet 反而受益（+2~4.8 dB），但其**残留比中位 0.59**
> —— 数值改善与"肉眼可见残留"并存；真正稳定为负的是**几乎无反射的干净区**（−2.26 dB，72% 块为负）。
> headline 应从"R 主导"改为：**①' 指标与感知脱节（残留六成）+ ② 无恒等分支（干净区主动伤害）**。

---

## 1. 方法（零训练）

`scripts/e3_robs_binning.py`：三套实拍配对集（4/5/6 月）逐 64×64 块，
按局部 `r_obs = mean|g·I − GT| / mean(GT)` 分箱，统计 (a) 输入相对 GT 的 PSNR、(b) RDNet 的块级增益。
`scripts/e3_residual_ratio.py`：在强反射块上直接量**残留比** `mean|RDNet−GT| / mean|I−GT|`。

## 2. 结果

### 2.1 r_obs 分箱（13,395 块，三套合并）

| r_obs 区间 | 块数 | 输入 PSNR | RDNet 增益中位 | 增益<0 占比 |
|---|---|---|---|---|
| **0.00–0.05** | 1567 | **35.82** | **−2.26** | **72%** |
| 0.05–0.10 | 2113 | 24.43 | +1.52 | 35% |
| 0.10–0.20 | 4785 | 22.27 | +1.39 | 41% |
| 0.20–0.30 | 2636 | 19.13 | +0.56 | 45% |
| 0.30–0.50 | 1565 | 15.69 | +2.52 | 28% |
| 0.50–0.80 | 575 | 12.68 | +4.53 | 0% |
| 0.80–1.20 | 105 | 12.33 | +4.84 | 0% |

相关系数 r_obs vs 增益 **+0.261（正）** → **"反射越强越救不回来"不成立**。

纹理对照：在 r_obs>0.3 的块内按 GT 纹理分箱，增益各档均为正（+1.98~+4.37），
纹理与增益相关 **−0.058（无关）** → "增益只来自平坦区"的假设亦被否。

### 2.2 残留比（强反射块 r_obs>0.5，n=729）

| 指标 | 值 |
|---|---|
| 误差：输入 → RDNet | 58.0 → 32.2（≈砍半，对应 +5 dB） |
| **残留比中位** | **0.59**（p10 0.17 / p90 0.89） |
| 残留 >30% / >50% 的块 | **78% / 61%** |

## 3. 结论

1. **①"R 主导=硬退化"被否**：强反射区 RDNet 确有数值改善（+2~4.8 dB），且增益不依赖纹理。
   *人话：反光越强的地方，它其实越有用。*
2. **但残留六成（中位 0.59）**，78% 的强反射块残留 >30% → **PSNR 奖励"砍半"，感知判"没去掉"**。
   指标与感知脱节本身是该报告的问题。*人话：影子擦淡一半，分数涨了，眼睛还看得见。*
3. **稳定为负的是干净区**：r_obs<0.05 的块 −2.26 dB、72% 为负（输入 PSNR 已 35.8）→
   **缺口②「无恒等分支」是 headline**，且它是可做的方法贡献（no-harm / 按强度插值动作）。
4. **与场景级结果的调和**：4 月场景级 −1.78 dB 由"干净区被搞坏"拖下来，强反射区的改善救不回整体；
   5 月的月内二分（有反射 +0.3~2.0 / 近零反射 −3.9~−7.9）是同一机制的极端表现。
