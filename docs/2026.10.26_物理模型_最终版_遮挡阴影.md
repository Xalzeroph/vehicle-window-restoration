## 1. 光路剖析：从物理光线到像素

### 1.1 相机在像素 x 上收到的是什么

隔着贴膜玻璃朝场景看，到达相机同一像素的光有**两条互不相干的路径**：

```
        相机侧                                         玻璃背面
   ┌──────────┐        ┌─────────────┐              ┌──────────┐
   │  相机    │◄───────│  贴膜玻璃   │◄─────────────│  场景    │
   └──────────┘        └─────────────┘              └──────────┘
        ▲                    │  ▲
        │  ② 反射光           │  │  ① 透射光
        │                    ▼  │
   ┌──────────┐          （相机侧来光）
   │ 遮挡物   │
   └──────────┘
```

- **① 透射光**：场景辐亮度穿过膜与玻璃，被吸收一部分
- **② 反射光**：相机侧的光在玻璃界面被反射进镜头

### 1.2 逐因子分解（原公式）

原写作

```
I(x) = e^(−τ(x)) · T(x) · (1 − η(x))
```

| 因子 | 物理含义 | 成立条件 |
|---|---|---|
| `e^(−τ)` | Beer–Lambert **吸收** | τ = α·d 为光学厚度；**只含吸收，不含菲涅耳反射损失** |
| `T(x)` | 场景辐亮度 | 应为**无玻璃、无阴影**的真值 |
| `(1 − η)` | 被遮挡物挡掉的那部分**照明** | 仅在**线性辐亮度域**、且**照明均匀/各向同性**时是标量乘子 |

菲涅耳的严格写法是

```
t_total = (1 − R₁)(1 − R₂)(1 − R₃) · e^(−τ)
```

正入射时界面反射合计约 8%，斜入射更大。所以把 `e^(−τ)` 当成"透光率"是**少算了菲涅耳**。

### 1.3 三处必须修正

#### (a) `e^(−τ)` 与 `T` 重复计算了玻璃衰减

我们的 `T` 是**同场景黑布帧**——**玻璃仍在**，只是反射源被黑布挡住。故数据里的

```
T_measured = e^(−τ) · L_scene · (1 − η_T)
```

**玻璃衰减已经在 `T` 里了。** 再乘一次 `e^(−τ)` 等于算两遍。

**原公式隐含假设**：`T` 是"无玻璃的真实场景辐亮度"。**而数据集里不是，且没有这样的真值。**

#### (b) 11% 是像素域的数，辐亮度域约 24%

8-bit sRGB 编码近似 `L ∝ V^2.2`。逐场景测得的 `(I/T)` 是**像素值之比**：

| 量 | 像素域 | 辐亮度域（γ=2.2） |
|---|---|---|
| 洞内 (I/T) | 0.882 ± 0.078 | **0.759**（压暗 **24.1%**）|
| 洞外 (I/T) | 1.143 ± 0.179 | **1.342**（反射贡献 **+34.2%**）|

即**照度下降在辐亮度域是约 24%，不是 11%**；反射贡献约 34%，不是 14%。
"两者量级相当"这个结论**不变**，但绝对数值翻倍。

> 注：手机图可能另有 tone mapping，纯 γ=2.2 为近似；严谨需 RAW 或标定的相机响应曲线。
> **论文里报照度下降时必须注明所在域。**

#### (c) 反射发生在哪个界面，决定它是否受膜衰减

`τ` 是**体吸收**。反射发生在界面：

| 反射界面 | 是否穿过介质 | 是否受 `e^(−τ)` |
|---|---|---|
| **相机侧界面（膜表面）** | 否 | **不受衰减** |
| 远侧界面（玻璃–空气） | 是，进出各一次 | 受一次衰减 |

贴膜车窗的膜在内侧，主要反射来自膜表面，故"反射不被 τ 衰减"是对的；
但严格模型应分两项：

```
R_refl = R_near + e^(−τ) · R_far
```

遮挡物挡住的是"相机侧的反射路径"，故 `β` 主要调制 `R_near`。

### 1.4 修正后的自洽模型（以可测量为准）

```
I(x) = T(x) · (1 − η_rel(x))  +  (1 − β(x)) · R_near(x)  +  β(x) · R_b(x)
       └── 透射侧：黑布帧 + 额外压暗 ──┘  └─ 被挡的镜面反射 ─┘  └ 遮挡物自身漫反射 ┘
```

| 符号 | 物理含义 | 数据里怎么得到 | 所在域 |
|---|---|---|---|
| `T` | 黑布帧（**已含**玻璃吸收与菲涅耳） | 直接有（`T/`） | 像素 |
| `η_rel` | 相对黑布帧的**额外**照明损失 | `(I/T)_in / g` 再转辐亮度域 | **辐亮度**约 24% |
| `β` | 反射立体角被挡比例 | 由遮挡区 Ω 定义，间接 | — |
| `R_near` | 相机侧界面反射（不受膜吸收） | 洞外约 `I − T` | 像素 |
| `R_b` | 遮挡物自身漫反射（很淡） | 高通残差 | 像素 |

**关键：`e^(−τ)` 已从公式中移除**——它被 `T` 吸收。写上去会让读者误以为数据集有无玻璃真值。
若必须显式写出光学厚度，正确方式是 `T_measured = e^(−τ)·L_scene·(1−η_T)`，与输入方程联立后 τ 自动消去。

### 1.5 `(1 − η)` 这个乘子的适用边界

- **仅在线性辐亮度域**成立；在 gamma 编码像素上直接相乘是错的。
- **仅在照明均匀/各向同性**时成立。若照明有方向性（一扇窗、一盏灯），遮挡改变的是**照明的方向分布**，
  阴影两侧表面着色模式会变，**不是一个标量乘子能描述**。
- 严格做法：`L'(x) = ∫ ρ(x,ω) · E'(x,ω) dω`，其中 `E'` 是遮挡后的入射辐照度分布。

对本文的 diffuse 场景 + 漫射环境光，标量近似可接受，但**必须作为假设写明**。

## 4. 已撤回的错误表述

> **⛔ 撤回 1：`e^(−τ)·T·(1−η)` 这个形式。**
> `T` 已含玻璃衰减，再乘 `e^(−τ)` 是重复计算。正确形式见 §1.4。

> **⛔ 撤回 2：把"11.4% 压暗"当作辐亮度域的照明损失。**
> 11.4% 是像素域；辐亮度域约 24%。**论文必须注明域。**

> **⛔ 撤回 3：早前"Ω 内 R_obs 中位 −12.08 vs 洞外 +8.05，差 −20.12 灰阶，故照度下降是主项"。**
> 该 −20.12 主要反映"反射对比"（洞外反射加光），不是压暗幅度。
> 反证：把 Ω 平移 45% 画面高度的**对照区也掉 −15.48**（真实 Ω 为 −20.69）。
> 正确压暗幅度以 `(I/T)_in / g` 度量。

## 5. 命名处置

**不再使用"反射洞（reflection hole）"作为核心术语。** 该名称暗示"只有反射被挖空、其他不变"，
与实测（照度同时下降、且存在遮挡物自身淡反射）不符。

**改用**：

> **遮挡区（occlusion region）Ω**：相机侧前景物体遮挡反射光路与场景照明的区域。
> 其内反射被大幅削弱、场景照度下降（辐亮度域约 24%），并叠加大幅衰减的遮挡物自身漫反射。

英文：*occlusion region*，首次出现写 *the occluder-induced region (formerly called "reflection hole")*。

## 6. α 必须由数据定

∂Ω 是**阴影的边缘**，故它**本来就存在于 T 中**（不止存在于 R 中）。

实测（**旧池 126 对**，新池待复核）：

```
|∇T_GT| / |∇R_GT| |_∂Ω  =  0.685
|∇T_GT| |_∂Ω           =  1.59 × |∇T|_洞外
```

故"∂Ω 上 T 应平滑"的阈值必须取

```
α_data ≈ 0.69      （阴影所能解释的边缘强度）
```

**而非 α = 0.25。** α=0.25 等于要求模型比阴影本身还平滑，必然抹掉真实结构——
L^shift 首次实验（α=0.25、旧掩码）洞区反而由 17.46 掉到 17.18，与此一致。

## 7. 方法论教训：区域内外比较必须配平移对照

"平移 45% 画面高度的对照区"直接抓出了用错参照系的问题：
真实 Ω 的内外差是 −20.69，而任意平移区也有 −15.48。

**今后凡"区域内 vs 区域外"的比较，必须同时报告平移对照；否则差值不可信。**
同理，涉及"像素值 vs 辐亮度"的换算，必须注明域。

## 10. 复算入口

```bash
# 三项目分解：R_obs = I - g*T；统计 Ω 内 R<-2 / |R|<=2 / R>+2 占比与中位数
# 压暗幅度（不依赖 g）：逐场景 (I/T)_in / g ；(I/T)_in = median(I|Ω)/median(T|Ω)
# 辐亮度域换算：V^2.2（近似 sRGB；严谨需标定响应曲线）
# 反射缺失：洞外 (I/T)_out = median(I|far)/median(T|far)
# 对照：把 Ω 平移 45% 画面高度后重复上述统计
# 高通正向残差聚集度：高通 σ=30，阈值 max(3, 3σ)，与随机置换比较最大连通域
```
