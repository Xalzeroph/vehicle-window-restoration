# 2026.10.26 物理模型最终版：遮挡区 = 反射缺失 + 遮挡物自身淡反射 + 照度下降

> 此前所有关于"反射洞"机制的说法以本文档为准；第 6 节列出已被否证的旧说法及错因。

## 1. 结论：三项目同时成立

拍摄者隔着贴膜玻璃拍照时，**自身身体**挡在相机背后。在遮挡区 Ω 内同时发生三件事：

```
I(x) = e^(−τ(x)) · T(x) · (1 − η(x))  +  R(x) · (1 − β(x))  +  β(x) · R_b(x)
       └──── 透射侧被压暗 ────┘        └── 镜面反射被挡 ──┘    └ 遮挡物自身漫反射 ┘
```

| 项 | 含义 | 实测证据（新池 82 对，另注者除外） |
|---|---|---|
| R(1−β) | **镜面反射被挡** | 洞外 (I/T) = 1.143 ± 0.179；若反射被完全挡掉则 (I/T) 回到 1.0 |
| β·R_b | **遮挡物自身淡反射**（很淡但存在） | 高通 σ=30 后，Ω 内正向残差占 **1.66%** 面积（中位 1.01%），空间聚集度 **280×**（中位 250×，随机置换 n=60） |
| η | **照度下降**（遮挡物挡住照到场景的环境光） | 洞内 (I/T) = 0.882 ± 0.078；全局增益 g = 0.997 ± 0.046（无全局曝光偏差）⇒ **额外压暗 11.4% ± 7.7%（≈12.5 灰阶）**；61/82 样本 >5%，仅 8/82 无压暗 |

其中 R_obs ≡ I − g·T（g 为逐场景标定增益，与池内 `R/` 相关 0.994）。

### 两项的相对大小（修正后的定论）

| 效应 | 幅度 | 定义方式 |
|---|---|---|
| **反射缺失** | 约 **14%** | 洞外 (I/T)=1.143 → 洞内若仅"反射被完全挡掉"则为 1.0 |
| **照度下降** | 约 **11%** | (I/T) 由 1.0 进一步降到 0.882 |

**两者量级相当。不存在"某一项压倒性主导"。**

> ### ⛔ 已撤回的错误表述
>
> 早前写作"Ω 内 R_obs 中位 −12.08 vs 洞外 +8.05，差 **−20.12** 灰阶"，并据此称"照度下降是主项"。
>
> **该 −20.12 主要反映"反射对比"（洞外反射加光约 +14%），不是压暗幅度。**
>
> **反证**：把 Ω 平移 45% 画面高度的**对照区也掉 −15.48**（真实 Ω 为 −20.69），
> 说明该差值主要由"距反射富集区的远近"决定。
>
> **正确的压暗幅度是 11.4%，以 (I/T)_in / g 度量，与 g 的假设无关。**

## 2. 推论：Ω 内 R_obs 不等于 0，可以为负

```
R_obs |_Ω  ≈  ( −τ·T·η )  +  ( β·R_b )
                负，主导        正，稀疏（1–2% 面积）
```

解释了三件此前解释不通的事：

| 现象 | 解释 |
|---|---|
| Ω 内 R 中位为负（约 −12 灰阶） | −τ·T·η，即约 11% 的额外压暗 |
| 但有 11.9% 像素 R > +2 | β·R_b 压过阴影的那些位置 |
| 正向残差**成团 280×**（不是散点噪声） | 是真实的物体像，高通后仍有结构 |

## 3. 对"反射洞"这个命名的处置

**不再使用"反射洞（reflection hole）"作为核心术语。** 理由：该名称暗示"只有反射被挖空、其他不变"，
与实测（照度同时下降约 11%、且存在遮挡物自身淡反射）不符，会给审稿人留下"定义与证据不符"的口子。

**改用**：

> **遮挡区（occlusion region）Ω**：相机侧前景物体遮挡反射光路与场景照明的区域。
> 其内反射被大幅削弱（约 14%）、场景照度下降（约 11%），并叠加大幅衰减的遮挡物自身漫反射。

英文：*occlusion region*，首次出现时写 *the occluder-induced region (formerly called "reflection hole")*。

## 4. 对损失的直接影响：α 必须由数据定

∂Ω 是**阴影的边缘**，因此它**本来就存在于 T 中**（不只是存在于 R 中）。

实测（**旧池 126 对**，新池待复核）：

```
|∇T_GT| / |∇R_GT| |_∂Ω  =  0.685
|∇T_GT| |_∂Ω           =  1.59 × |∇T|_洞外
```

故任何"∂Ω 上 T 应平滑"的约束，其阈值必须满足

```
α_data ≈ 0.69      （即"阴影所能解释的边缘强度"）
```

**而不是 α = 0.25。** α=0.25 等于要求模型比阴影本身还平滑，必然抹掉真实结构——
L^shift 首次实验（α=0.25、旧掩码）洞区反而由 17.46 掉到 17.18，与此一致。

## 5. 方法论教训：区域内外比较必须配平移对照

本轮检验里，**"平移 45% 画面高度的对照区"** 直接抓出了用错参照系的问题：
真实 Ω 的"内外差"是 −20.69，而任意平移区也有 −15.48，说明该差值主要来自参照系（反射富集区）。

**今后凡"区域内 vs 区域外"的比较，必须同时报告一个平移对照；否则差值不可信。**
