## 2. 新判据精确定义

### a. 反射区 mask
- **合成集必须用 `r/`**：实测 `I = α·T + α^p·R + n`、`r_couple=0`（p=0 → 反射不随膜衰减），
  `r/` 本身就是 R_eff 且**与 α 无关**——膜外（α=1，占 17.7%）照样有反射 → **不能用 α 当 mask**。
  定义：`M = gray(r/) > 8`（≈5.3σ_noise）；α 阶跃带（|Δα|>0.05）只作诊断列。
- **实拍集**：`D_gain = max_c|g·I − T|`（g = 最小二乘增益，消 I/T 曝光差；jun 实测 gain 1.21–1.27），
  `M = D_gain > 8`；敏感性带 thr∈{5,8,12,16}；**不用 build 时的 floor 条款**（apr/may meta 无 floor，不可复现）。
- 禁含被评臂预测（mask 不得由被评输出导出）。两集机制不同 → 只定义层可比，**数字不跨集混排**。

### b. 结构残差（三量并列）
- (i-a) 掩膜内 SSIM 图均值（skimage full=True，σ=1.5）
- (i-b) **NGR（主）**：σ=2 低通抗 0.36px 对齐误差；`E = G₂*|T−Ŷ|`；分母 `N = sqrt(G₄*(T−G₄T)²)`，
  下限 n0=3（敏感性 {2,3,5}）；`NGR = mean_M[ E / max(N, n0) ]`。
  **分母=GT 自身局部对比度**（不用输入误差 → 无"强反射免单"；旧残留比与 PSNR 同轴正因分母≈|I−T|）
- (i-c) **免伤项 NGR_bg（决议遗漏，必须补）**：同式在 `M̄ ∩ {G₈*T ≥ 20}`。
  "不劣于输入"的定义域在非反射区；缺此则"全图抹平"算子在掩膜外零罚。

三量均算 gm 与 raw：**实拍主口径 gm**（各臂同规则 LS 增益），**合成主口径 raw**，另一口径次报。

### c. Exist 反射存在性分数（eval-only，论文须标）
`G = G₄*(I − g·T)`，`E = G₄*(Ŷ − T)`；形状保留 `ρ = Σ_M E·G / √(ΣE²ΣG²)`（identity 构造性=1，
若 ρ_identity<0.9 即实现 bug）；能量保留 `A = √(Σ_M E² / Σ_M G²)`。完美去反射→0；
**ρ<−0.3 = 过减 alarm**（4 月失效签名）。

### d. 裁剪 LPIPS
组件 = M 的 8-连通域中面积≥1% 者；bbox 外扩 16px；边<128px 者 pad 或记 skip；I/Ŷ/T 同窗；
逐图值 = **跨组件中位**，另报最大组件与 union-bbox（jun frac_M 0.69 → union≈全图必稀释，不作主值）。
模型同 E4/E7 的 pyiqa lpips。

### e. 约束非劣
逐图 gm 差 `d_struct = NGR_m(Ŷ) − NGR_m(I)`，d_perc、d_bg 同理（≤0 佳）。
**必经约束**：d_perc、d_bg 中位≤0 且 bootstrap CI 上界 ≤ +0.005(LPIPS)/+0.02(NGR)；
违反者无论结构多好都判"违反不劣"。满足者之间比 d_struct 中位，符号检验 p<0.05 判胜，否则 tie；
双方都违反＝双方 FAIL。ΔPSNR≥0 只作第 4 约束，不参与排序。

### f. 统计口径
配对单位=图，聚类=场景（13/6/5/12）。Bootstrap **按场景重采样**（含场景内全部图/档），
B=10000，percentile CI；报逐图中位差与场景级中位差双版本。符号检验对象=场景级配差中位，
exact binomial（13 场景需 ≥11/13 才 p<0.05，功效如实报）。确认性比较仅 3 个
（①实拍合并 zeroshot vs identity_gm；②v2.1 各 S1 臂 vs 输入；③litgt none_low 免伤），各家族 Holm；
其余只描述。

## 5. 风险 / 作废条件

1. **mask 口径 = 单点最大风险**（两集机制不同、floor 不可复现）→ 全表随报阈值敏感性带。
2. 帧级配对残留对齐误差污染掩膜内结构量（σ=2/4 低通只缓解）。
3. Exist 是 oracle 量（吃 GT 反射分量），**不得写成在线指标**。
4. 功效：场景聚类后 CI≈±10%，大量 tie；如实报，禁以均值强判。
5. G-A 若在 ±0.05 内失败，先分辨"读出差 vs 口径错"再决定是否重跑推理。

**作废条件**：(a) G-A 失败且 24h 未定位 → 全部重评数字不可比；
(b) G-D 仲裁 >1/3 格 → 判据体系推翻重议；(c) 报告出现 v23/indomain 臂间胜负 → 该段作废。
