# 01_cover

这个月的汇报，核心就是这一组数字：在最深的那一档贴膜、也就是 alpha 等于零点三时，raw PSNR 从零样本的十二点零五，做到了十八点五。下面我按时间线讲三件事：我们怎么把它做活的，哪些路走不通，以及接下来押哪两条腿。

---

# 02_task_and_benchmark

先把任务和口径对齐。任务一句话：观测图等于逐像素衰减 alpha 乘上透射层 T，再加上反射层 R，我们要在只有单帧的条件下把 T 抠出来。深色车膜把光吃掉七成再叠上反射，所以这不是普通的去反射问题。路线是两阶段的，RDNet 先去反射，ExpoMamba 再提亮。基准用 v2.1，三档 alpha 乘十二个场景，口径是 raw 和 gm 两种 PSNR，并且强制并读常数基线与结构相关。另外我们立了三条护栏贯穿这个月：常数基线必须同框，结论必须在两个测试集上各自成立，统计一律用配对检验加场景聚类的百分之九十五置信区间。后面会看到，这三条每一条都救过一次结论。

---

# 03_network_architecture

这一页把"我们到底改了什么"说清楚。输入进来分成两条支路：主干是 FocalNet-L，两亿零五百七十万参数，我们全程冻结，它给出四档多尺度特征，分辨率从二分之一到十六分之一；另一条支路把图缩到 224 见方，过同样冻结的 ConvNeXt-small，得到一个六维的 code。要注意这是一个全局向量，不是逐像素的 alpha 图——它过一个 6 到 512 再到 64 的两层 MLP，变成 64 维的通道门控，只乘到主干的 stem 特征上，后面的四档特征和 SubNet 内部完全不经 alpha。这一点很重要，它解释了为什么单独去调 alpha 头那条线会一直卡在零点七的平台。两条支路在门控这里汇合，然后串四个 SubNet，每个里面有可逆残差；Decoder 代码里建了三个，但只有一个被真正调用。输出是残差式的，I 和自己拼接再减去 decoder 的结果，前三通道是 R̂、后三通道是 T̂。左下角是这轮 PEFT 线的改动：Mona 适配器挂进 FocalNet 的每个 FocalModulationBlock，调制残差之后挂 mona1、FFN 残差之后挂 mona2，二十四个 block 一共四十八个，新增五点二七兆参数，配梯度重算换显存。右下角是参数量账：主干两亿零五百七十万冻结，可训的是其余六千零七十万；加上 Mona 之后变成六千五百九十五万。

# 04_zero_shot_collapse

起点是什么样的？直接拿 RDNet 官方权重在贴膜域跑，最深那一档只有十二点零五 dB。这个数字要和同档的常数基线一起看——一张涂成 GT 均值的平坦灰图，什么都不做，也能拿到十七点六八 dB，比零样本还高五点六 dB。结构相关只有零点二六，误差还随着 alpha 变小急剧上升。所以失败的性质很清楚：不是图像太暗，是内容被破坏了。这条判断决定了后面所有方法的方向。

# 05_september_timeline

这一个月的时间线大概是这样。九月九号做预演和实拍协议，十三号基准 v2.1 定版、跑了 pilot 的 A 和 B 两轮、也确认了 alpha 平台，十四号迁进共享机，十五号做数据卫生重建和分离器方案，十六号 S1 域适配判决，主结果落袋，十七号就是今天，出口判决、锚点探针和两个新方向。中间有两个明显的断点：搬迁占掉一整天，还有十五号那次数据卫生事故——训练池被测试集污染了，一批结论当场作废，我们按内容级核查重建之后才继续。渲染成橙色的两个节点就是这两处。

# 06_alpha_plateau

先说第一个困难。我们最开始的判断是 alpha 头没调好，但四个独立估计器——alpha 头、ridge、GLOBAL 和 B 臂，特征源和架构都不一样——估计结果全部落在零点六零五到零点七四一之间，而真值是一。四个独立方法撞在同一个平台上，说明这不是调参问题。理论上的原因也很清楚：在 I 等于 alpha T 加 R 这个模型下，把 alpha 放大 s 倍、同时把 T 缩小 s 倍，观测完全不变，所以单帧只能定下两者的乘积，这是本征分解的经典歧义。这和 Retinex、去雾、阴影消除是同一类问题，都要靠先验加锚点来消歧。所以方向不是继续调 alpha 头，而是把结构信息当锚点引进来——这一点在最后一页会回到。

---

# 07_leak_incident

第二个困难是一次事故。我们发现那个所谓的域匹配训练池，五百一十六个文件里其实只有十二张内容，而且这十二张全部就是测试集的 T。这意味着域匹配训练集整体泄漏，相关结果全部作废。麻烦的地方在于，按文件名查、按统计口径查都查不出来，必须按内容查。处置做了三件事：把内容级泄漏核查，md5 加感知哈希，固化进流程护栏；训练池按谱匹配加对比度加 JPEG 重编的配方重建；新引入的两个源也都过了内容级核查。教训只有一句：泄漏核查必须按内容，不能按文件名或统计口径。这条已经写进每一轮实验的准入检查。

---

# 08_three_traps

第三个困难不是技术，是统计。这个月我们踩了三个都能翻转判断的坑。第一是常数基线：低对比的 GT 下，一张平坦图就能拿十七点六八 dB，所以低档位的 PSNR 必须和基线并读，否则会把平凡解当成进展。第二是结论跟着测试集走：同一个 w 重加权组件，在 v2.1 上是负的，在扩增集上是正的；R 的偏差在 v2.1 偏亮、在扩增集偏暗。单测试集的结论不能外推。第三是噪声和门槛同量级：seed 之间的极差就有零点四到零点六 dB，而我们的判据门槛也是这个量级，所以一律要用配对检验加场景聚类的百分之九十五置信区间，不读单 seed 的点估计。三条合起来是一句：口径先于结论——每一个数字旁边都要站着它的基线、测试集和不确定性。

---

# 09_domain_adaptation

这是这个月的主结果。零样本在最深那一档是十二点零五，域适配之后做到十八点五，提了六点四 dB；另外两档分别是十九点七，不低于官方权重。方法很简单：冻结 FocalNet 主干，做三万步的域适配微调，配上干净的数据管线。结构相关从零点二六提到零点六三。下面这六列对照，每一行是一个场景，从左到右是输入、GT、零样本、pilot 和域适配的结果——请重点看第三列和第五列的区别：零样本基本是坏掉的，域适配把内容找回回来了。这也印证了前面的判断：原来的失败是内容级损伤，域适配修的是内容，不是亮度。四条臂的结果在十八点三到十八点七之间，是稳健的。

---

# 10_low_alpha_specialist

接下来讲低 alpha 专支，这一页要说清楚增益和代价各自落在哪儿。在四十八个场景的扩增集上做无泄漏重评，freeze 减 plain 的增益是：alpha 等于零点零五时正一点三一，零点一时正一点七五，零点二时正一点零九，零点三时正零点五二，而到了一就变成负零点三六。三个低档的聚类置信区间下界都大于零，但零点三档已经贴线。代价这一侧，在 v2.1 上 alpha 等于零点六和一时分别是负一点七五和负零点九四——注意这个量级只在 v2.1 上成立，两个集之间不能直接换算。所以定位很清楚：这不是一个独立的增益，而是一个把工作点往低 alpha 搬的旋钮，价值主要在零点二档及以下。它是低 alpha 专支，和主臂分工，不作替代。

# 11_identifiability_map

这一页是我们对"这题能到哪"的量化回答。四条参考线：最上面是真值天花板，用真 R 加精确的逐像素 alpha，能做到三十点七、三十四点一、三十四点九；往下是用我们自己训出来的 R̂ 配合真 alpha 做物理除法，掉到十七点二、二十点三、二十二点三；我们当前方法在十八点五、十九点七、十九点七；最下面是平坦图常数基线十七点六八。三档 alpha 顺序对应。这张图的价值在于：差距几乎全部出在 R̂ 和 alpha 这两处，不在方法结构上。别人问这个任务能到什么程度，我们有一张分档的答案。

---

# 12_physical_exit

这是本轮最关键的科学发现，也是两个负结果里的第一个。我们设计了一个物理除法出口：在冻结主干的基础上，加一个两万两千参数的出口头，公式是 T̂ 等于一减 beta 乘 T̂ head，加上 beta 乘 I 减 R̂ 除以 alpha 的估计。E 臂用估计的 alpha 做除法，G 臂用自由增益，各跑两个 seed。判决是：E 和 G 完全等价，差异不超过零点零二 dB，而且 alpha 等于一时相对 plain 还掉了二点零二 dB。也就是说，出口的净效应只是把工作点搬走。但接下来这个反事实诊断是决定性的：保留训练好的 beta，只把 alpha 换成真值，数值立刻跳到二十二点一五、二十一点一八、十八点八五，alpha 等于一时单档涨四点二六 dB，和训练前算的天花板二十二点二五几乎重合。结论就是标题这句：出口机制没问题，瓶颈是 alpha 的跨域校准。所以出口线我们条件性冻结了，重启条件是 alpha 的跨域误差足够小——目前测试端场景均值的 MAE 是零点二六、零点一七、零点零七，还远高于零点一这个门。

---

# 13_rhat_bottleneck

顺着上一页的归因往下追，瓶颈就落到 R̂ 上。误差预算是这样的：用真 R 时物理除法能到三十点七、三十四点一、三十四点九，换成我们训出来的 R̂ 就只剩十七点二、二十点三、二十二点三，落差十三点五、十三点七、十二点六 dB。原因是低 alpha 档的除法把 R̂ 的误差按 1 除以 alpha 放大了，零点三档这个倍数大约是二点四四。更麻烦的是 R̂ 的偏差还会跨域翻符号：在 v2.1 上偏亮，正四到正十五灰阶，百分之九十二同号；到了扩增集上反而偏暗。同一个根因的两种表现。根因假设是 R 训练池太小——只有一百三十一张，六百零一个候选里剔掉了四百七十个，而其中真正与测试 R 同簇的其实只有七十五张。下一页就说这两条腿怎么补。

---

# 14_mona_peft

两条腿里的第一条在特征侧。依据是一条同构的先例：CVPR 二〇二六的 GFRRN 发现全量微调掉分，从二十六点七掉到二十五点三五，而加 Mona 适配器反而涨分，从二十五点三五回到二十七点三三。我们在 pilot 上也见过同一个现象——长训之后 R̂ 反而下降。所以这是一个判别性实验：如果 Mona 有效，说明特征侧是瓶颈；如果无效，说明问题在数据侧。目前的进度是官方实现已经调研完，插入点确认在 FocalNet 块内两个残差之后，实现和冒烟测试正在进行。预期我给得比较诚实，正零点二到正零点八 dB，点估计正零点五；无论结果如何都有信息量。

---

# 15_rrw_expansion

第二条腿在数据侧，就是扩池。先解释池子为什么这么小：六百零一个候选里，只保留了一百三十一张，剔除构成是两百二十六张冗余副本、一百六十九张孪生、七十五张与测试 R 同簇。保留下来的这一百三十一张里，十七张来自 RRW 场景层，一百一十四张来自 wsoft。那是不是还有大片没开采？查过之后答案是否定的：本地 RRW 的一万零五百零八帧、四十二个场景已经全部开采完，未用场景是零。真正的余量在还没下载的场景上，一共一百零七个。扩池计划是把新提取的窗口过一遍孪生簇安全网，目标把干净池从一百三十一扩到两百八十七。

# 16_structure_anchor

第三个方向是储备，分两块。第一块是结构锚，两个都是零训练就能拿到的。边界台阶锚只读图像的硬边界结构，估计误差的 MAE 是零点零八零，场景聚类的置信区间零点零五九到零点一零一，R 真值的下界是零点零二三。多档配对不变量是无掩膜口径下误差百分之零点零六五，GT 掩膜口径是零点三一和零点二五；它描述的是同一物理量在两档之间的比值关系恒定。下一步是把这两个锚放进训练做一致性损失。第二块是全膜，也就是完全没有参照的场景：单帧不可辨，解不出唯一的 alpha，所以改用一个候选族加一次标定的协议——给出同一张图的若干亮度档，由一次外部标定来选。目前 oracle@k 扩档到 k 等于七是二十点九零 dB，标定之后的选择悔值是三点二零 dB，前二命中百分之八十六，按采纳门还需要改进，所以我们诚实地把它标成储备，不是已解决。新颖性上，文献调研确认单帧、硬边界、离散档、深衰减这个组合还没有人占位。

# 17_judgment_and_plan

最后是我对这个项目的三条判断和推进节奏。判断一，主线：论文押域适配加可辨识性地图，也就是刚才那个十二到十八点五的主结果，加上把可辨识性边界量化成图；方法增量是上行空间，不是前提。判断二，止损：物理除法出口在低 alpha 档判死，判死的原因是 alpha 而不是机制，重启条件是 alpha 的跨域误差足够小，在此之前不再投入算力。判断三，新方向：特征侧的 Mona 适配器和数据侧的 RRW 扩池并行验证，本周内出判决。节奏上，本周跑 PEFT 和扩池并出判决，下周把结构锚放进训练做一致性损失，实拍 sanity 等数据到位就排，用来补定量缺口。风险我如实说：目前所有主结论都是合成域上的结论，实拍定量还待补。
